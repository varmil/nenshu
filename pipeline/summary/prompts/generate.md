# 説明文の生成（C6・#160）

有価証券報告書の「事業の内容」の**原文だけ**を読んで、その会社が何をやっている会社かを
述べる説明文を書く。

## 入力

`work/batch_NNNN.json`。`companies[]` の各要素が1社で、`edinet_code` / `sec_code` /
`name` / `source`（原文）を持つ。

## 出力

`work/gen_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json
{"edinet_code": "E01967", "summary": "……。……。"}
```

書けないと判断した会社は `"summary": ""` にする。**無理に書かない。**

## 規格

- **全角60〜130字 / 2〜3文。** 句点で区切る
- **社名を含めない**（見出しに出ている）
- **数値を含めない**（子会社の数・売上・従業員数・設立年、いずれも）
- **評価語を含めない**（「業界最大手」「日本初」「高い収益性」「優れた」「急成長」…）
- **原文に現れない固有名詞を含めない**（カタカナ語・欧文の略語・関係会社名）
- 文体は常体（「……を行う。」「……を手がける。」）。敬体にしない

## 守る線

**原文から導けることだけを書く。** これが ADR-0010 決定2 で、この Unit の存在理由でもある。

- **世間で知られている話を足さない。** 例: キーエンスの原文には「キーエンス
  エンジニアリング㈱は当社商品の製造を行っております」とある。ここから
  「自社工場を持たないファブレス体制」とは**書けない**（原文はむしろ逆を書いている）
- **評価を書かない。** 「高い利益率を保つ」は記述ではなく評価
- **原文に無い言葉で言い換えない。** 「センサ・測定器」は原文に無ければ書けない。
  原文が「電子応用機器」としか言っていないなら、こちらもそう書く
- **原文が事業を説明していない会社がある。** 当期の異動（子会社の上場・セグメント区分の
  変更）の説明しか無い型がそれで、**その会社は `""` にする。** 字数があることと、
  会社の説明が書けることは別

## 書き方

1. 原文から「主な事業内容」に当たる記述を拾う。多くは冒頭の「その主な事業内容は……で
   あります」の一文にある
2. セグメントが複数あれば、**原文が使っている呼び名のまま**並べる
3. 誰が何をしているか（自社が開発と販売、子会社が製造、など）が原文にあれば1文足す。
   **関係会社の固有名を出さず**「子会社が製造を担う」のように書く
4. 規格に収める。**足りないから足す、ということをしない**——足りなければ `""` にする

## 例

**キーエンス（原文433字）**

> 電子応用機器の開発、製造及び販売を主な事業とする。商品の開発から販売までを自社で担い、
> 製造とソフトウェア開発は子会社が分担する。海外では現地の子会社を通じて販売する。

**ベリテ（原文116字）** — 原文が短く、2文に足りない。

> ""

**ＥＮＥＯＳホールディングス（原文417字）** — 字数はあるが、中身は当期の異動の説明だけ。

> ""
