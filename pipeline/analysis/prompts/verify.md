# 要約と分析の検証パス（C9・#241）

生成された**要約**と**分析**を、それぞれ別の基準で判定する。

**生成とは別の仕事として読む。** 「読んで自然か」「日本語として良いか」は見ない。機械ゲート（`gate.py`）が拾えないものをここで止める。

**この文書だけを読めばよい。** ADR-0015・ADR-0016 の決定は下に取り込んである。型の番号は `prompts/generate.md` が持っているが、報告に必要な番号は下の表にある。

**基準が2つある。** 混ぜると、要約に評価が通るか、分析が事実の写しになるかのどちらかが起きる。

| | 要約 | 分析 |
| --- | --- | --- |
| 判定 | 「4節の原文に**書いてあるか**」 | 「渡した材料から**導けるか**」 |
| 材料 | `sections` の4節だけ | 4節＋`figures`＋**`sources` の URL の中身** |
| 評価語 | あれば `false` | **あって当然。それだけでは `false` にしない** |


## この規格の育て方（**規則を足す前にここを読む**）

**規則は放っておくと厳しくなる一方になる。** 失敗は目に見えて記録され、そのたびに「次はこうしない」が1行増える。**通ったもの・良かったものは記録されないので、緩める側の力が働かない。** 181回目までの実測で、`generate.md` は否定・制約の語 281 に対し許容の語 29（9.7倍）、`verify.md` は 177 対 57（3.1倍）まで偏っていた。**そして180回目には、その偏りが実際に出力を壊していた**——分析が要約に戻り、主観の語が 109 → 44 に減っていた。

**だから、規則を足すときは次の3つを守る。**

1. **足す前に、既存の規則で防げないかを確かめる。** 同じ事故の言い換えなら足さない。**規則の数ではなく、規則が読まれる順序が効く**（180回目、丸めの細則21,000字が分析の規格の前にあることが「何を言うか」を消していた）。
2. **足すなら、同時に1つ緩めるか、緩める側の条件を書く。** 「〜しない」だけの追記は、**その規則が効かない場面**を併記する（`ただし〜のときは構わない`）。**例外の無い禁止は、書いた瞬間から過剰適用が始まる。**
3. **1つの事故から一般則を作らない。** 実例が1件しか無いなら、**その1件を判例として書き、規則にはしない**。3件そろってから規則にする。

**定期的に緩める。** 10回に1度は、この規格を通しで読んで**過剰に厳しくなった条項を緩める**（運営者の指示・181回目）。緩めた記録も docs に残す——**厳しくした記録だけが残ると、次に読む人は「厳しくするのが正しい」と読む。**

**「原文にこう書いてあるから」を、書き方の縛りに使わない。** 原文の表記・語順・区分の呼び方は、**事実が合っているかとは別の話**である。読者に伝わる書き方を選んでよい。


## 入力

`work/gated_NNNN.json`。`companies[]` の各要素が1社で、`edinet_code` / `name` / `summary` / `headline` / `analysis` / `sources` / `sections`（4節の**切った版**）を持つ。

**渡してあるのは、生成が見たのとまったく同じ材料である**（節ごとに MD&A 2,200字 / リスク 1,500字 / 課題 3,000字 / サステナビリティ 1,500字で切ってある）。**だから「切った先にあるから正しい」は成り立たない**——生成が持っていない位置にある事実を根拠にして通すと、材料の外から採ったものを見逃す。

**`pipeline/data/analysis_text_2026.csv`（切らない版）を絶対に開かない。** そこは生成が見ていない材料で、根拠に使うと判定の意味が変わる。

## 出力

`work/verify_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json

 "summary_supported": true,  "summary_reason": "",
 "analysis_supported": false, "analysis_reason": "撤退した事業を現在形で書いている",

```

`false` のときは `reason` に**食い違う箇所を1つ**書く（20字程度）。

## 要約の判定

**各文について、4節のどれかがその内容を述べているかを見る。1文でも支持されなければ `false`。**

`false` にするもの。

- 原文に無い事実を述べている（**記憶からの補完もここ**。「起こした電気を電力会社などに販売する」——4節に販売先が0件だった）
- 原文と逆のことを述べている
- 原文が触れていない範囲に広げている
- **評価になっている**（「収益性が高い」「強みを持つ」）
- **撤退した事業を現在形で書いている**（C6 の型①。これだけは先に確かめる）
- **有報の記載作法の説明を写している**（「報告セグメントは……で区分している」。C6 の型⑪）
- **主語が滑っている**（型④）。原文の主体が当社グループなのに、前文の子会社名が引き継がれて読める形。**処分や事案ごとに主体が違うのに束ねた形**も同じ
  - **対象が滑る形も同じ型で見る。** 品目を並べた次の文の「その生産は…へ委託している」のように、**指示語が原文の言明より広い範囲を受ける**形。指し先を書き出して、原文がその言明を与えている範囲と一致するかを見る

`true` にしてよいもの。

- 原文の言い換え・要約・順序の入れ替え／4節のうち一部だけを取り上げること
- 「当社」「当社グループ」を主語なしで書き直すこと
- **社名・子会社名・ブランド名を書くこと**（**原文に無い呼び方でも、一般に通っているものなら構わない**。読者が知っている名前で書くほうが伝わる。原文の表記に縛るのは、**その名前が別の会社・別の製品を指してしまうとき**だけでよい）
- **4節のどこから拾ってもよい。節の帰属は問わない**（分析では型A16 が生きているので、そちらは節と区分を見る）
- **「単一セグメントである」**（事業構成の事実。ただし「記載を省略している」まで写せば型⑪、主語を「報告セグメント」にすれば開示の話に寄る）
- **「持株会社である」**（4節に語が無くても、当社／当社グループの区別と事業会社の実名から構造の言い直しとして通す）
- **別の節に主体が書いてあれば、節をまたいで主体を合成すること**
- **述語が切れた文を根拠にすること**——見るのは「枠が読めるか」ではなく**「切れた先を推測して補っていないか」**。「取り組んでいる」なら通し、「提供を開始した」なら落とす
  - **線は「続きが一意に定まるか」。** 材料が `身近な風土であ` で終端していれば続きは「である／であり」しかなく、**時制も態も一意**なので `風土になっている` は通す。`注目を集` は「集めた／集めている」で**時制が確定しない**ので落とす。同じ「切れた述語」でも扱いが割れる
  - **切れた文の中に完結した成分があれば、そこを取ったものは通す。** `30周年のイベントを実施している『ポムポムプリン』が注目を集` の連体修飾は完結しているので、`『ポムポムプリン』は30周年のイベントを実施している` は根拠がある
- **`profit_per_employee_yen` の見送りに、規格に無い条件を既存の条件の名で付けない。** 162回目、リニカル（指標 0.922倍・**当期は経常損失**）を生成側が「条件④（またいで逆側）」で見送ったが、**当期は中央値のさらに下＝同じ側で、またいでいない**。**123回目の判例（当期が負でも、指標が正で両方が中央値の同じ側なら書く）にそのまま当たる**——バトンズ型が見送りになるのは「読者が突き合わせると2つの数字が逆を向く」からで、**さらに下に沈むだけなら向きは一致する**。**当期が損失であることを新しい条件として立てる必要も無い。** 書き方は判例どおり**倍率も実額も出さず語で書く**（数値を並べると、5期中央値である指標の正の値と当期の赤字が符号だけ食い違って見える）。**この見送りは `false` にせず申告で返す**（`false` にするのは6つの型だけで、指標に触れないことは事実の誤りではない）——申告も書き直させる経路なので直しは同じだけ起きる
- **型S3（区分の数え落とし）と型S4（membership の取り違え）は、同じ材料の読み方から出る。確かめ方も共通で「その事業名で4節を検索し、その段落の中に挙がっている区分を数える」で足りる。番号を分けたままにしているのは直し方が違うため**——S3 は数の断定を外す、S4 は原文の括りをそのまま写す。**MD&A の営業概況の見出しだけを数えない**（155回目、興和の6つ目の部門は課題の節にだけ見えていた）
- **申告（`false` にしない指摘）にも、`false` と同じ検索義務が掛かる。** 155回目、`自社オリジナル` を「語そのものは4節に無い」と申告したが、**リスクの節に製品名まで含めて逐語であった**（`自社オリジナルの基幹業務パッケージソフトウェアである「アラジンオフィス・シリーズ」`）。課題の節と MD&A しか見ずに書いたもので、**146回目とまったく同じ形の再発**。**落ちる理由の無いものを直させると、そのぶん別の問題が入る**——直しは常に新しい誤りの機会になる
- **原文にその語があることを根拠にしないこと。** 「有機・無機・バイオの技術知見を基盤とする会社である」——語は原文にあるが、原文は `新規事業創出については、…技術知見を基盤に…「浸み出し戦略」に重点をおいた取り組みを展開いたします` で、**掛かり先は新規事業創出の取り組み**。会社全体の性格として書けば**一段下に閉じた記述を上位で書く形**になり、要約の `false`。**語の存在だけを見て通さない。原文でその語がどこまでを覆っているかを当てる**（この型は検証側が言い換えを提案するときにも出る——語を探して掛かり先を確かめないと、生成側に誤りを渡すことになる）

**原文の構造から導けないことは、それだけでは `false` の理由にならない**（運営者の指示・181回目）。**有報も人間が書いているので、主述がねじれていたり、修飾の掛かり先が曖昧だったり、同じ節の中で言っていることが割れていたりする。** そこを厳密に読んで「原文はそう言っていない」と落とすと、**原文の書き癖を読者に転嫁する**ことになる。**見るのは「書き手が言おうとしていること」から外れているかどうか**であって、係り受けの厳密な当否ではない。

- **原文がねじれていて2通りに読めるなら、どちらに寄せても `false` にしない。** 落とすのは、**どちらに読んでも成り立たないとき**だけ。
- **主語が省かれている・「その」の指し先が形式上は複数あり得る、といった理由で落とさない**（日本語の文章では普通に起きる）。**文脈から素直に読める側を採る。**
- **ただし、事実そのものが逆になる読み方をしているなら落とす**（型S1）。**「除き」を落として反対の意味にする、増減の向きが逆になる、といった場合である**——これは構造の問題ではなく事実の問題。

**原文にない因果を接続詞で作らない。** 「品位低下や埋蔵量の減少が進む**ため**、高品位資源への需要が高まる」——原文が需要増の理由に置いているのは社会の持続可能性追求で、品位低下が導いているのは需給の逼迫だった。**2つの事実が両方とも原文にあっても、繋ぎ方が原文と違えば要約としては誤り**（分析では因果を作ってよいので、ここが2つの規格の分かれ目）。

**同じ形が「帰結の付け替え」としても出る。** 169回目、カチタスの要約は `買い取る住宅の約４分の３が空き家で、新築住宅に比べて約半額程度の価格で手ごろな住宅を提供することを通じ、空き家問題の解決に貢献している` と書いたが、**原文は貢献先を2文に分けている**——約4分の3が空き家 → 空き家問題の解決、半額程度の手ごろな住宅 → お客様のより良い暮らしの実現。**2つを1文に潰す過程で片方の帰結が落ち、両方が一方の帰結へ寄った。** 因果を発明したのではなく、**並んだ2文の帰結を一方へ寄せた形**で、確かめ方は同じ——**繋ぐ前に、原文でそれぞれが何に掛かっているかを当てる**。**直し方は原文の対応に戻すことで、主張を弱めることではない**（帰結を書かずに事実だけ並べるのでもよい）。**同じ節のマテリアリティ表が2項目を別に並べている**ように、**原文が分けているものは分けたまま写す**

## 分析の判定

**見るのは「事実の誤りが無いか」だけである**（ADR-0016）。

**分析の申告は、事実の誤りに関わるものに限る。踏み込みを弱める提案をしない。** 180回目に実測したところ、**初期60社と直近60社で主観の語が 109 → 44 に減り、事実の語が 119 → 284 に増えていた**——分析が要約に近づいていた。原因の一つが**申告の向き**である。「材料は述べていない」「この数字からは読めない」という申告は、`false` にしていなくても**書き直しの経路に乗るので、踏み込みが1つずつ削られていく**（169回目、`初任給を上げただけで人が残る段階には届いていない` を `この数字からは読めない` に弱めた直しは、ADR-0016 に照らすと**当てるべきでなかった**）。**推測が「材料に無い」のは当たり前で、それが分析の仕事である。** 申告してよいのは、**その推測の土台になっている事実そのものが間違っているとき**だけ——数値の向き、区分の帰属、時点、材料が持たない出来事の存在。**「言い過ぎ」「断定しすぎ」は申告の理由にならない。**

**規格の例文の事実関係は、原文に当たって食い違えば原文が正**（191回目の判例）。`generate.md` に載る良い版・悪い版は**主題の立て方の見本**であって、その中の事実まで正としているわけではない。**「規格に載っている形と違う」を落とす理由にすると、原文より規格の写しが優先される逆転が起きる。** 実例——東京海上の良い版の `保険引受能力の高度化` は、原文が `高度な保険引受能力や専門性を活かした保険料収入の拡大…を通じて、保険引受利益を持続的かつ安定的に拡大` と書いており、**会社は能力を高度化するとは言っていない**。生成側が `保険引受利益の持続的な拡大` に直してきたのが正しかった。

**6つ目として「事実で終わっていて "So What" に降りていない」も指摘してよい**（187回目・運営者の指摘）。**求職者が知りたいのは数字や事実ではなく "So What?" である**——主張が主で、事実はその補足として書いてもよいもの（`generate.md` の「主従の向きを見出しにも当てる」）。**見出しや本文の主節が事実の記述で終わっているなら、そこから何が言えるかまで降りさせる。** これも**踏み込みを強める**申告なので、上の禁止とは向きが逆である。**`false` にはしない。**

**ただし、5つ目として「主題から外れた話題が並んでいる」だけは指摘してよい**（187回目・運営者の指摘）。**分析は1つの主題を立て、それを支える文だけで組む**（`generate.md` の「主題は1つ。刺さらない観点は、真であっても捨てる」）。**話題が3つ以上に散っていて、読み終えて何が残るか一言で言えない**なら、**見出しを支えていない文を名指しして落とさせる**。これは踏み込みを**弱める**申告ではない——**捨てることで残った主張が強くなる**ので、上の禁止とは向きが逆である。**`false` にはしない**（事実は誤っていない）。**「観点が少ない」を理由に足させることは絶対にしない。** **落とさせすぎる側の歯止めも要る**（187回目・検証側の指摘）——**主題に対する留保・裏返し・条件は、話題が替わって見えても落とさせない**（良い例の5文目「ただし平均年収は…」がそれで、主題と対立させることで主題を強めている）。**この指摘は外形が「踏み込みを弱める申告」とよく似ている**ので、使う前に**捨てることで残った主張が強くなるか**を確かめること。強くならないなら、それは弱める申告のほうである。

**外部 URL を根拠にした記述の照合は、`sources` に挙がったページの本文に閉じる。** 同一サイトの別ページまで探しに行かない——**どこまで探すかで `false`／申告／通すが変わってしまう**（180回目、鈴与シンワートの `上流工程` は挙がった URL には無く、同じ採用サイトのトップと FAQ にあった）。**生成側には「引いた記述のあるページを `sources` に挙げる」という規律が要る**ことの裏返しで、挙がったページに無ければ**材料の語に戻させる**（照合できないものを通すのでも落とすのでもなく、確かめられる形に直させる）。

**推測は落とさない。** 因果・評価・見通し・重み付け・比較・含意は**このセクションの本体**であって、材料が明示していなくても**そう読めるなら通す**。**言い過ぎを落とすのをやめた**——50回まわした結果、それが分析を要約と大差ないものにしていた。

`false` にするもの。**この6つだけ。**

| 型 | 落とすもの |
| --- | --- |
| **S1・A5** | **数値の向きが逆**（2,278 → 2,045 億円と減っているのに「上回った」） |
| **A8** | **数値の幅が食い違う**（9.0%増を「二桁の増益」、71.9%増を「7割近く」） |
| **A12** | **出来事の時点が違う**（翌期の発売を当期の新作として書く。日付が出てこない形もある）。**向きは前期→当期もある**（138回目。ＡＣＣＥＳＳの `売掛金が長期間にわたり滞留し、社内調査委員会を設置する事態になった` は、課題の節が設置を2024年10月15日＝**前期**の出来事として日付で書いていた）——**当期の業績を述べる流れに時点なしで置くと当期の出来事に読める**。**日付を持つ記述が材料にあるのに時点を書かなかっただけなら `false` にせず申告でよい**（`前期には` の一語で消える）。**当期として断定していたら落とす。****同じ書類に期間が2つ以上あるとき、片方の窓でもう片方を括るのもこれ**——134回目、イビデンの `2026年度から2028年度の３ヶ年` の投資を「中期経営計画の期間に」と書いたが、中計は2023年度からの5ヵ年で始期が3年ずれていた |
| **A10・A14・A16・型④** | **区分が違う**（セグメントの損益をその中の事業名で呼ぶ／別の節の出来事を移す） |
| **A3** | **材料の外の属性・出来事を事実として足した**（原文に無い工場・製品・資本関係。**数値を記憶から書いたもの**と、**材料に出てこない過去の出来事を持ち出して当期の増減を説明したもの**もここ） |
| **A13** | **改善要因を悪化の中身として並べた** |

**この6つは推測ではなく誤りである。** 読者が材料に当たれば違うと分かり、「そう読める」の余地が無い。

**「材料に出てこない過去の出来事」が型A3 に入る理由**——ADR-0016 が解いた旧・型A2 は「AがBを起こしている」という**関係**の推測だが、「前期に大口案件があった」は**出来事の存在**で形が違う。**因果の推測なら読者は「そう読めるか」を自分で判定できるが、出来事の存在は材料に当たっても無かったことを確かめられない。**

**`false` にしないもの。** 以下はすべて **ADR-0016 で通す側になった。**

- **材料が述べていない因果**（旧A2）・**内訳の無い切り分け**（旧A1）・**重み付け**（旧A15）
- **1期の増減から述べた趨勢**（旧A7）・**材料が持っていない比較**（旧A11）・**外から持ち込んだ評価の基準**（旧A17）
- **減収の要因を減益にも掛けること**（旧A18）・**並列に包含関係を作ること**（旧A19）・**材料が書いていないことを「無い」と述べること**（旧A6）
- **評価語があること・断定的であること**（それが本体）
- **業界の文脈や一般的な知識**（ADR-0016 決定3）。**ただし数値だけは材料にあるものに限る**ので、金額・率・順位・シェア・従業員数が材料のどこにも無ければ**型A3 として落とす**
- **材料が薄く、分析も薄いこと**（薄いまま書くのは正しい振る舞い）

**`sources` の URL は確かめる。** 落とすのは**分析が URL を根拠に述べたことがその URL に無いとき**だけ（型A3 扱い）。開けない・別の会社を指しているのも同じ。

- **URL が無いこと自体は落とさない**（記憶から文脈は書いてよい）
- **挙げたのに使っていないのも落とさない**（ただし生成側では挙げないほうが素直）
- **URL が主張を部分的にしか支持しない形も通す**——**一面的であることは推測の当否であって、事実の誤りではない**
- **URL が期末後の材料でも、時点を当期に寄せて書いていなければ通す**

## 通す判断の線（決着済み）

**丸めた比率**——**下から近づく言い方は、丸めた数に対して実測が9割以上なら通す。「◯に届かず」型にも同じ線を当てる。** 上から近づく言い方は誤差1ポイント台まで。**丸めの「〜ほど」は最も近い数に付くなら通す**（42.5% を「4割ほど」）。

**この2つを取り違えた申告が3回出ている。表で持つこと。**

| 言い方 | 例 | 当てる線 |
| --- | --- | --- |
| 下から近づく（`◯割近く` `◯に届かず` `◯を下回る程度`） | `月10時間に届かない`（実測8.4＝84.0%） | **丸めた数の9割以上**。84.0% は**落ちる** |
| 丸め（`◯割ほど` `およそ◯割`） | `2割ほど上がり`（実測+17.85%） | **最も近い丸い数に付くなら通す**。2割との距離2.15 < 1割との距離7.85 なので**通る** |
| 上から近づく（`◯割余り` **`◯割強`** `ほぼ◯割`） | `2割余り`（実測20.8%） | 誤差1ポイント台まで |
| **参照先が実額**（`figures` が渡す値そのもの） | `業種中央値には届いていない`（実測82.5%） | **9割線を当てない**。丸めた数ではないので、大小が真なら通す（離れているなら実数か倍率で書かせる） |

**丸めの刻みは5ポイントまで細かくしてよい**（`1割半ほど`／実測 −16.60% は差1.60ポイントで、`2割ほど`（差3.40）より近い）。**刻みを細かくして実測に近づけるのは通し、粗い刻みを緩めるのは通さない**——後者は「半分あまり」を4.3ポイント外れで通さないのと同じ線で、**緩めるとどこまで粗い目盛りなら許すかを毎回決めることになる**。

**同じ回の同じ文に両方が並ぶことがある**（`平均年収はこの10年で2割ほど上がり、残業時間も月10時間に届かない`）——**片方に当てた線をもう片方に持ち越さない**。

**`◯割強` はこの行に入る。** 実測 +13.75% を「1割強」（3.75ポイント外れ）、+32.8% を「3割強」（2.8ポイント外れ）と書いた例が同じ回に2つ出た。**どちらも丸めの「〜ほど」なら通る**（13.75% は1割、32.8% は3割が最も近い）ので、**言い方を替えるだけで解ける**。

**`半分あまり` のように目盛りが10ポイント刻みでない語も、3行目の線に掛ける。** ある回、実測54.3%を「半分あまり」と書いた例が出た（4.3ポイント外れ）——**「半分を超える」と書けば下限の言明になって通る**。**「半分」は目盛りが粗いから緩めてよい、とはしない**（緩めると、どこまで粗い目盛りなら許すかを毎回決めることになる）。

**ただし `大半` は3行目に掛けない。過半の下限言明として扱い、9割線も1ポイント線も当てない**（133回目。それまで `半分あまり` と同じ行に置いていたが、**`大半` は目盛りの数を持たない**——`半分あまり` が「半分」に上から近づく語なのに対し、`大半` は何割に近づいているのかが定まらないので、当てる目盛りを判定する側が選ぶことになる）。実測85.7%・92.1%の2件はどちらも下限が真なので通る。**逆に過半に届かないのに `大半` と書いたら偽**なので、線としてはこれで閉じている。**過半すれすれ（6割未満が目安）で `大半` を使ったのは `false` にせず、「半分を超える」に替えさせる**——下限が真である以上は事実の誤りではなく、ここに別の下限を持ち込むと「どの目盛りなら大半と呼べるか」を毎回決めることになる。

**`◯を超える` はこの行に入らない。`◯割を超え` も `◯倍を超える` も下限の言明**なので、**実測がその数を超えていれば真**（`2割を超えて`／実測22.6%＝通る）。表の3行目が掛かるのは**その数に近いことを含意する語**だけ——`◯割余り`・`◯割強`・`ほぼ◯割`。**「超える」と「余り／強」を同じ行に置いていたため、同じ回に両方の判定が出て衝突した**（107回目）。

**倍率の `◯倍を超える` に「誤差1ポイント台」を当てない。** 3行目の線が掛かるのは**その数に近いことを含意する語**（`◯割余り`・`ほぼ◯割`）で、`◯倍を超える` は**下限の言明**だから、実測がその数を超えていれば真である（`業種中央値の倍を超える`／実測2.24倍＝**通る**）。**「2倍を超える」のほうが近い、は落とす理由にならない**——より近い言い方があることと、書いてある言明が偽であることは別。

| --- | --- | --- | --- |
| 「3倍近い」 | 2.73倍 | 91.0% | 通す |
| 「4割近く」 | 36.7% | 91.8% | 通す |
| 「3割近く」 | 26.8% | 89.3% | 落とす |
| 「倍に迫る」 | 1.75倍 | 87.5% | 落とす |

| 「半分に届かず」 | 42.5% | 85.0% | 落とす |

そのほか決着したもの。

- **数を語で丸めること**（「上位10社」を「上位数社」）は型A8 に当たらないが**幅の食い違いに近い**ので直させる
- **「最も高い」と「並んでいる」の間**——差 0.02% なら「並んでいる」で通す
  - **`並んでいる`・`同じ水準` のように向きを名乗らない語は、誤差1ポイント未満まで**（倍率で言うなら1%未満）。**超えたら向きを名乗らせる**（145回目。日本システム技術の 1.036倍＝3.6%上回るを `わずかに上回る程度` と書いた）。**上の 0.02% の判例はこの内側**で、例として残す
  - **`わずかに`・`大きく` のような目盛りを持たない程度の語には、目盛りを当てない**（`大半` を丸めの表に入れないのと同じ。133回目）。**向きさえ名乗っていれば、程度の語の強さは問わない**
  - **この対称性は語の強さの判定に限る。** `profit_per_employee_yen` に**触れるかどうか**は依然として非対称（上回る側の見送りは落とさない／下回る側は条件①③④に当たるときだけ）
- **一人当たり利益の分母と分子の範囲がずれること**（`employees` は単体、`profit_per_employee_yen` は連結の利益ベース）は**通す**——`figures` がその2つを渡しており、同じページのレーダーも同じ掛け算をしている。**落とすと `figures` を使うほど落ちる圧力が掛かる**ので、線は生成側に引いた
- **指標に触れていないことを申告する前に、`pipeline/data/performance_history.csv` の `oi_basis` を読む。** ある回、「業種中央値を0.50倍で下回るのに書いていない＝下回る側だけ避けている」と申告したが、**その社は中央値に採られた年が `nonconsolidated` で、分母が連結＝条件①に当たり、見送りが正しかった**。**値だけで申告しない**——基準は確かめられる
- **分析が画面の作りを説明すること**は**「画面の数値をどう読むか」まで通す**（持株会社の年収を事業会社の水準と誤読するのは実害）。**我々の側を主語にした形**（「当サイトでは提出会社ベースで表示している」）**は書き直させる**——実装の説明は `/about` と C10 の断りの仕事
- **社名から自明な系列関係**（「トヨタ系」）は**数値でないので通す**
- **区分のうち1つだけ材料が増減を書いていないとき**、**逆を指す数値も記述も無いなら束ねてよい**
- **材料が1点しか持たないことに継続の語（`まま`・`続けており`）が当たっていたら申告する**（137回目）。過年度の記載は確かめられないので**偽とは言えない**が、`挙げており`・`…するなかで` に替えれば含意ごと消える
- **原文の「おそれ」「可能性」が「見込み」に上がっていないか、「一つ」に順位が付いていないかを見る。** どちらも**一段強めた形**で、原文の語に戻すだけで解ける——**ただしこの行は要約にだけ掛かる。** 分析では**強さの調整は申告の理由にならない**（180回目の新規則。申告してよいのは数値の向き・区分の帰属・時点・材料が持たない出来事の存在の4つだけ）。180回目、エフ・シー・シーの `会社自身が最大のリスクに書いており`（原文は順位を付けず並列）とコロプラの `22時以降の作業を禁じる`（採用ページは「深夜（22時以降）の**残業**を**原則**禁止」）がこの境目に落ちた——**前者は申告しない、後者は「作業」が「残業」より広く字面が材料と食い違うので材料の語に戻させる**。**強さを弱めさせるのではなく、字面を材料に合わせるだけ**である
- **修飾語の掛かり先が原文から動いていないかを見る。** `当社及びグループ社員のすべての行動・判断の基準` を `全社員の行動・判断の基準` と縮めると、**「すべて」が行動から社員へ移り、グループ社員が落ちて読める**——**縮めるときに動くのは修飾語の位置**
- **排他の語で表を受けている箇所は、表の型に応じて確かめる**（149回目）。**金額の区分表なら合計欄と区分の和**（下記）、**目標と実績が並ぶ表なら行を1行ずつ突き合わせる**——ＴＯＷＡの表は7行あり**配当性向だけが達成側**だったので、`すべての指標` なら偽だった（本文は `営業利益率とＲＯＥには` と閉じていたので真）。**向きが揃っていない行が1つでもあれば、排他の語を表全体に掛けさせない**
- **排他の語（`全て`・`だけ`・`いずれも`）は、材料の表の合計欄と区分の和が一致するかまで見る**（136回目）。モリタホールディングスの表は4区分の和が合計欄と数百万円ずれており、**表に載らない小区分がある**——`全ての事業が` は表の外まで覆うので `４つの事業がいずれも` と数を名乗らせる。**本文で区分を数え上げてから受ける `だけ` は通す**（排他の範囲がその数え上げに閉じる）。**この照合は売上の表（合計欄が区分の単純和になる系列）にだけ当てる**——**損益の区分表では、合計欄と区分の和は一致しないのが通常である**（全社費用・調整額が引かれる）。179回目、文化シヤッターのセグメント利益は区分和 21,110百万円に対し全社の営業利益 15,569百万円で **5,541百万円ずれる**が、これは小区分ではなく調整額であり、下の線をそのまま当てると**「表に載らない小区分がある」と誤判定する**（検証側の指摘）。**ずれが丸めか小区分かは `区分数 × 単位の半分` で切り分ける**——百万円単位で4区分なら 2百万円までは丸めで出る差なので、**それを超えたときだけ小区分を疑う**（177回目、ＣＫサンエツの販売実績は合計149,438 対 3区分和149,436 の**差2百万円**で、3区分×0.5＝1.5 をわずかに超えるが相殺消去の注記があり丸めと判断できた）。**上限が書かれていないと、判定側が毎回自分で線を引くことになる**（検証側の指摘）
- **全体の値で言う文に区分ごとの逆向きがあるとき**は、`全体では` を足させる。**落とすほどではない**（合計が真なら偽ではない）が、読者が区分の列と突き合わせると逆に読める
- **為替中立と報告ベースで向きが逆になるとき**、**原文が主系列を明らかにしていれば明示は要らない**
- **「若い会社」を在籍年数だけから言うこと**は通す（数値でも属性でもない）
- **判定の入口はこの2行で足りる。まず `profit_per_employee_yen ÷ industry_median_profit_per_employee_yen` を1回出す**（この割り算は「確かめ」に数えない。どちらの入口に入るかがこれで決まる）。 **倍率が1以上で指標に触れていないなら、そこで終わり**（**`1` を含める**——171回目、日産車体は 1.000倍ちょうどで、「超えて」いないために条文通読の側＝下回る側の扱いへ流れた。通読すれば下の「触れても触れなくてもよい」に着地するが、**入口で閉じるべき社**である）（触れないこと自体は減点ではなく、理由も立てさせない）。**触れているなら、確かめるのは「基準（`oi_basis` と分母）がそろっているか」と「またいでいないか」の2点だけ**——**またぎは向きによらず見る**。入口の1行目（倍率が1以上なら終わり）は**触れていない社**の話で、**触れている社では上回る側でもまたぎが起きうる**（166回目の新日本電工型・176回目のプラップジャパンで実際に確かめた）。**入口の2行だけを守ると、上回る側で2点目を飛ばしかねない**（検証側の指摘）。**下回る側で触れていないときにだけ、以下の条文を通読して見送りが3条件のどれかに当たるかを判定する**——長いのは、その1つの場合のためである。
- **見送ってよい条件は次の3つだけ。番号はこの表が正で、名乗るときはここから引く。当てる順序は ①→④→③ が速い**（209回目・検証側の提案。**①は CSV の1列を読めば終わり、④は割り算1回、③は指標を見るだけだが該当はまれ**。**番号順に当てると、①が外れた社で③を挟んでから④に着く**——東急建設は**①が不成立で④だけが成立**する組み合わせで、最新年の分子・分母を自分で割って初めて決まった）。**並びは番号順のまま置く**（判例が番号で引いている）
  - **条件①（基準の食い違い）**——`performance_history.csv` の `oi_basis`（連結／単体）と、分母の従業員数（連結／単体）が**食い違う**とき。**どちらの向きも当たる**——`nonconsolidated`（単体の経常利益）なのに分母が連結、も、`consolidated`（連結の経常利益）なのに分母が単体、も同じである（178回目、ユナイトアンドグロウは中央値の年が `consolidated` で分母が単体307人という**鏡像**だった。条文が単数の組み合わせでしか書かれておらず、**名乗れる番号が無かった**）。**判定は値ではなく基準で行う**ので、「連結と単体の人数がほぼ同じだから食い違いではない」とは数えない。**5期のうち一部だけ基準が違うときは、中央値に採られた年の `oi_basis` を見る**。
  - **条件③（指標が負）**——`profit_per_employee_yen` そのものが負。**負の値を業種中央値と比べても位置が読めない**。
  - **条件④（またぎ）**——当期の経常利益 ÷ 同じ分母が、業種中央値を**またいで逆側に出る**。差の大きさに下限は無く、向きは両方ある。
  - **②は欠番。** かつて「5期のうち1期でも `oi_basis` が違う」を独立の条件として数えていたが、**173回目に「中央値に採られた年の基準を見る」として条件①へ吸収した**ので、いま名乗れる番号ではない。**①③④の番号は過去の判例（162・166・173回目）が使っているので振り直さない。**
  - **番号を名乗らせる規則（173回目）は、この表があって初めて働く。** 175回目、生成側が Photosynth の「指標が負」を**条件②と呼んだ**——見送りの実体は正しかったが、**規格のどこにも番号の割り当てが列挙されていなかったので、検証側は照合できなかった**（`条件①〜④`・`4条件` という書き方だけがあり、①と④しか判例から逆算できない状態だった）。

- **`profit_per_employee_yen` が業種中央値を下回ることは、指標を避ける理由にならない。** **以下は上の表の条件①を詳しく述べたもので、条件③と条件④は表のほうを見る。** 条件①が言うのは**分子と分母の基準が食い違う**とき——`performance_history.csv` の `oi_basis` が `nonconsolidated`（単体の経常利益）なのに分母が連結の従業員数、という組み合わせ——である。**判定は値ではなく基準で行う**：この型では値が中央値の 0.6 倍でも 3 倍でも指標として意味をなさず、逆に基準がそろっていれば 0.3 倍でも書いてよい。**「5期の中央値が当期を代表しない」も避ける理由として認めない**——この指標は定義からして5期の中央値で、成長中の会社ならどこでも中央値は古い年に当たる（認めると下回る側だけ代表性を疑う逃げ道になる）。**「1/10 以下なら」と値で線を引かない**（楽天グループは 0.60 倍だが分子が単体・分母が連結29,419人で、避けるのが正しい）。**基準がそろったうえで下回るのを避けると、上回る会社でだけ指標を出す**選り好みになる。**`oi_basis` が5期のうち一部だけ `nonconsolidated` のときは、中央値に採られた年の基準を見る**——指標は5期の**中央値**なので、実際に効くのはその年の基準である（173回目、tripla は中央値が2024年の `nonconsolidated` で分母が連結190人＝条件①そのもの）。**`performance_history.csv` から確かめられる**。条文が「`oi_basis` が `nonconsolidated` なのに分母が連結」という単数の組み合わせで書かれているため、**「中央値の年は `consolidated`、他の年が `nonconsolidated`」という並びが来たときに一意でなかった**（検証側の指摘）。**`nonconsolidated` というだけで「基準が食い違う」と数えない**——分母は `employeesConsolidated ?? employeesNonConsolidated` を使う**——`figures.employees` は提出会社の数なので、持株会社のように連結と単体で2桁違う会社では**分母の選び方でまたぐ／またがないが割れる**（168回目、東洋製罐グループHDは連結19,067人で当期1.49倍・提出会社533人なら109倍と、桁が変わる）。これまでの実例（バトンズ・八十二・リニカル・新日本電工）はどちらの分母でも結論が同じだったので表に出ていなかっただけで、**分母を書いておかないと、またぎの判定そのものが選べる**
  - **「業種中央値に近いから言うことが無い」も、上回る側でだけ認める**（125回目。八洲電機＝1.025倍で見送り、通した）。却下した2つ（「5期の中央値が当期を代表しない」「当期の利益額に触れるから割ると合わない」）と**同じ形**で、**下回る側でこの理由が出たら認めない**——**中央値への近さは向きによらない**ので、下回る側で使えば「近いから」の一語で選り好みが通る。上回る側は避けてよい（「上回るのに触れないことは落とさない」）ので、そこで近さを挙げるのは差し支えない
  - **倍率がちょうど 1.000（その社自身が業種中央値）のときは、触れても触れなくてもよい**（127回目）。**社数が奇数の業種には中央値そのものの社が原理的に1社ずつ存在し**、同じ回に2社出た（栗本鐵工所＝鉄鋼35社の18番目、東和薬品＝医薬品41社の21番目。どちらも `industryMedian` と完全一致）。**「上回る側」でも「下回る側」でもないので、下回る側の見送りを認めない規則は掛からない**
  - **触れるなら「業種中央値と同じ水準にある」と書いてよい**——値が同一なので真であり、読者が「たまたま中央値付近に並んだ」と読んでも導かれる結論（業種のまん中にいる）は変わらない。**その社が中央値そのものであることまでは書かせない**（画面の他の数字から確かめられず、読者が確かめられない属性になる）。**この社ではまたぎの判定を行わない**——またぎは「指標と当期が業種中央値の逆側にある」で決まるが、**指標が中央値そのものだとどちらの側にも属さない**ので、当期がどちらに出ても「またいだ」と言えるし言えない（171回目、日産車体の当期は 2.946倍で上）。**触れるなら「業種中央値と同じ水準にある」とだけ書く**
  - **「同じ業種の社が並んだから片方は書かない」を見送り理由にしない**（128回目）。**「近いから」よりたちが悪い**——近さはその社自身の値から言えるが、これは**同じバッチに何が入ったかで決まる**ので、**同じ会社が別のバッチなら結論が変わる**。上回る側でも理由として立てさせない（触れないだけにする）。下回る側で出たら認めない
  - **上回る側で見送るときは、理由を立てずに触れないだけにする**（126回目）。上回る側の見送りはもともと落とさないので理由は要らず、**書けば「近いから」「別の軸で書いたから」という言葉が回をまたいで残り、下回る側でそのまま使われる**——**認めない側の逃げ道は、認める側で立てた理由が作る**
  - **本文が金額を書かないなら、`profit_per_employee_yen` が経常利益かどうかの確かめは検証パスの対象外。** 当てるのは**倍率が正しいか**だけで、**指標そのものの正しさは pipeline（P2 のラベル二重弾き）の責任**——混ぜると毎回全社ぶんの経常利益を疑うことになる。167回目のりそな銀行がこの形（本文は `銀行業の中央値の2倍を超える` としか書かず金額を1円も出していない）
  - **経常収益との取り違えを疑うときは、系列の水準の一貫性を本命にする。** 同じ会社の他の年が同じ桁に並んでいるかを見る（りそなは 2018年 128,722／2019年 130,446／2020年 147,730／2026年 281,030百万円 と8年ぶん同じ水準で、**経常収益ならどの年も兆円台になるはず**）。**仮定を置かないので最も安い。** 逐語照合（155・158回目）と要素名＋ラベルの二重弾き（152回目）が使えるならそちらが先。**税率の逆算（経常利益から法人税等を落として純利益に着地するか）は添え物**——推論の鎖が長く外部の仮定が混じるので、**2つの候補が桁で分かれるときに限る**
  - **またぎは両向きある。向きは問わない。** 166回目、**上回る側でまたぐ例**が出た（新日本電工＝指標 5,040,456円で鉄鋼の中央値 3,492,404円の **1.443倍＝上**、当期の経常利益 ÷ 従業員数は 2,803,942円で **0.803倍＝下**）。**これまでの実例（バトンズ・八十二・リニカル）はすべて「指標が下」から出ており、条文が「下回る側の逃げ道を塞ぐ」文脈の中にある**ので、上回る側でまたぐ社が来たとき「上回る側の見送りはもともと落とさないのだから条件を名乗る必要がない」と処理されかねない。**見送りの根拠は「読者が突き合わせると2つの数字が逆を向く」ことで、どちらから逆を向いても同じ**——新日本電工の分析は当期の合金鉄の経常損失を中心に据えているので、指標を「1.4倍」と書けば同じ画面で「上」と「下」が並ぶ
  - **この見送り（＝またぎ）だけは、上回る側でも名乗ってよい。** すぐ上の「上回る側では理由を立てない」（126回目）の**例外**。**理由がその社の2つの値だけで決まり、下回る側に流用しても同じ条件でしか通らないので、選り好みの逃げ道にならない**——「近いから」「別の軸で書いたから」「字数が埋まったから」はどの社にも当てはまるが、またぎは値が実際にまたいでいなければ名乗れない
  - **当期の経常利益が負でも、指標が正で両方が業種中央値の同じ側なら書く**（123回目。バルミューダ＝指標13.5万円で中央値の0.06倍・当期は△869万円）。**逆側にまたぐとき（バトンズ型）だけが見送り**で、**両方が同じ側に落ちるなら、符号が違っても読者が突き合わせて逆を向くことは起きない**——同じ分析が当期の営業損失に触れていても書く。**書くときは倍率も実額も出さず語で書く**（「業種中央値を大きく下回る」）——数値を並べると、5期の中央値である指標の正の値と当期の赤字が画面上で符号だけ食い違って見える
  - **「当期の利益額に触れる分析だから割ると合わない」は見送り理由にしない**（118回目。八十二長野銀行で出た）。認めるのは、当期の経常利益 ÷ 従業員数と `profit_per_employee_yen` が**業種中央値をまたいで逆側に出る**とき（バトンズ型）だけで、**同じ側に落ちるなら倍率がどれだけ離れていても認めない**（八十二は当期1,975万・指標921.7万で、どちらも業種中央値772.0万の上）。**この理由は当期の損益に触れた分析すべてに使える**——指標は定義からして5期の中央値なので、増益中の会社では当期と必ず食い違う。**下回る側の社でこの理由が出たら、逆転を数字で示させる**：2つの値を並べて中央値をまたいでいなければ、`oi_basis` の食い違いでも負値でもない
- **逆に「上回るのに触れない」ことは落とさない。** 指標に触れるかどうかは生成側が選んでよく（`generate.md`）、**避けてはならないのは下回る側だけ**——そこで避けると選り好みになるが、**分析の筋に載らないから書かないのは、どちらの向きでも通す**
- **持株会社で平均年収・在籍年数を語るとき、その数字が事業会社ではなく提出会社のものだと断ること**は**通す**（画面の数値をどう読むかの範囲）。**「持株会社である」と構造を主張するなら根拠は4節に要る**が、**「この平均年収は◯◯株式会社に在籍する人のもの」と数値の読み方に留めるなら、4節に `持株` が無くても通す**——`figures.employees` の定義（提出会社）から言えるうえ、**4節の事業の記述がすべてグループを主語にしている**ことも支えになる。**根拠は4節に要る**——「当社の子会社及び関連会社は……を営む会社等で構成」のような記述から到達できること。社名や業態からの補完で書かない。**我々を主語にした形**（「当サイトでは提出会社ベースで表示している」）は書き直させる
- **`profit_per_employee_yen` を「一人当たり経常利益」と呼ぶことは、4節に `経常利益` が0件でも落とさない。** この指標は**連結の経常利益が取れない会社では単体の経常利益から作られている**（`pipeline/data/performance_history.csv` の `oi_basis` が `nonconsolidated`。**直近5期すべてが単体なのは527社＝17.8%**で、IFRS 採用会社の多くがここに入る）。**経常利益は有報の「主要な経営指標等の推移」の提出会社欄に実在する科目**で、記憶からの創作ではない。**指標名をそのまま書くほうが揺れないので、段階を名乗らない形（「一人当たり利益」）へ書き換えさせない**
- **業種の分類と事業の中身がずれる会社で、倍率を数値で書かずに「大きく上回る」と書き、分類の効果を名指しすること**（「同じ区分に並ぶのは信販やリースの会社で、取引所とは商売の形が違う」）は**通す**——業界一般の知識で数値を含まない。**数値を書かないことと、読者が同じページで見る数字の読み方を添えることは両立する**
- **9割の線は「近づく」言い方に当てる。** 上限を示すだけの「◯に満たない」（0.4% を「1%に満たず」）は近接を含意しないので**落とさない**が、離れているなら**実数で書かせる**——「◯に届かず」（近接を含意する）とは別の語として扱う
- **原文の「〜も あり」を因果として言い切ること**は**通す**（型A9 を新設しない）。落とすのは材料が**逆を指している**とき（型S1）だけで足りる——「原文が『も』を使ったら言い切れない」を規格にすると、ADR-0016 が通すと決めた重み付けと因果のほとんどが引っかかり、**分析が要約に戻る**。ただし**他の要因を排除する書き方**（「〜だけによる」）は別で、その要因が原文に並んでいれば落とす

## 落とすほどではないが直させるもの

**事実の誤りではないが、読者が材料に当たったときに引っかかる形。** `true` にしたうえで申告し、書き直させる。

**区分の帰属がずれていても、その区分の損益の向きが材料と一致していれば申告に留める**（181回目に足した。**落とす範囲を狭める側の追記**である）。型A10（区分の帰属）で `false` にするのは、**製品の話を事業全体の話として書いたために向きが逆に読める**ときだけ。日本石油輸送の分析が `ＬＮＧは…まだセグメント損失にある` と書いたのは、損失が高圧ガス輸送事業のもので**ＬＮＧ単体の損益は材料に無い**——**ただし向きは合っており、読者が突き合わせて逆に読むことは起きない**ので申告に留めた（主語を `高圧ガス輸送は` に替えれば消える）。

**この節は要約にだけ掛かる**（181回目に絞った）。**分析では、ここに並ぶ形のうち「事実そのものが違う」ものだけを申告する**——`## 分析の判定` の冒頭が言うとおり、申告してよいのは数値の向き・区分の帰属・時点・材料が持たない出来事の存在の4つである。**分析で「言い方が強い」「読者が引っかかる」を理由に直させると、踏み込みが1つずつ削られて要約に戻る**（180回目に実際にそうなっていた）。

**ここに並べるものを増やすときは、`## この規格の育て方` の3つを守ること**——同じ事故の言い換えなら足さない、足すなら効かない場面を併記する、実例が1件なら判例として書いて規則にしない。

- **状態の反転を「まま」で書く**（前期 182億円の営業利益 → 当期 △88億円の損失なのに「赤字のまま」）。**材料が1点しか持たない指標に「まま」を使う**のも同じ
- **状態を一括りにする語**（「どこを見ても悪くない」に対し**純利益だけが △10.6%**）
- **単調性を含意する語**（「上がり続けている」）が推移の形と食い違う。**指している範囲が違えば片方だけが誤りになる**（見出しの10年では誤りでも、本文の直近5年では正しい）
- **見出しだけが本文より一段強いこと**（本文「利益の出る形になったのがごく最近」に対し見出し「利益の出る形にようやく届いた」＝当期に初めて黒字化したと読める。実際は前期も3段階とも黒字）
- **2つある要因の1つを全体の性格として言い直すこと**（減収要因が「連結除外**や官公庁業務の反動減**」なのに「減収の中身は事業の入れ替えによるもの」）
- **材料が逆方向の記述を持つとき**、正面から向き合う書き方（「放送の現場を持たない持株会社」に対し材料は「放送インフラアセットを当社へ移管し」）
- **同じ会社の中で集計単位の違う記述が逆を向くとき**、見出しに単位を書かせる
- **利益段階のずれ**（セグメントの当期利益が「税引前利益を押し上げた」）。向きが合っていれば通すが、**読者が突き合わせられる食い違い**
- **基準年を書かずに「横ばい」**（原文は2022年度実績比なのに読者は前期比と読む）
- **`figures` の指標を、その定義と違う統計として説明する**（中央値を「打ち消し合う」「ならした」と呼ぶ）。**指標の定義を言い換えるときは、その統計が何をしているかまで合わせる**
- **指標の定義を部分的に挙げて、符号の向きが違う項目を「など」に隠す**
- **要約が節をまたいで区分名を補うこと**（セグメント名と船種の対応が4節のどこにも無い）。**辿れることを根拠に通すと分析より緩くなる**
- **セグメント名と製品名を入れ替えること**（**製品の話を事業全体の話として書くと向きが逆に読める**）
- **出来事の成否を断定すること**（「交渉が通った」）
- **子会社が「手がける」と書いて開発主体がずれること**（`sources` が「当社の開発製品」と書いている）
- **調達手段を並べて、充当先が材料と対応していないこと**（「社債と」の1語だけが対応を持たない）
- **材料が扱っていない年について理由を述べること**（「投資の成果が大きかった2023年」——年収は `figures` にあるが、その年の投資の成果は材料に無い）

- **増減の列挙が実態より短いこと。** ある回、エステーの分析が「エアケアとペットケアが**伸びた一方**、衣類ケア、湿気ケア、サーモケアは前期を下回り」と書いたが、**7カテゴリーのうちホームケア +2.7%・ハンドケア +2.9% も増えていた**（同じ回、佐藤商事も営業開発の △1.8% に触れずに「増益となり」を並べていた）。**排他の語（「だけ」「のみ」）が無ければ事実の誤りではない**が、2つ挙げて「一方」で受けると増収が2つに見える。**「など」で開くか、網羅して書く**——**両側に「など」を付けない**ことが要点で、実際に網羅している側に付けると存在しない区分を含意する
- **会社が定義した区分の membership を取り違えている**（型S4。**要約の `false`**。144回目に新設）。東邦瓦斯の要約が `都市ガス・ＬＰＧ・電気の供給をコア事業とし` と書いたが、原文は `都市ガス・ＬＰＧなどのコア事業では…また、戦略事業では、電気事業において…海外事業において…` と2つの括りを分けている。**確かめ方は、その定義語（コア事業／戦略事業のような会社の用語）で4節を検索し、下に挙がっている要素を数えること。** **リスクの節が別の切り方（`主要な事業である都市ガス・ＬＰＧ・電気事業`）を持っていても、切り方をまたいで要素を移さない**——どちらの節を読んでも支持されない文になる。**原文が「など」で開いている括りをそのまま写せば衝突しない**
- **材料が持つ区分の数を減らして断じている**（型S3。**要約の `false`**）。「エラストマー素材と高機能材料の**二つの**事業部門を持つ」——材料の MD&A に「（その他の事業部門）」の見出しが**見えている**。**分析の型A10（区分の取り違え）の裏返しで、取り違えではなく数え落とし。**「主力の」「〜を中心とする」と書けば残余の区分と両立するので、直し方は数の断定を外すだけ。**切れた先に区分があるかは問わない**——見えている範囲に3つ目があるときだけ落とす
- **実額と増減率で向きが割れる形。** ある回、トリドールホールディングスの分析が「事業利益の伸びが**そのまま最終利益に残る形にはなっていない**」と書いた。**実額では真**（事業利益 +3,254百万円に対し当期利益 +437百万円）だが、**増減率では最終利益のほうが伸びている**（+17.9% に対し +23.3%）。**事実の誤りではないので落とさない**が、読者が同じ表の2つの列を突き合わせると逆に読める。**どちらで言っているかを書かせる**（「増えた**額**のほとんどが最終利益には残らず」のように実額を明示する）
  - **区分どうしを「最も大きい」で比べる形にも同じ線を当てる**（135回目）。テイ・エス テックの `地域別では米州の落ち込みが最も大きく` は、**営業利益の減少額では米州が最大、売上収益の減少額では中国が最大**（△4,644 と △14,664百万円）。**同じ表の2列で先頭が入れ替わるときは、指標を名乗らせる**（`営業利益の落ち込みが米州で最も大きく`）
- **計画の目標に触れるとき、どの年度の目標かを書かせる。** ある回、「中期経営計画の最終年度の目標」「2026年度までの中期目標」と年度が読める2社と、「掲げた中期の目標損益」とだけ書いた1社が同じ回に並んだ。**目標値は年度とセットでしか読者が突き合わせられない**——計画名か年度のどちらかを添えれば足りる
- **4節の中で同じ出来事の時点が割れているときに、日付を持たない側を採ること。** ある回、ヤプリの要約が MD&A の逐語（`子会社化…同社が展開する「Yappli MobileOrder」をラインナップに加えた`）で書いたが、**課題の節は同じ製品の提供開始を2026年2月＝期末後と日付で書いていた**。**逐語であることは時点の根拠にならない**——日付を持つ記述のほうを採る。**`false` にはしない**（材料自身が割れており、直し方も「日付のある側の言い方に寄せる」で足りる）
- **業界一般に「求められている」ことを、当社の実施として書くこと**（型④の縁）。原文は
  「技能労働者の処遇改善による担い手確保の推進や…**取り組みが求められている**」なのに、
  要約が「処遇改善を**進め**」と当社の行為にしていた。**同じ一文の中で支持の強さが割れる**
  ことがある（重層下請構造改革のほうはサステナビリティの節に「推進状況」があり当社の話）
- **区分の帰属が材料に無いのに補うこと。** 「持分法適用関連会社であるONE社を**含む製品物流
  セグメント**」——**ONE社がそのセグメントに属するとは4節のどこにも書かれていない**。
  セグメント損益 △2,027億円が経常利益の減少 △1,989億円とほぼ一致することから切った版の中で
  到達できる推論なので通すが、**数値で書かせるほうが安全**
- **材料が1点しか持たない指標に「戻る」を使うこと。** 「工事の利幅が**戻り**」——材料にあるのは
  前期比の売上総利益率の向上だけで、それ以前の水準を持っていない。**「まま」と同じ形の逆向き**

**迷ったら `true`。** **推測が1つ外れることの損は、読者が「AI の分析」として読むぶん小さく、踏み込みが1つ減ることの損のほうが大きい**——**分析が事実の言い直しになれば、要約と2つ持つ意味そのものが消える。**

**この一文は分析にだけ掛かる**（理由づけが分析固有の「踏み込み」だから）。**要約でも、落とすのは列挙された型に当たるときだけ**——列挙に当たらないものを落とすと「規格に無い理由で落とす」ことになり、161回目に止めた形（規格に無い条件を既存の条件の名で付ける）が判定側で再現する。**ただし要約で迷ったものは申告に回す**（申告も書き直させる経路なので、直しは同じだけ起きる）。178回目、検証側が「この一文が要約にも掛かるか読み取れない」と指摘し、境界例2件を申告で返した——**その扱いが正しい。**

## 落ちたら書き直す（上限2回）

**要約と分析は対で出す。片方だけのページを作らない**（spec 1.19・AC-28）。だから `false` を付けたら、そこで終わりにしない——**理由を生成側に返して書き直す。**

**直し方は「材料と合わせる」であって「主張を弱める」ではない。** 落ちるのは数値の向き・幅・時点・区分のどれかなので、**材料の数字に合わせて書き直す**。**主張そのものは残す**——弱めて通せば、落とした意味が消える。

| 落ちた文 | なぜ落ちたか | 直した形 |
| --- | --- | --- |
| 金属資源は前年度を上回った | 2,278 → 2,045 億円と**減っている**（型S1） | 金属資源は前年度を下回った |
| 売上総利益から下はすべて二桁の増益 | 売上総利益は **9.0%増**で二桁でない（型A8） | 営業利益から下はすべて二桁の増益 |
| 当期の新作『真・三國無双 ORIGINS』 | 材料が書いているのは**受賞と追加DLC と移植版だけ**（型A12） | 当期の新作『仁王３』『ゼルダ無双 封印戦記』 |

**2回書き直しても通らなければ、そのまま `false` で出す。** `merge` が**要約も一緒に落とす**（`generate.pair_or_drop`）。**ここで無理に通さないことが、この工程の意味を保っている**——「必ず対にする」を絶対条件にすると、通らない分析を通す圧力がそのまま検証パスに掛かる。

## 報告

`false` の内訳は**型の番号で数える**（要約は `S`、分析は `A`、要約については C6 の型①〜⑪も使う）。**読む側で振り直さない**——振り直すと回をまたいで内訳を比べられなくなる。どの型にも当てはまらないものは「その他」として理由を1行書く。

**`true` にしたが迷った箇所も添える。** 落とすほどではないと判断したもの、既存の型を広げれば当たるもの、基準が定まっていないと感じたものを、社名と該当文を挙げて書く。**判定と申告は別のもので、迷いを `false` に切り上げる必要はない**——`false` は書き直しを起こし、申告は基準を動かす。

**生成側の申告を数えず、実物に当たる。** 「原文にある語で書いた」「文を割った」という報告が実態と食い違ったことが2回ある。**語で検索して確かめる。**

**この規則は検証側の申告にも掛かる。** ある回、「個々の地域を『成長市場』と位置づける記述は無い」と申告したが、**原文（リスクの節）に「中国、インド、東南アジア、ヨーロッパならびに北米を成長市場と位置づけ」と逐語であった**（書き直し側が実物に当たって見つけた）。**落ちる理由が無いものを直させると、そのぶん別の問題が入る**——このときも直しが新しい曖昧さを1つ持ち込んだ。**「原文に無い」と書く前に、必ずその語で検索する。**
  - **検索するのは4節すべて。節を決め打ちしない**（146回目）。ＲＯＸＸ の要約 `年収400万円未満のノンデスクワーカーの人材市場` を「原文の定義に所得の限定は無い」と申告したが、**`年収400万円未満` はリスクの節に逐語で2箇所あった**——課題の節と注記しか見ていなかった。**要約は4節のどこから拾ってもよい**ので、1つの節に無いことは「原文に無い」の根拠にならない。**この回は書き直した後に検証側が自分で見つけて報告し、元の文に戻した**
