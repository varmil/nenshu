# 要約と分析の検証パス（C9・#241）

生成された**要約**と**分析**を、それぞれ別の基準で判定する。

**生成とは別の仕事として読む。** 「読んで自然か」「日本語として良いか」は見ない。
機械ゲート（`gate.py`）が拾えないものをここで止める。

**基準が2つある**（ADR-0015 決定1）。混ぜると、要約に評価が通るか、分析が事実の写しに
なるかのどちらかが起きる。

| | 要約 | 分析 |
| --- | --- | --- |
| 判定 | 「4節の原文に**書いてあるか**」 | 「渡した材料から**導けるか**」 |
| 材料 | `sections` の4節だけ | 4節＋`figures`＋**`sources` の URL の中身** |
| 評価語 | あれば `false` | **あって当然。それだけでは `false` にしない** |

## 入力

`work/gated_NNNN.json`。`companies[]` の各要素が1社で、`edinet_code` / `name` /
`summary` / `headline` / `analysis` / `sources` / `sections`（4節の**切った版**）を持つ。

**渡してあるのは、生成が見たのとまったく同じ材料である**（節ごとに MD&A 2,200字 /
リスク 1,500字 / 課題 3,000字 / サステナビリティ 1,500字で切ってある）。**だから
「切った先にあるから正しい」は成り立たない**——生成が持っていない位置にある事実を
根拠にして通すと、材料の外から採ったものを見逃すことになる。

**原文の全文を自分で引きに行かない。** `pipeline/data/analysis_text_2026.csv` を開けば
全文は読めるが、**それは生成が見ていない材料で、そこを根拠に通しても落としても
判定の意味が変わる**（32回目に、`gate` が全文を渡していたバグをこの形で見つけた）。

## 出力

`work/verify_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json
{"edinet_code": "E02181",
 "summary_supported": true,  "summary_reason": "",
 "analysis_supported": false, "analysis_reason": "撤退した事業を現在形で書いている",
 "types": ["A2"]}
```

`false` のときは `reason` に**食い違う箇所を1つ**書く（20字程度）。

## 要約の判定

**各文について、4節のどれかがその内容を述べているかを見る。1文でも支持されなければ
`false`。**

`false` にするもの。

- 原文に無い事実を述べている
- 原文と逆のことを述べている
- 原文が触れていない範囲に広げている
- **評価になっている**（「収益性が高い」「強みを持つ」）
- **撤退した事業を現在形で書いている**（C6 の型①。これだけは先に確かめる）
- **有報の記載作法の説明を写している**（「報告セグメントは……で区分している」。C6 の型⑪）

`true` にしてよいもの。

- 原文の言い換え・要約・順序の入れ替え
- 4節のうち一部だけを取り上げること
- 「当社」「当社グループ」を主語なしで書き直すこと
- **社名・子会社名・ブランド名を書くこと**（50回目に禁止を外した。原文にある呼び方に限る）

**要約は4節のどこから拾ってもよい。節の帰属は問わない**（作り直しの2回目に線を決めた）。
三井不動産の「リスクとしては…建築費の高騰…を挙げる」は、建築費の高騰が書かれているのが
リスクの節ではなく課題の節（経営環境）だった。**要約は4節をまとめて読むものなので、
原文のどこかにあれば通す**——**分析では型A16（区分をまたいで出来事を移した）が生きている**
ので、そちらは節と区分を見る。

**要約では、原文にない因果を接続詞で作らない**（50回目の作り直しで踏んだ）。三井物産の
「既存鉱山の品位低下や埋蔵量の減少が進む**ため**、高品位資源やリサイクル由来の原料への需要が
高まる」——原文が高品位資源の需要増の理由に置いているのは**社会の持続可能性追求**で、
品位低下が導いているのは**需給の逼迫**である。**2つの事実が両方とも原文にあっても、
繋ぎ方が原文と違えば要約としては誤り**（分析では因果を作ってよいので、ここが2つの規格の
分かれ目になる）。

## 分析の判定

**見るのは「事実の誤りが無いか」だけである**（ADR-0016・50回目に線を引き直した）。

**推測は落とさない。** 因果・評価・見通し・重み付け・比較・含意は**このセクションの
本体**であって、材料が明示していなくても**そう読めるなら通す**。**言い過ぎを落とすのを
やめた**——50回まわした結果、それが分析を要約と大差ないものにしていた。

`false` にするもの。**この6つだけ。**

| 型 | 落とすもの |
| --- | --- |
| **S1・A5** | **数値の向きが逆**（2,278 → 2,045 億円と減っているのに「上回った」） |
| **A8** | **数値の幅が食い違う**（9.0%増を「二桁の増益」、71.9%増を「7割近く」） |
| **A12** | **出来事の時点が違う**（翌期の発売を当期の新作として書く。日付が出てこない形もある） |
| **A10・A14・A16・型④** | **区分が違う**（セグメントの損益をその中の事業名で呼ぶ／別の節の出来事を移す） |
| **A3** | **材料の外の属性を事実として足した**（原文に無い工場・製品・資本関係。**数値を記憶から書いたものもここ**） |
| **A3** | **材料に出てこない過去の出来事を持ち出して当期の増減を説明した**（6回目に足した。下記） |
| **A13** | **改善要因を悪化の中身として並べた** |

**「材料に出てこない過去の出来事」を型A3 に足した理由**（6回目・ＧＭＯ）。「イニシャル売上が
**前期の大口案件の反動**で落ちる」——「反動」は材料に0件、「大口」はリスク節の**仮定形**
（「大口の販売計画を見直す必要が生じた場合には」）だけ。**ADR-0016 が解いた旧・型A2 は
「AがBを起こしている」という関係の推測**だが、ここで足されているのは**「前期に大口案件が
存在した」という出来事の存在**で、形が違う。**因果の推測なら読者は「そう読めるか」を自分で
判定できるが、出来事の存在は材料に当たっても無かったことを確かめられない。** 型A12
（出来事の時点が違う）が守っているものと同じ性質である。

**この6つは推測ではなく誤りである。** 読者が材料に当たれば違うと分かり、「そう読める」の
余地が無い。

**`false` にしないもの。** 以下はすべて **50回目までは落としていたが、いまは通す。**

- **材料が述べていない因果**（旧・型A2）。「労務費と資材価格の高騰が利益を削っている」
- **内訳の無い切り分け**（旧・型A1）。「会計処理の変更を差し引いても縮小は続いている」
- **材料が並べているものへの重み付け**（旧・型A15）。会社が4つ並べていても、
  求職者にとって効くのがどれかを言ってよい
- **1期の増減から述べた趨勢**（旧・型A7）・**材料が持っていない比較**（旧・型A11）・
  **材料の外から持ち込んだ評価の基準**（旧・型A17）
- **減収の要因を減益にも掛けること**（旧・型A18）・**並列に包含関係を作ること**（旧・型A19）
- **材料が書いていないことを「無い」と述べること**（旧・型A6）
- **評価語があること・断定的であること**（それが本体）
- **業界の文脈や一般的な知識**（ADR-0016 決定3 で解いた）。**ただし数値だけは材料に
  あるものに限る**ので、金額・率・順位・シェア・従業員数が材料のどこにも無ければ
  **型A3 として落とす**
- **材料が薄く、分析も薄いこと**（薄いまま書くのは正しい振る舞い）

**`sources` の URL は引き続き確かめる。** ただし落とすのは**分析が URL を根拠に述べたことが、
その URL に無いとき**だけ（型A3 扱い）。開けない・別の会社を指しているのも同じ。

- **URL が無いこと自体は落とさない**——記憶から書いてよくなったので、出典の無い主張があってよい
- **挙げたのに使っていないのも落とさない**（50回目の作り直し1回目で2社に出た）。害が無く、
  **取りに行ったこと自体は記録として正しい**。ただし生成の側では、**使わなかった URL は
  挙げない**ほうが読者に対して素直である
- **URL が主張を部分的にしか支持しない形も通す**（ネクソンの採用ページにはデザイナーの募集も
  並ぶので「届ける側の会社である」は一面的、Ｍ＆Ａキャピタルパートナーズには最低保証年収が
  あるので「出なければ返らない」も一面的）。**一面的であることは推測の当否であって、
  事実の誤りではない**

**線が決まっていないもの**（50回目の検証パスが申告してきた。**出たときは通し、ここに足す**）。

- **単調性を含意する語**（「崩れることなく」「一貫して」「上がり続けている」）。日本政策金融
  公庫の平均年収は10年で +10.5% だが、2021→2022 に 5% 下がった年がある。**大崩れが無い意味
  なら通し、単調上昇と読ませているなら型A8。** 幅ではなく形の話なので、いまは通す
- **材料が同じことについて複数の系列を持つとき、どれを指しているかを明示していれば通す。**
  三井不動産の空室率は、**本文が数値で名指ししているのは首都圏オフィス（単体）の 1.6%（上昇）**
  で、表にしか出てこない**オフィス・商業施設（連結）は 3.5→3.0（改善）**と向きが逆になる。
  分析が「連結で」と明示していれば事実として正しいので通す。**明示せずに都合の良い側だけを
  述べていれば、読者はどちらか分からないまま良い向きを受け取る**ので、そこは書き直させる
  （この回は明示させて直した）
- **丸めた比率の境目は「9割」で決めた**（10回目に1つの数字に固定した。検証パスの提案）。
  **下から近づく言い方は、丸めた数に対して実測が9割以上なら通す。** 実測が並んだのは——
  ネクソン「3倍近い」2.73倍＝**91.0%**（通した）、電源開発「4割近く」36.7%＝**91.8%**（通した）、
  大気社「3割近く」26.8%＝**89.3%**（直させた）、大気社「倍に迫る」1.75倍＝**87.5%**（直させた）、
  メルカリ「2割近く」16.6%＝**83.0%**（直させた）。**上から近づく言い方は誤差1ポイント台まで**
  （メルカリ「1割半ば」16.6%）。**回をまたいで揺れないことのほうが、境目を厳密に定めることより
  大事**——0.7ポイント足りない例（大気社）が実際に出た
- **`sources` の URL が主張を部分的にしか支持しない形。** ネクソンの採用ページには
  デザイナーやエンジニアの募集も並ぶので「作る側ではなく届ける側の会社である」は一面的、
  日本製鉄のキャリアページは「異動パターンはあくまでも一例」と断っている。
  **挙げた事実が実在すれば通す**（一面的であることは推測の当否であって、事実の誤りではない）

- **材料が扱っていない年について理由を述べること。** ドリームインキュベータの「投資の成果が
  大きかった2023年に一度跳ね上がり」——年収の数値は `figures` にあるが、**その年に投資の成果が
  大きかったという事実は材料のどこにも無い**（材料は当期と前期だけ）。因果を作ってよい以上
  通すが、**因果一般と違って、時点そのものが材料の外にある**。**数値が `figures` と合っている
  うちは通す**（外れれば型A3・時点が違えば型A12）
- **利益段階のずれ。** 東京海上の「セグメントの当期利益が**税引前利益**を押し上げた」——
  セグメントの数字は「親会社の所有者に帰属する当期利益」で、押し上げた先として挙げた指標が
  1段ずれている。**型A10・A14 はセグメント区分を指しているので当たらないが、読者が突き合わせ
  られる形の食い違いではある**（この回は書き直させた）。**向きが合っていれば通し、申告する**
- **持株会社という語。** 電通・東京海上の要約は「グループの持株会社である」と書いたが、
  **4節に「持株会社」の語は無い**（実測0件）。材料が 当社／当社グループ を区別し、事業を担う
  会社を実名で並べているので**構造の言い直しとして通す**。社名に「ホールディングス」「グループ」
  が入る会社では毎回出る
- **要約が節をまたいで区分名を補うこと。** 川崎汽船の「自動車船やコンテナ船を含む製品物流」は、
  セグメント名と船種の対応が**4節のどこにも書かれていない**（消去法と金額では辿れて事実として
  正しい）。**分析の型A16 と対になる要約側の線で、まだ決まっていない**。この回は対応関係を
  外させた——**要約の基準は「原文に書いてあるか」なので、辿れることを根拠に通すと分析より
  緩くなる**

- **「単一セグメントである」を要約に書くこと**（5回目に GLM とライズの両方で出た）。原文は
  「不動産ソリューション事業の単一セグメントであるため、セグメント別の記載を省略しております」
  で、**要約が写しているのは事業構成の事実だけ**（記載を省く旨は落としている）。**C6 の型⑪
  （記載作法の説明を写す）に隣接するが、当たらない**とみて通す。**「省略しております」まで
  写せば型⑪**
- **数を語で丸めること。** ライズの「売上の上位**数社**への偏り」——原文は「取引額上位**10社**の
  合計販売比率63.1%」で、「数社」は通常3〜5社を指す。**数値表現ではないので型A8 には当たらない
  が、幅の食い違いに近い**（この回は原文の数字に直させた）
- **区分のうち1つだけ材料が増減を書いていないとき。** 野村の「**四つの部門がそろって**収益を
  伸ばし」——3部門は前期比が明示だが、ホールセールだけ「高い収益水準を実現し」で増減が無い。
  **向きが逆になる材料が無いなら推測として通す**（旧・型A6 は廃止した）

- **一人当たり利益の分母と分子の範囲がずれること。** ＧＭＯの「従業員100人あまりで…連結の
  売上と利益」——106人は**提出会社（単体）**の従業員数で、語っている売上・利益は**連結**である。
  `figures` がそう渡しているので**レーダーの「稼ぐ力」を語る会社では毎回出る**。ADR-0016 の
  6種のどれにも当たらないので通す
- **「最も高い」と「並んでいる」の間。** ジャフコの2026年は 13,656,206 円で、最高の2023年
  （13,659,476円）と**差 3,270円（0.02%）**。「最も高い」と書けば誤りだが「並んでいる」なら
  通る。**丸めた比率の境目と同じ扱い**

- **分析が画面の作りそのものを説明すること**（7回目・三井住友トラスト。5回目の野村が最初）。
  「ここが持株会社だという点で、**画面に出ている平均年収も在籍年数も**中核子会社ではなく
  この会社に籍を置く社員のものである」——**4節に「持株会社」の語は無く、「有報の平均年間給与は
  提出会社（単体）ベース」も材料の外の一般知識**である。**通す**——持株会社の年収を事業会社の
  水準と誤読することは求職者にとって実害があり、`figures.employees`（194人）がその根拠を
  渡している。**通してよいのは「画面の数値をどう読むか」まで**で、**我々の側を主語にした形**
  （「当サイトでは提出会社ベースで表示している」）**が出たら書き直させる**——実装の説明は
  分析ではなく `/about` と C10 の断りの仕事で、役割が重なる
- **述語が切れた文を根拠にすること**（7回目・メルカリ）。issues 節が「あわせて、『メルカリ
  モバイル』や『メルカリNFT』等の」で途切れている。**見るのは「枠が読めるか」ではなく
  「切れた先を推測して補っていないか」**（再検証の申告で線を立て直した）——「取り組んでいる」
  なら補っていないので通し、「提供を開始した」「等のサービスを拡大した」なら補っているので
  落とす。**切れ目に掛かった文を一律に捨てない**——切った版で書く前提のもとでは、節の末尾が
  毎回失われることのほうが損が大きい。**分析なら URL を取りに行けば切れ目の問題そのものが
  消える**（メルカリの分析側は `sources` を根拠にしていて切れ目と無関係だった）
- **「2割近く」の下限。** メルカリの US は実測 **△16.6%** で、2割に対して 83%。ネクソンの
  「3倍近い」（2.73倍＝91%）より開きが大きい。**この回は「1割半ば」に直させた**——
  **下から近づく言い方でも、9割を切ると別の数を指しているように読める**
- **「報告セグメントは」で始めること**（7回目・東京エレクトロン）。「単一セグメントである」
  自体は5回目に通すと決めたが、**「報告セグメントは……である」は C6 の型⑪の例示
  （「報告セグメントは……で区分している」）とほぼ同じ形**になる。**この回は「事業は……の
  単一セグメントである」に直させた**——**主語を「報告セグメント」にすると開示の話に寄る**

- **上から近づく言い方の許容幅。** 書いてあるのは「**下から**近づく言い方が実測と同じ側なら
  通す」だけで、上からは決めていない。メルカリの US は実測 △16.6% で、「2割近く」（83%）は
  落とし「1割半ば」（上振れ1ポイント強）は通した。**誤差1ポイント台なら通す**
- **節をまたいで主体を合成すること**（7回目・メルカリ。川崎汽船の「区分名を補う」と同じ未決の
  線）。issues の「スマホ決済サービス『メルペイ』で提供するCreditサービスにおいて」は主体が
  当社グループだが、要約は risks の「**株式会社メルペイでは**……『メルペイ』……を提供」と
  合わせて「株式会社メルペイは……与信を行う」と書いた。**別の節に主体が書いてあるなら通す**
  ——ただし**サービス名から会社名へ寄せる形は型④の縮小版**で、子会社名が並ぶ要約では
  滑りやすい

- **状態の反転を「まま」で書くこと**（8回目・フジ・メディア）。「本業は赤字の**まま**で」——
  連結の営業損益は前期 18,293百万円の**利益**から当期 △8,766百万円の**損失へ転落**しており、
  「まま」は継続を含意する。**既存の単調性の例（「一貫して」「上がり続けている」）は幅の話**
  だが、これは**状態そのものが反転している**。この回は「営業赤字に転じ」に直させた。
  **同じ回の兼松は「残業を月ひと桁に収めた**まま**」で、`worklife` が 2025年3月時点の1点しか
  持たない**——反する記述が材料に無い点はフジと違うが、**1点しか無い指標に継続を含意させる
  形**なので同じく直させた（「残業は月ひと桁で」）
- **社名から自明な系列関係。** 豊田通商の「**トヨタ系**の看板で稼ぎながら」——トヨタとの資本
  関係は4節に一切無い（社名と㈱アイシンとの合弁だけ）。**型A3 の例示に「資本関係」が挙がって
  いる**が、**社名から自明で数値でもないので ADR-0016 決定3 の一般知識として通す**
- **材料が逆方向の記述を持つとき。** フジの「**放送の現場を持たない**持株会社」——issues 節は
  「フジテレビが保有する放送用設備等の放送インフラアセットを**当社へ移管**し」と書いている。
  移管されるのはハードで制作・放送の実務ではないと読めば通るが、**材料に当たった読者が緊張を
  感じる**。この回は「放送を担うのが子会社である持株会社」に直させた——**事実の誤りではないが、
  材料の一文と正面から向き合う書き方は避ける**

- **`figures` の指標を、その定義と違う統計として説明すること**（9回目・ソフトバンクグループ）。
  「直近5期の中央値で見れば、**損失の年が黒字の年を打ち消す**振れ方をしている」——**中央値は
  打ち消し合う統計ではない**（打ち消すのは平均）。事実の誤りとまでは言えないので通したが、
  **指標の定義そのものを言い換えるときは、その統計が何をしているかまで合わせる**
- **基準年を書かずに「横ばい」と述べること**（9回目・SMFG）。原文が言っているのは
  **2022年度実績比**の横ばいで前期比ではないが、分析が基準を書かないと読者は前期比と読む。
  **向きは正しいので型A12 には当たらない**が、「材料が同じことについて複数の基準を持つときは
  どれを指しているか明示する」（三井不動産の空室率）の親戚である。**1語入れるだけで解消する**
- **子会社が「手がける」と書くとき、開発主体がずれることがある**（9回目・ダイダン）。
  `sources` は「**当社の**開発製品」と書いており、子会社が担うのは販売とコンサルティング
  だった。**「扱う」なら通る**

- **`sources` の URL が期末後の材料であること**（9回目・大成建設）。「T-iDRIVE X」「T-BasisX」の
  リリースは 2026年8月31日・7月27日で、**当期末（2026年3月31日）より後**である。分析は
  「手を広げている」と**現在の取り組み**として書いており当期の出来事にしていないので型A12 には
  当たらない。**要約・分析の他の記述が当期のものである中に期末後の材料が混ざる**形は、
  外部の文書を使う以上いつでも起きる——**時点を当期に寄せて書いていなければ通す**
- **調達手段を並べるとき、充当先が材料と対応しているか**（9回目・ソフトバンクグループ）。
  「**社債と**ブリッジローンを重ねて OpenAI への追加出資に充てている」——ブリッジローンの
  充当先は明示されているが、**社債は満期償還・借り換えとブリッジローン返済への充当**として
  書かれている。**1語だけが材料の対応を持たない**形なので落とした

- **定義の中で符号の向きが違う項目を「など」で束ねること**（10回目・双日）。基礎的収益力の
  定義は「売上総利益＋販管費＋金利収支＋受取配当金＋持分法投資損益」だが、「売上総利益と
  持分法投資損益**など**からなる」と書くと**販管費（マイナス寄与）と金利収支が「など」に
  隠れる**。**読者が突き合わせたときに引っかかる**ので「会社が定義する」に寄せた——
  **指標の定義を部分的に挙げるなら、符号の向きが揃っているものだけにする**

- **処分や事案ごとに主体が違うのに束ねること**（11回目・ＳＯＭＰＯ。**型④の縮小版**）。
  原文は「自動車保険金不正請求は**当社および損保ジャパン**」「保険契約情報等の不適切な管理は
  **損保ジャパン**」と分けているが、要約が2つを並べて両社に掛けると**読者は持株会社も情報管理の
  処分を受けたと読む**。原文自身が列挙のあと「（両者が）業務改善計画に取り組んでおります」と
  束ねているので通したが、この回は主体ごとに書き分けさせた
- **セグメント名と製品名を入れ替えること**（11回目・朝日工業社）。「**機器製造販売事業の主要
  製品である**精密環境制御機器は…受注が回復した」——回復したのは**ＦＰＤ製造装置向け製品**で、
  **機器事業の受注高そのものは △26.3%**。原因（中国パネルメーカーの需要増加）が FPD の記述と
  一対一なので誤りではないが、**製品名を事業の代表として置くと向きが逆に読める**
- **出来事の成否を断定すること**（11回目・朝日工業社）。「発注者との請負金額の**交渉が通った**
  ぶん利幅も厚くなった」——交渉の取り組みは risks 節にあるが「通った」は材料に無く、
  営業利益 +61.2% からの推測である。**因果は作ってよいが、出来事の成否を事実として書くと
  型A3 の「出来事の存在」に近づく**
- **「若い会社」を在籍年数だけから言うこと**（11回目・パワーエックス）。設立年も上場年も4節に
  無く、根拠は `figures.avg_tenure_years` 1.8年だけ。**数値でも属性でもないので通す**が、
  **在籍年数が短い理由は転籍・出向など他にもありうる**（ソニーFG の「人の層はこれから厚くなる
  段階」も同じ形）

**迷ったら `true`。** 50回目に向きが変わった。**推測が1つ外れることの損は、読者が
「AI の分析」として読むぶん小さく、踏み込みが1つ減ることの損のほうが大きい**——
**分析が事実の言い直しになれば、要約と2つ持つ意味そのものが消える。**

## 落ちたら書き直す（上限2回）

**要約と分析は対で出す。片方だけのページを作らない**（spec 1.19・AC-28）。だから
`false` を付けたら、そこで終わりにしない——**理由を生成側に返して書き直す。**

**直し方は「材料と合わせる」であって「主張を弱める」ではない**（50回目に改めた）。
落ちるのは数値の向き・幅・時点・区分のどれかなので、**材料の数字に合わせて書き直す**。
**主張そのものは残す**——弱めて通せば、落とした意味が消える。

| 落ちた文 | なぜ落ちたか | 直した形 |
| --- | --- | --- |
| 金属資源は前年度を上回った | 2,278 → 2,045 億円と**減っている**（型S1） | 金属資源は前年度を下回った |
| 売上総利益から下はすべて二桁の増益 | 売上総利益は **9.0%増**で二桁でない（型A8） | 営業利益から下はすべて二桁の増益 |
| 当期の新作『真・三國無双 ORIGINS』 | 材料が書いているのは**受賞と追加DLC と移植版だけ**（型A12） | 当期の新作『仁王３』『ゼルダ無双 封印戦記』 |

**2回書き直しても通らなければ、そのまま `false` で出す。** `merge` が**要約も一緒に落とす**
（`generate.pair_or_drop`）。**ここで無理に通さないことが、この工程の意味を保っている**
——「必ず対にする」を絶対条件にすると、通らない分析を通す圧力がそのまま検証パスに掛かる。

## 報告

`false` の内訳は、`prompts/generate.md` の**型の番号で数える**（要約は `S`、分析は `A`、
要約については C6 の型①〜⑪もそのまま使う）。**番号はあちらが持っているので、読む側で
振り直さない**——振り直すと回をまたいで内訳を比べられなくなる（C6 で3人が別々の番号を
振って食い違った）。どの型にも当てはまらないものは「その他」として理由を1行書く。

**新しい型を見つけたら、番号ではなく「その他」で報告して中身を書く。** 番号を振るのは
`generate.md` を直すときで、そこで初めて次の回に効く。

**`true` にしたが迷った箇所も添える。** 落とすほどではないと判断したもの、既存の型を
広げれば当たるもの、基準が定まっていないと感じたものを、社名と該当文を挙げて書く。
**48回目はこの申告が型A18・A19 を立てるきっかけになり、49回目は申告8件のうち3件が
実際に直すべきものだった**（要約に無い段階利益を分析が束ねていた／要約が表の別の列を
拾っていた／限定が落ちていた）。**判定と申告は別のもので、迷いを `false` に切り上げる
必要はない**——`false` は書き直しを起こし、申告は基準を動かす。
