# 要約と分析の検証パス（C9・#241）

生成された**要約**と**分析**を、それぞれ別の基準で判定する。

**生成とは別の仕事として読む。** 「読んで自然か」「日本語として良いか」は見ない。機械ゲート（`gate.py`）が拾えないものをここで止める。

**この文書だけを読めばよい。** ADR-0015・ADR-0016 の決定は下に取り込んである。型の番号は `prompts/generate.md` が持っているが、報告に必要な番号は下の表にある。

**基準が2つある。** 混ぜると、要約に評価が通るか、分析が事実の写しになるかのどちらかが起きる。

| | 要約 | 分析 |
| --- | --- | --- |
| 判定 | 「4節の原文に**書いてあるか**」 | 「渡した材料から**導けるか**」 |
| 材料 | `sections` の4節だけ | 4節＋`figures`＋**`sources` の URL の中身** |
| 評価語 | あれば `false` | **あって当然。それだけでは `false` にしない** |

## 入力

`work/gated_NNNN.json`。`companies[]` の各要素が1社で、`edinet_code` / `name` / `summary` / `headline` / `analysis` / `sources` / `sections`（4節の**切った版**）を持つ。

**渡してあるのは、生成が見たのとまったく同じ材料である**（節ごとに MD&A 2,200字 / リスク 1,500字 / 課題 3,000字 / サステナビリティ 1,500字で切ってある）。**だから「切った先にあるから正しい」は成り立たない**——生成が持っていない位置にある事実を根拠にして通すと、材料の外から採ったものを見逃す。

**`pipeline/data/analysis_text_2026.csv`（切らない版）を絶対に開かない。** そこは生成が見ていない材料で、根拠に使うと判定の意味が変わる。

## 出力

`work/verify_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json
{"edinet_code": "E02181",
 "summary_supported": true,  "summary_reason": "",
 "analysis_supported": false, "analysis_reason": "撤退した事業を現在形で書いている",
 "types": ["A12"]}
```

`false` のときは `reason` に**食い違う箇所を1つ**書く（20字程度）。

## 要約の判定

**各文について、4節のどれかがその内容を述べているかを見る。1文でも支持されなければ `false`。**

`false` にするもの。

- 原文に無い事実を述べている（**記憶からの補完もここ**。「起こした電気を電力会社などに販売する」——4節に販売先が0件だった）
- 原文と逆のことを述べている
- 原文が触れていない範囲に広げている
- **評価になっている**（「収益性が高い」「強みを持つ」）
- **撤退した事業を現在形で書いている**（C6 の型①。これだけは先に確かめる）
- **有報の記載作法の説明を写している**（「報告セグメントは……で区分している」。C6 の型⑪）
- **主語が滑っている**（型④）。原文の主体が当社グループなのに、前文の子会社名が引き継がれて読める形。**処分や事案ごとに主体が違うのに束ねた形**も同じ

`true` にしてよいもの。

- 原文の言い換え・要約・順序の入れ替え／4節のうち一部だけを取り上げること
- 「当社」「当社グループ」を主語なしで書き直すこと
- **社名・子会社名・ブランド名を書くこと**（原文にある呼び方に限る）
- **4節のどこから拾ってもよい。節の帰属は問わない**（分析では型A16 が生きているので、そちらは節と区分を見る）
- **「単一セグメントである」**（事業構成の事実。ただし「記載を省略している」まで写せば型⑪、主語を「報告セグメント」にすれば開示の話に寄る）
- **「持株会社である」**（4節に語が無くても、当社／当社グループの区別と事業会社の実名から構造の言い直しとして通す）
- **別の節に主体が書いてあれば、節をまたいで主体を合成すること**
- **述語が切れた文を根拠にすること**——見るのは「枠が読めるか」ではなく**「切れた先を推測して補っていないか」**。「取り組んでいる」なら通し、「提供を開始した」なら落とす

**原文にない因果を接続詞で作らない。** 「品位低下や埋蔵量の減少が進む**ため**、高品位資源への需要が高まる」——原文が需要増の理由に置いているのは社会の持続可能性追求で、品位低下が導いているのは需給の逼迫だった。**2つの事実が両方とも原文にあっても、繋ぎ方が原文と違えば要約としては誤り**（分析では因果を作ってよいので、ここが2つの規格の分かれ目）。

## 分析の判定

**見るのは「事実の誤りが無いか」だけである**（ADR-0016）。

**推測は落とさない。** 因果・評価・見通し・重み付け・比較・含意は**このセクションの本体**であって、材料が明示していなくても**そう読めるなら通す**。**言い過ぎを落とすのをやめた**——50回まわした結果、それが分析を要約と大差ないものにしていた。

`false` にするもの。**この6つだけ。**

| 型 | 落とすもの |
| --- | --- |
| **S1・A5** | **数値の向きが逆**（2,278 → 2,045 億円と減っているのに「上回った」） |
| **A8** | **数値の幅が食い違う**（9.0%増を「二桁の増益」、71.9%増を「7割近く」） |
| **A12** | **出来事の時点が違う**（翌期の発売を当期の新作として書く。日付が出てこない形もある） |
| **A10・A14・A16・型④** | **区分が違う**（セグメントの損益をその中の事業名で呼ぶ／別の節の出来事を移す） |
| **A3** | **材料の外の属性・出来事を事実として足した**（原文に無い工場・製品・資本関係。**数値を記憶から書いたもの**と、**材料に出てこない過去の出来事を持ち出して当期の増減を説明したもの**もここ） |
| **A13** | **改善要因を悪化の中身として並べた** |

**この6つは推測ではなく誤りである。** 読者が材料に当たれば違うと分かり、「そう読める」の余地が無い。

**「材料に出てこない過去の出来事」が型A3 に入る理由**——ADR-0016 が解いた旧・型A2 は「AがBを起こしている」という**関係**の推測だが、「前期に大口案件があった」は**出来事の存在**で形が違う。**因果の推測なら読者は「そう読めるか」を自分で判定できるが、出来事の存在は材料に当たっても無かったことを確かめられない。**

**`false` にしないもの。** 以下はすべて **ADR-0016 で通す側になった。**

- **材料が述べていない因果**（旧A2）・**内訳の無い切り分け**（旧A1）・**重み付け**（旧A15）
- **1期の増減から述べた趨勢**（旧A7）・**材料が持っていない比較**（旧A11）・**外から持ち込んだ評価の基準**（旧A17）
- **減収の要因を減益にも掛けること**（旧A18）・**並列に包含関係を作ること**（旧A19）・**材料が書いていないことを「無い」と述べること**（旧A6）
- **評価語があること・断定的であること**（それが本体）
- **業界の文脈や一般的な知識**（ADR-0016 決定3）。**ただし数値だけは材料にあるものに限る**ので、金額・率・順位・シェア・従業員数が材料のどこにも無ければ**型A3 として落とす**
- **材料が薄く、分析も薄いこと**（薄いまま書くのは正しい振る舞い）

**`sources` の URL は確かめる。** 落とすのは**分析が URL を根拠に述べたことがその URL に無いとき**だけ（型A3 扱い）。開けない・別の会社を指しているのも同じ。

- **URL が無いこと自体は落とさない**（記憶から文脈は書いてよい）
- **挙げたのに使っていないのも落とさない**（ただし生成側では挙げないほうが素直）
- **URL が主張を部分的にしか支持しない形も通す**——**一面的であることは推測の当否であって、事実の誤りではない**
- **URL が期末後の材料でも、時点を当期に寄せて書いていなければ通す**

## 通す判断の線（決着済み）

**丸めた比率**——**下から近づく言い方は、丸めた数に対して実測が9割以上なら通す。「◯に届かず」型にも同じ線を当てる。** 上から近づく言い方は誤差1ポイント台まで。**丸めの「〜ほど」は最も近い数に付くなら通す**（42.5% を「4割ほど」）。

**この2つを取り違えた申告が3回出ている。表で持つこと。**

| 言い方 | 例 | 当てる線 |
| --- | --- | --- |
| 下から近づく（`◯割近く` `◯に届かず` `◯を下回る程度`） | `月10時間に届かない`（実測8.4＝84.0%） | **丸めた数の9割以上**。84.0% は**落ちる** |
| 丸め（`◯割ほど` `およそ◯割`） | `2割ほど上がり`（実測+17.85%） | **最も近い丸い数に付くなら通す**。2割との距離2.15 < 1割との距離7.85 なので**通る** |
| 上から近づく（`◯割余り` **`◯割強`** `ほぼ◯割`） | `2割余り`（実測20.8%） | 誤差1ポイント台まで |

**同じ回の同じ文に両方が並ぶことがある**（`平均年収はこの10年で2割ほど上がり、残業時間も月10時間に届かない`）——**片方に当てた線をもう片方に持ち越さない**。

**`◯割強` はこの行に入る。** 実測 +13.75% を「1割強」（3.75ポイント外れ）、+32.8% を「3割強」（2.8ポイント外れ）と書いた例が同じ回に2つ出た。**どちらも丸めの「〜ほど」なら通る**（13.75% は1割、32.8% は3割が最も近い）ので、**言い方を替えるだけで解ける**。

**`◯を超える` はこの行に入らない。`◯割を超え` も `◯倍を超える` も下限の言明**なので、**実測がその数を超えていれば真**（`2割を超えて`／実測22.6%＝通る）。表の3行目が掛かるのは**その数に近いことを含意する語**だけ——`◯割余り`・`◯割強`・`ほぼ◯割`。**「超える」と「余り／強」を同じ行に置いていたため、同じ回に両方の判定が出て衝突した**（107回目）。

**倍率の `◯倍を超える` に「誤差1ポイント台」を当てない。** 3行目の線が掛かるのは**その数に近いことを含意する語**（`◯割余り`・`ほぼ◯割`）で、`◯倍を超える` は**下限の言明**だから、実測がその数を超えていれば真である（`業種中央値の倍を超える`／実測2.24倍＝**通る**）。**「2倍を超える」のほうが近い、は落とす理由にならない**——より近い言い方があることと、書いてある言明が偽であることは別。

| 表現 | 実測 | 比 | 判定 |
| --- | --- | --- | --- |
| 「3倍近い」 | 2.73倍 | 91.0% | 通す |
| 「4割近く」 | 36.7% | 91.8% | 通す |
| 「3割近く」 | 26.8% | 89.3% | 落とす |
| 「倍に迫る」 | 1.75倍 | 87.5% | 落とす |
| 「2割近く」 | 16.6% | 83.0% | 落とす |
| 「半分に届かず」 | 42.5% | 85.0% | 落とす |

そのほか決着したもの。

- **数を語で丸めること**（「上位10社」を「上位数社」）は型A8 に当たらないが**幅の食い違いに近い**ので直させる
- **「最も高い」と「並んでいる」の間**——差 0.02% なら「並んでいる」で通す
- **一人当たり利益の分母と分子の範囲がずれること**（`employees` は単体、`profit_per_employee_yen` は連結の利益ベース）は**通す**——`figures` がその2つを渡しており、同じページのレーダーも同じ掛け算をしている。**落とすと `figures` を使うほど落ちる圧力が掛かる**ので、線は生成側に引いた
- **指標に触れていないことを申告する前に、`pipeline/data/performance_history.csv` の `oi_basis` を読む。** ある回、「業種中央値を0.50倍で下回るのに書いていない＝下回る側だけ避けている」と申告したが、**その社は直近5期のうち1期が `nonconsolidated` で基準が混ざっており、見送りが正しかった**。**値だけで申告しない**——基準は確かめられる
- **分析が画面の作りを説明すること**は**「画面の数値をどう読むか」まで通す**（持株会社の年収を事業会社の水準と誤読するのは実害）。**我々の側を主語にした形**（「当サイトでは提出会社ベースで表示している」）**は書き直させる**——実装の説明は `/about` と C10 の断りの仕事
- **社名から自明な系列関係**（「トヨタ系」）は**数値でないので通す**
- **区分のうち1つだけ材料が増減を書いていないとき**、**逆を指す数値も記述も無いなら束ねてよい**
- **為替中立と報告ベースで向きが逆になるとき**、**原文が主系列を明らかにしていれば明示は要らない**
- **「若い会社」を在籍年数だけから言うこと**は通す（数値でも属性でもない）
- **`profit_per_employee_yen` が業種中央値を下回ることは、指標を避ける理由にならない。** 触れないでよいのは**分子と分母の基準が食い違う**とき——`performance_history.csv` の `oi_basis` が `nonconsolidated`（単体の経常利益）なのに分母が連結の従業員数、という組み合わせ——**だけ**。**判定は値ではなく基準で行う**：この型では値が中央値の 0.6 倍でも 3 倍でも指標として意味をなさず、逆に基準がそろっていれば 0.3 倍でも書いてよい。**「5期の中央値が当期を代表しない」も避ける理由として認めない**——この指標は定義からして5期の中央値で、成長中の会社ならどこでも中央値は古い年に当たる（認めると下回る側だけ代表性を疑う逃げ道になる）。**「1/10 以下なら」と値で線を引かない**（楽天グループは 0.60 倍だが分子が単体・分母が連結29,419人で、避けるのが正しい）。**基準がそろったうえで下回るのを避けると、上回る会社でだけ指標を出す**選り好みになる
- **逆に「上回るのに触れない」ことは落とさない。** 指標に触れるかどうかは生成側が選んでよく（`generate.md`）、**避けてはならないのは下回る側だけ**——そこで避けると選り好みになるが、**分析の筋に載らないから書かないのは、どちらの向きでも通す**
- **持株会社で平均年収・在籍年数を語るとき、その数字が事業会社ではなく提出会社のものだと断ること**は**通す**（画面の数値をどう読むかの範囲）。**「持株会社である」と構造を主張するなら根拠は4節に要る**が、**「この平均年収は◯◯株式会社に在籍する人のもの」と数値の読み方に留めるなら、4節に `持株` が無くても通す**——`figures.employees` の定義（提出会社）から言えるうえ、**4節の事業の記述がすべてグループを主語にしている**ことも支えになる。**根拠は4節に要る**——「当社の子会社及び関連会社は……を営む会社等で構成」のような記述から到達できること。社名や業態からの補完で書かない。**我々を主語にした形**（「当サイトでは提出会社ベースで表示している」）は書き直させる
- **`profit_per_employee_yen` を「一人当たり経常利益」と呼ぶことは、4節に `経常利益` が0件でも落とさない。** この指標は**連結の経常利益が取れない会社では単体の経常利益から作られている**（`pipeline/data/performance_history.csv` の `oi_basis` が `nonconsolidated`。**直近5期すべてが単体なのは527社＝17.8%**で、IFRS 採用会社の多くがここに入る）。**経常利益は有報の「主要な経営指標等の推移」の提出会社欄に実在する科目**で、記憶からの創作ではない。**指標名をそのまま書くほうが揺れないので、段階を名乗らない形（「一人当たり利益」）へ書き換えさせない**
- **業種の分類と事業の中身がずれる会社で、倍率を数値で書かずに「大きく上回る」と書き、分類の効果を名指しすること**（「同じ区分に並ぶのは信販やリースの会社で、取引所とは商売の形が違う」）は**通す**——業界一般の知識で数値を含まない。**数値を書かないことと、読者が同じページで見る数字の読み方を添えることは両立する**
- **9割の線は「近づく」言い方に当てる。** 上限を示すだけの「◯に満たない」（0.4% を「1%に満たず」）は近接を含意しないので**落とさない**が、離れているなら**実数で書かせる**——「◯に届かず」（近接を含意する）とは別の語として扱う
- **原文の「〜も あり」を因果として言い切ること**は**通す**（型A9 を新設しない）。落とすのは材料が**逆を指している**とき（型S1）だけで足りる——「原文が『も』を使ったら言い切れない」を規格にすると、ADR-0016 が通すと決めた重み付けと因果のほとんどが引っかかり、**分析が要約に戻る**。ただし**他の要因を排除する書き方**（「〜だけによる」）は別で、その要因が原文に並んでいれば落とす

## 落とすほどではないが直させるもの

**事実の誤りではないが、読者が材料に当たったときに引っかかる形。** `true` にしたうえで申告し、書き直させる。

- **状態の反転を「まま」で書く**（前期 182億円の営業利益 → 当期 △88億円の損失なのに「赤字のまま」）。**材料が1点しか持たない指標に「まま」を使う**のも同じ
- **状態を一括りにする語**（「どこを見ても悪くない」に対し**純利益だけが △10.6%**）
- **単調性を含意する語**（「上がり続けている」）が推移の形と食い違う。**指している範囲が違えば片方だけが誤りになる**（見出しの10年では誤りでも、本文の直近5年では正しい）
- **見出しだけが本文より一段強いこと**（本文「利益の出る形になったのがごく最近」に対し見出し「利益の出る形にようやく届いた」＝当期に初めて黒字化したと読める。実際は前期も3段階とも黒字）
- **2つある要因の1つを全体の性格として言い直すこと**（減収要因が「連結除外**や官公庁業務の反動減**」なのに「減収の中身は事業の入れ替えによるもの」）
- **材料が逆方向の記述を持つとき**、正面から向き合う書き方（「放送の現場を持たない持株会社」に対し材料は「放送インフラアセットを当社へ移管し」）
- **同じ会社の中で集計単位の違う記述が逆を向くとき**、見出しに単位を書かせる
- **利益段階のずれ**（セグメントの当期利益が「税引前利益を押し上げた」）。向きが合っていれば通すが、**読者が突き合わせられる食い違い**
- **基準年を書かずに「横ばい」**（原文は2022年度実績比なのに読者は前期比と読む）
- **`figures` の指標を、その定義と違う統計として説明する**（中央値を「打ち消し合う」「ならした」と呼ぶ）。**指標の定義を言い換えるときは、その統計が何をしているかまで合わせる**
- **指標の定義を部分的に挙げて、符号の向きが違う項目を「など」に隠す**
- **要約が節をまたいで区分名を補うこと**（セグメント名と船種の対応が4節のどこにも無い）。**辿れることを根拠に通すと分析より緩くなる**
- **セグメント名と製品名を入れ替えること**（**製品の話を事業全体の話として書くと向きが逆に読める**）
- **出来事の成否を断定すること**（「交渉が通った」）
- **子会社が「手がける」と書いて開発主体がずれること**（`sources` が「当社の開発製品」と書いている）
- **調達手段を並べて、充当先が材料と対応していないこと**（「社債と」の1語だけが対応を持たない）
- **材料が扱っていない年について理由を述べること**（「投資の成果が大きかった2023年」——年収は `figures` にあるが、その年の投資の成果は材料に無い）

- **業界一般に「求められている」ことを、当社の実施として書くこと**（型④の縁）。原文は
  「技能労働者の処遇改善による担い手確保の推進や…**取り組みが求められている**」なのに、
  要約が「処遇改善を**進め**」と当社の行為にしていた。**同じ一文の中で支持の強さが割れる**
  ことがある（重層下請構造改革のほうはサステナビリティの節に「推進状況」があり当社の話）
- **区分の帰属が材料に無いのに補うこと。** 「持分法適用関連会社であるONE社を**含む製品物流
  セグメント**」——**ONE社がそのセグメントに属するとは4節のどこにも書かれていない**。
  セグメント損益 △2,027億円が経常利益の減少 △1,989億円とほぼ一致することから切った版の中で
  到達できる推論なので通すが、**数値で書かせるほうが安全**
- **材料が1点しか持たない指標に「戻る」を使うこと。** 「工事の利幅が**戻り**」——材料にあるのは
  前期比の売上総利益率の向上だけで、それ以前の水準を持っていない。**「まま」と同じ形の逆向き**

**迷ったら `true`。** **推測が1つ外れることの損は、読者が「AI の分析」として読むぶん小さく、踏み込みが1つ減ることの損のほうが大きい**——**分析が事実の言い直しになれば、要約と2つ持つ意味そのものが消える。**

## 落ちたら書き直す（上限2回）

**要約と分析は対で出す。片方だけのページを作らない**（spec 1.19・AC-28）。だから `false` を付けたら、そこで終わりにしない——**理由を生成側に返して書き直す。**

**直し方は「材料と合わせる」であって「主張を弱める」ではない。** 落ちるのは数値の向き・幅・時点・区分のどれかなので、**材料の数字に合わせて書き直す**。**主張そのものは残す**——弱めて通せば、落とした意味が消える。

| 落ちた文 | なぜ落ちたか | 直した形 |
| --- | --- | --- |
| 金属資源は前年度を上回った | 2,278 → 2,045 億円と**減っている**（型S1） | 金属資源は前年度を下回った |
| 売上総利益から下はすべて二桁の増益 | 売上総利益は **9.0%増**で二桁でない（型A8） | 営業利益から下はすべて二桁の増益 |
| 当期の新作『真・三國無双 ORIGINS』 | 材料が書いているのは**受賞と追加DLC と移植版だけ**（型A12） | 当期の新作『仁王３』『ゼルダ無双 封印戦記』 |

**2回書き直しても通らなければ、そのまま `false` で出す。** `merge` が**要約も一緒に落とす**（`generate.pair_or_drop`）。**ここで無理に通さないことが、この工程の意味を保っている**——「必ず対にする」を絶対条件にすると、通らない分析を通す圧力がそのまま検証パスに掛かる。

## 報告

`false` の内訳は**型の番号で数える**（要約は `S`、分析は `A`、要約については C6 の型①〜⑪も使う）。**読む側で振り直さない**——振り直すと回をまたいで内訳を比べられなくなる。どの型にも当てはまらないものは「その他」として理由を1行書く。

**`true` にしたが迷った箇所も添える。** 落とすほどではないと判断したもの、既存の型を広げれば当たるもの、基準が定まっていないと感じたものを、社名と該当文を挙げて書く。**判定と申告は別のもので、迷いを `false` に切り上げる必要はない**——`false` は書き直しを起こし、申告は基準を動かす。

**生成側の申告を数えず、実物に当たる。** 「原文にある語で書いた」「文を割った」という報告が実態と食い違ったことが2回ある。**語で検索して確かめる。**
