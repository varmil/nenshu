# 要約と分析の検証パス（C9・#241）

生成された**要約**と**分析**を、それぞれ別の基準で判定する。

**生成とは別の仕事として読む。** 「読んで自然か」「日本語として良いか」は見ない。
機械ゲート（`gate.py`）が拾えないものをここで止める。

**基準が2つある**（ADR-0015 決定1）。混ぜると、要約に評価が通るか、分析が事実の写しに
なるかのどちらかが起きる。

| | 要約 | 分析 |
| --- | --- | --- |
| 判定 | 「4節の原文に**書いてあるか**」 | 「渡した材料から**導けるか**」 |
| 材料 | `sections` の4節だけ | 4節＋`figures`＋**`sources` の URL の中身** |
| 評価語 | あれば `false` | **あって当然。それだけでは `false` にしない** |

## 入力

`work/gated_NNNN.json`。`companies[]` の各要素が1社で、`edinet_code` / `name` /
`summary` / `headline` / `analysis` / `sources` / `sections`（4節の**全文**）を持つ。

**渡してある原文は打ち切られていない。** 生成には切って見せているので、**切った先のことを
述べていたら、それは生成が原文の外から採ったということ**になる。

## 出力

`work/verify_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json
{"edinet_code": "E02181",
 "summary_supported": true,  "summary_reason": "",
 "analysis_supported": false, "analysis_reason": "撤退した事業を現在形で書いている",
 "types": ["A2"]}
```

`false` のときは `reason` に**食い違う箇所を1つ**書く（20字程度）。

## 要約の判定

**各文について、4節のどれかがその内容を述べているかを見る。1文でも支持されなければ
`false`。**

`false` にするもの。

- 原文に無い事実を述べている
- 原文と逆のことを述べている
- 原文が触れていない範囲に広げている
- **評価になっている**（「収益性が高い」「強みを持つ」）
- **撤退した事業を現在形で書いている**（C6 の型①。これだけは先に確かめる）
- **有報の記載作法の説明を写している**（「報告セグメントは……で区分している」。C6 の型⑪）

`true` にしてよいもの。

- 原文の言い換え・要約・順序の入れ替え
- 4節のうち一部だけを取り上げること
- 「当社」「当社グループ」を主語なしで書き直すこと

## 分析の判定

**各主張について、根拠が材料のどれかにあるかを見る。**

**根拠は3つのどれかにある。**

1. `sections` の4節
2. `figures` の数値
3. **`sources` に挙がった URL の中身** — **実際に取りに行って確かめる**。ここが C6 に無かった
   工程で、材料を有報の外へ広げたぶんの埋め合わせになっている（AC-27）

`false` にするもの。

- **3つのどれにも根拠が無い**——これが**記憶から補った**ということ。ADR-0015 が唯一
  残した線で、**分析でも覆らない**
- `sources` の URL が**そのことを言っていない**（取りに行って確かめた結果）
- URL が開けない・404・別の会社のページを指している
- 材料と**逆のこと**を述べている（`figures` が上昇を示しているのに「下がっている」）
- **撤退した事業を、いまやっているように書いている**
- **数値を並べただけで、意味付けが無い**（対照表の「左」の形になっている）
- 一言が**言い切っていない**（「〜と思われる」「〜の可能性がある」で逃げている）

**`false` にしないもの。**

- **評価語があること。** それが本体である
- **断定的であること。** 材料から導けるなら言い切ってよい
- **数値が少ないこと。** 少ないほうが規格に合っている
- **材料が薄く、分析も薄いこと。** 薄いまま書くのは正しい振る舞い（埋めにいけば記憶から
  補うことになる）

**迷ったら `false`。** 分析が1つ減ることの損は、根拠の無い評価が1つ出ることの損より小さい
——**文は照らし合わせる先が読者の手元に無い**（ADR-0010）。**分析では出典を画面に出すので
手元に来るが、そのぶん出典が支えていない文の据わりが悪くなる。**

## 報告

`false` の内訳は、`prompts/generate.md` の**型の番号で数える**（要約は `S`、分析は `A`、
要約については C6 の型①〜⑪もそのまま使う）。**番号はあちらが持っているので、読む側で
振り直さない**——振り直すと回をまたいで内訳を比べられなくなる（C6 で3人が別々の番号を
振って食い違った）。どの型にも当てはまらないものは「その他」として理由を1行書く。

**新しい型を見つけたら、番号ではなく「その他」で報告して中身を書く。** 番号を振るのは
`generate.md` を直すときで、そこで初めて次の回に効く。
