# 要約と分析の生成（C9・#241）

1社につき**2つのものを書く**。規格が違うので、混ぜない。

- **要約** — 有報の4節に**書いてある事実**を、評価語なしでまとめる
- **分析** — 材料から**導ける解釈**を、評価を入れて書く。冒頭に一言

**1回で両方書く**のは原文を2回読ませないためであって、規格が近いからではない。
**書き分けられないなら、片方を空にする。**

## 入力

`work/batch_NNNN.json`。`companies[]` の各要素が1社。

- `edinet_code` / `sec_code` / `name`
- `sections` — 有報の4節（`mdna` 経営者による分析 / `risks` 事業等のリスク /
  `issues` 対処すべき課題 / `sustainability` サステナビリティ。**節ごとに先頭を切ってある**）
- `figures` — **同じページが既に表示している数値**。平均年収・平均年齢・平均在籍年数・
  従業員数・業種・決算期・平均年収の10年推移・稼ぐ力（一人当たり経常利益）と業種中央値・
  残業と有給

## 出力

`work/gen_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json
{"edinet_code": "E02181",
 "summary": "……。……。……。",
 "headline": "業績は堅いが、平均年収は10年で13%下がっている。",
 "analysis": "……。……。……。",
 "sources": [{"url": "https://……", "title": "……", "accessed": "2026-08-28"}]}
```

書けないと判断したものは空文字にする。**無理に書かない。** ただし**要約と分析は対で出す**ので、片方だけ空にしても `merge` が両方落とす（spec 1.19・AC-28）。

## 材料——ここが C6 といちばん違う

**分析は有報の外の文書も材料にしてよい。むしろ使う**（ADR-0015 決定2）。

1. `sections` の4節
2. `figures` の数値
3. **Web から取得した文書** — 公式サイト・ニュースリリース（自社ページでも PR TIMES 等の
   配信サービスでも）・採用求人（自社ページでも HRMOS・Indeed 等でも）・その他、検索で
   辿れる一次情報

**配信サービスや求人サイトを理由に落とさない。** 出しているのは会社自身で、第三者の
編集物より一次に近い。**見るのは出所の格ではなく、取れて出典を示せるかどうか。**

**ただし「会社自身が出している」までが線である**（パイロットで足した）。年収まとめ記事・
転職メディアの解説・個人ブログは**会社が出したものではない**ので材料にしない。実際に
「ファナック 採用 初任給」で検索すると上位8件のうち5件がこの型で、**平均年収を
1,238万・1,163万・1,164万と互いに違う値で書いている**——このサイトが有報から出している
数字と食い違うものを材料にすると、有報ベースだという立て方そのものが崩れる。

**報道記事も本文の根拠にしない。** 会社自身の発表があるならそちらを当たる（新業態の
出店を日経が報じていても、リリースが出ているならリリースを引く）。

**会社が自分で言っている評価は、そのまま書かない。** 「業界シェアNo.1」のような自称は
**その会社が出した文書にある**ので材料の条件は満たすが、こちらが地の文で書くと我々の
評価になる。書くなら「同社はシェア首位としている」と帰属を付ける。

**そのうえで、モデルの記憶から補ってはならない。** 世間で知られている話・報道の記憶・
世評を、**取ってきた文書の裏付け無しに**書かない。**これが唯一残っている ADR-0010 の線**で、
分析セクションでも覆らない。書こうとしている事実の出所が「知っているから」なら、
**取りに行くか、書かない。**

**使った URL は `sources` に全部入れる。** 有報の4節と `figures` だけで書いたなら空でよい。

**取り方の線**（ADR-0008 決定1）。

- ブラウザの UA に偽装しない。ヘッドレスブラウザで取りに行かない
- 403・503・画像認証・WAF のチャレンジは**明示的な拒否**として受け取り、その材料は使わない
- **転載しない。** 導いた解釈を自分の言葉で書くのであって、原文を長く写さない

**探す量には上限がある。** 1社あたり**検索は2回まで、取りに行くページは3つまで**
（パイロットの実測で決めた。8社中5社は有報と `figures` だけで書けている）。
**材料が薄い会社は薄いまま書く**——埋めにいけば記憶から補うことになる。

## 要約の規格

**この要約が答えるのは「この会社は何をしている会社か」であって、「当期の業績はどうだったか」
ではない。** 読むのは**求職者**で、投資判断のために読む人ではない。**売上高と利益の推移は
C10 が別途チャートで10年ぶん出すので、ここで厚く書かない**——文字で並べても読みにくく、
その会社のイメージも湧かない。

- **業績の数値から書き始めない。**「当連結会計年度の売上高は…」の形にしない。
  **50回目までの316社では168社（53.2%）がこの書き出しで、要約1本あたりの数値は中央27個
  だった**——運営者の指摘で規格を改めた
- **数値は原則として書かない。** 業績に触れるとしても**1文まで**で、そこでも
  「増収増益だった」のように語で言う。**機械ゲートが数を数える**（カギ括弧の中の
  固有名詞は数えない。`一太郎2025` や `ATOK Passport` は名前であって量ではない）
- **拾うのは、その会社が何をどう作って誰に届けているか。**
  - **商品名・サービス名・ブランド名**を出す（「新サービス」ではなく名前）
  - それが**誰に何を提供しているか**（「幼児から高校生まで全16学年の通信教育」）
  - **当期に何を出したか・始めたか**（新製品、新コース、新拠点）
  - 会社が掲げている**考え方・こだわり・これからやろうとしていること**
  - **人にどう向き合っているか**（人的資本の節。制度・育成・働き方）
  - **リスクは、そこで働くことに関わるものだけ**（人材の確保、事業環境の変化）
- **全角200〜700字 / 3〜10文**（**500字前後を目安に。上限に近づけない**）
- **評価語を含めない**（「業界最大手」「高い収益性」「優れた」「急成長」…）。C6 と同じ表
- **社名は書いてよい**（50回目に規則を外した）。子会社名・ブランド名・サービス名に社名の語が
  入っているもの——`東急電鉄㈱`・`楽天市場`・`太陽ファルマ`・`富士通ゼネラル`——も**そのまま
  書く**。**ただし見出しに社名が出ているので、文頭で名乗り直す必要はない**（「◯◯株式会社は、
  〜を営む」で始めなくてよい）
- **原文に現れない固有名詞を含めない**
- 文体は常体。**ここには評価も解釈も入れない**——それは分析の仕事
- **原文にある会社自身の表現でも、評価語なら書けない**（「世界最大級の工場」「優位性」で落ちた）。
  **機械ゲートは社ではなく文を落とす**ので、気づかないとその情報だけが要約から消える——
  `gate_reasons.jsonl` の `文を落とした` は、社が落ちていなくても読む
- **固有名詞は原文の表記のまま写す。`㈱` を `株式会社` に展開しない**
  （展開した瞬間、原文に無い固有名詞になって文ごと落ちる）

### 何を拾うか——ジャストシステム（E04996）の原文で

原文（MD&A・課題の節）にはこう書かれている。

> 高機能で付加価値の高い商品・サービスを提供することにこだわり、既存ビジネスによる安定した
> 収益を基盤としつつ…／日本語ワープロソフト「一太郎」等のパッケージソフトウエアや、
> 「ATOK Passport」「スマイルゼミ」等のクラウドサービスを提供し、ECサイト「Just MyShop」も
> 運営／「スマイルゼミ」は、幼児から小学生・中学生・高校生まで、全16学年の学びを提供…
> AIを活用した対話で導く教材「Coachez」を提供開始／米国向けHome Learning Service
> 「Smile Zemi」は…新たに幼児向けGrade K を開講／「ATOK Passport」は、Windows版に
> 「ATOKハイパーハイブリッドエンジン２」を搭載／「一太郎」は、40周年を記念して
> 「一太郎2025 プラチナ [40周年記念版]」を発売

**拾うのはこの側である**——サービスの名前、それが誰に何を届けているか、当期に何を出したか、
会社が何にこだわっていると言っているか。**同じ会社の売上高・営業利益・その増減率は、
この要約には要らない。**

## 分析の規格

- **`headline`** — 全角12〜75字の**1文**。その会社が**いまどうなのか**を言い切る
- **`analysis`** — 全角120〜500字 / 3〜10文。「うまくいっていること」「うまくいって
  いないこと」「今後の挑戦」を**地の文で**書く。見出しを付けて箇条書きにしない
- **評価語を書いてよい。これが本体である**
- **算用数字は合計3個まで**（`headline` ＋ `analysis`）。機械ゲートが数える。**少ないほど良い**——パイロット8社の実測は1〜3個だった
- **段階評価にしない。** 「好調」「安定」「不振」のような語彙から選ばない——
  **語彙は自由で、観点だけが固定されている**
- **「材料」と書かない。読者はこの語を知らない。** ここでは有報の4節を指す我々の内部
  用語だが、**画面（C10）に出るのは本文だけで、材料という言葉の説明はどこにも無い。**
  有報にそう書いてあることを示すなら **「会社は〜と説明している」「会社自身が〜」** と
  書く（有報を書いたのは会社なので、指しているものは変わらない）。**33回目の検証パスが
  見つけた**——それまでの216社のうち **49社（23%）** が「材料は説明している」の形で
  書いており、機械的に置き換えて直した。**商材としての「材料」（半導体材料・原材料）は
  そのまま**——直すのは我々の内部用語として使っている側だけ

### 数値は脇役。ここが最も外しやすい

**同じ材料でも、数値を並べるか意味を言い切るかで別物になる。**

| 書いてはいけない形（数値が主役） | 書く形（定性が主役） |
| --- | --- |
| 売上58,448百万円（3.4%減）、営業利益1,298百万円（52.2%減）、経常利益1,436百万円（49.2%減）、純利益4,113百万円（2.7%増）。 | **本業は苦しい。** 営業利益が半減し、値引きに頼った販売で粗利も落ちた。最終利益は増えているが、これは保有株の売却益によるもので、商売が上向いたわけではない。 |
| 売上132,328百万円（29.6%減）、営業損失18,692百万円、当期純損失19,810百万円。希望退職1,483名応募・1,319名退職。 | **縮小しながら建て直している最中で、次の柱はまだ立っていない。** 工場を畳み、人を減らし、資産を売って赤字幅を圧縮している段階。 |
| 売上7.6%増、経常利益15.6%増、純利益12.9%増。自己資本1.9兆円。平均年収は1,318万円→1,144万円で13%減。 | **業績は堅いが、平均年収は10年で13%下がっている。** 増収増益で財務も厚いのに、会社の好調が給与に回っていない期間が続いている。 |

**左は読者が自分で意味を組み立てる必要がある。右は組み立て済み。** 左の情報量は多いが、
それは有報が既にやっていることで、ここで繰り返す意味が無い。

**推移を語でまとめるときは、幅の基準を1つにする。** この節の良い例は
ファナックの「平均年収は10年で13%下がっている」——**1割強の動きを、一言に値するものとして
扱っている。** だから同じ1割強を別の会社で「大きくは動いていない」と書くと、基準が2つに
なる。**幅を語に置き換えるなら「1割ほど」「3割近く」のように動いた量が残る言い方にする。**

**分数は算用数字2個ぶん数えられる。** 「3分の1」「4分の3」はどちらも上限3個の**2つ**を
使う（`digit_runs` は数字の並びを数えるので、分子と分母が別々に当たる）。**35回目は6社中4社が
これで上限を超えた。** 「3分の1近くまで縮んだ」は「大きく縮んだ」、「4分の3が消えた」は
「ほとんど消えた」で足りることが多い——**幅を語に置き換えられないか先に試す。**

**「ほとんど落ちていない」と書く前に、上の基準に当てる。** 藤木工務店（37回目）の
「売上は2割近く減ったのに**利益はほとんど落ちておらず**」——当期純利益は**9.0％減**で
1割近い。ファナックの例が1割強を一言に値する動きとして扱っている以上、同じ幅を
「ほとんど」と書くと基準が2つになる。**落ち方を比べたいなら相対で書く**——
「売上の落ち込みに比べればずっと小さい」なら基準は1つのままである。

**幅を語に置き換えるときは、超えているのか足りないのかまで当てる。** 三菱倉庫（36回目）の
「最終利益は**7割近く**増えている」——実際は71.9％増で**7割を超えている**。「近く」は
届かない側の言い方なので、これで材料と食い違う（型A8）。「3割近く」「1割強」も同じ。

**「半減」「増収増益」「2割」「倍増」のように語で言えるものは語で言う。** そうすると
数値が要らなくなる——上の良い例5つに含まれる算用数字は**0〜2個**だった（あれは一言と短い裏づけだけの63〜90字で、ここで書く本文は3観点まで含めて約250字になる）。

### 固有名詞を積極的に出す。「新ブランド」ではなくブランド名を書く

**具体性は固有名詞から来る。** 材料にある製品名・ブランド名・サービス名・事業名は、
**言い換えずにそのまま書く。**

| 抽象に逃げた形 | 書く形 |
| --- | --- |
| ファッションビル向けの新ブランド | 新ブランド「AUREME」 |
| 本体のEC支援 | ECサイトの構築・運用を請け負うEC支援 |
| 主力の解体機械 | 主力の圧砕機 |
| 大型プラント解体向けの周辺機種 | 鉄骨カッターと油圧ブレーカ |
| 新しい中期経営計画 | 中期経営計画「変革2030」 |

**分析の機械ゲートは固有名詞を見ない**（外部の文書も材料なので、有報の原文だけと
突き合わせると誤判定する）。**だから抽象に逃げても機械は通す。** 具体的に書くかどうかは
ここで決まる。

**ただし材料にあるものに限る。** 「知っている製品名」を書かない——これは**記憶から補う**
ことそのもので、ADR-0015 が唯一残した線に当たる。**書きたい固有名詞が材料に無いなら、
`sections` を読み直すか、公式サイトを取りに行くか、書かない。**

**探すときは製品名・ブランド名を名指しで探す。** 「◯◯（社名） 製品」「◯◯ ブランド」
「◯◯ サービス」。有報の4節に無くても、公式サイトには必ず載っている。

### 価値が出るのは、有報が数字を並べているのに結論を言わない箇所

三陽商会がその典型で、**有報を素直に読むと「最終利益は増えた」で終わる。** 売却益に
よるものだと気づくには営業利益・経常利益・純利益の動きを突き合わせる必要がある。
**ここを一言で言い切ることが、この節の存在理由である。**

**`figures` の数値と有報の食い違いも同じ。** ファナックは有報の文面だけでは
「増収増益で財務も厚い」までしか言えないが、平均年収の10年推移を並べると
**求職者にとって最も効く食い違い**が出る。

## 「好調かどうかの一言」の実例（2026-08-27・人手）

**5社とも違う語彙になっている。** 段階評価では出せない言い方をすること。

- **ジャパンディスプレイ（6740）** — 縮小しながら建て直している最中で、次の柱はまだ
  立っていない。
- **三陽商会（8011）** — 本業は苦しい。
- **ファナック（6954）** — 業績は堅いが、平均年収は10年で13%下がっている。
- **ディスコ（6146）** — 数字の上ではほぼ隙がない。
- **出前館（2484）** — 赤字は続いているが、規模を追う段階は終えた。

## 実際に落ちた型

**番号は固定。回をまたいで内訳を数えるためにあるので、読む側で振り直さない。**
**要約と分析で表を分けてある**——規格が違うものを1つの表に混ぜると、12回ぶんの積み上げが
混ざる（C6 の教訓）。

### 要約の型（S）

C6（`summary/prompts/generate.md`）の型①〜⑪が**そのまま効く**。あちらは「事業の内容」
1節から2〜3文を書くもので、こちらは4節から3〜10文を書くが、**まとめ方・括り方・帰属が
原文を離れる**という失敗の質は同じである。**まず C6 の表を読むこと。**

このプロンプト固有の型は、回を重ねてここに足す。

- **型S1 増減や影響の向きを取り違えた。** 三菱商事のセグメント表で金属資源は 2,278 → 2,045
  億円と**減っている**のに、`[+]` 要因（銅事業の戻入・市況上昇）だけを読んで「前年度を
  上回った」と書いた。伊藤忠のリスクの節は生活消費分野を「相対的に**国内景気の影響を
  受けやすい**」としているのに「影響を受けにくい」と逆に書いた。**増減要因の欄には
  `[+]` と `[-]` が並ぶ。拾った要因の向きと、その項目そのものの向きは別である**——
  項目の向きは合計の側（表の増減欄）で確かめる。
- **型S2 枠組みの名前だけが材料にあるのに、中身まで書いた。** ＬＩＮＥヤフー（46回目）の
  要約は「グループトップリスク」として3項目を挙げたが、**リスクの節はその中身を書いて
  いない**——挙げた3項目はサステナビリティの節が SASB を参照して特定した**別の枠組み**の
  ものだった（C6 の型④の、節をまたぐ版）。**「◯◯として△△を特定している」と書く前に、
  △△がその◯◯の下に置かれているかを見る。**

### 分析の型（A）

- **型A1 内訳が書かれていない影響を、切り分けたように書いた。** 出前館の原文は
  「付与型クーポンの導入に伴い、販売促進にかかる金額を売上高から減額する処理を採用」と
  書いているが、**その金額は書いていない。** そこから「会計処理の変更を差し引いても
  縮小は続いている」とは言えない。**「◯◯を除いても」「◯◯の影響を差し引いても」は、
  その◯◯の大きさが材料にあるときだけ書ける。**
- **型A2 材料が述べていない因果を作った。** 第一建設工業の MD&A は減益を数字で示すだけで、
  理由を書いていない。課題の節にある「労務費・建設資材価格の高騰」は**今後の見通し**として
  挙がっているもので、当期の減益の原因としては書かれていない。**「AだからB」と書く前に、
  材料がその繋がりを述べているかを見る**——同じ文書の別の節に A と B が載っていることは、
  A が B の原因だという意味ではない。

  **逆接で並べられた2つを、同じ話に束ねない。** 日本光電工業（46回目）はアボット製品の
  取り扱い終了を「消耗品・サービス事業をどう積み直すか」と結んだが、MD&A は
  「**消耗品・サービス事業の強化に注力したものの**、現地仕入品の抑制が進み、導入品である
  アボット製品も減少した」と**逆接で並べている**——アボット製品はその事業の中身ではなく、
  並列の別要因である。

  **原因が書かれていないときは、起きたことだけを書く。** 「売上と受注は増えているのに、
  利益はそろって前期を下回った」で止めるほうが、原因を作るより強い。

  **型A2 は最後の1文に出やすい。** 2回目の8社で落ちた3件はすべてこの型で、しかも
  **`figures` の数字に理由を付けた1文**だった——在籍年数が短いのは「急に人が増えたから」、
  年収が上下するのは「市況に釣られて」、振れ幅が小さいのは「船種を広く持つから」。
  **どれも材料にはその理由が無い**（在籍年数の推移も、市況指標も、船種と振れ幅の関係も）。
  **数字を並べたあとに「〜だから」を足したくなったら、その理由が材料にあるかを見る。**
  無ければ**数字だけで止める**か、会社が課題として挙げているものに帰属を付ける。

  **1件の出来事から方針を読まない。** 42回目は6社中4社がこの型で、いずれも
  「起きたこと1つ」の裏に**方針・意図・動機・土台**を置いていた——三井住友銀行の
  子会社1件の売却から「**海外の持ち方を変えている**」、住友化学の持分引下げに「動機」、
  ぴあの利用料改定に「**催しの数に左右されない土台**」。**出来事はそれ自体として書く。**
  狙いや方針は、会社がそう書いているときだけ書ける。

  **要約と分析を突き合わせる。** 関電工（18回目）では、当期の押し上げ要因として
  半導体・データセンター関連投資と首都圏の大型再開発を挙げたが、材料がそれらを置いているのは
  **「今後の見通し」の側**で、当期の要因は工場建設・オフィスの新築更新・送配電設備の
  高経年化対策だった。**同じページの要約は正しく書けていて、分析だけが食い違っていた**
  ——要約に当期の要因を書いたなら、分析の当期要因はそれと揃うはずである。ずれていたら、
  どちらかが材料を離れている。

  **材料が理由を書いている場所を、まず探す。** 25回目は4件がこの型で落ち、うち2件は
  **材料が同じ段落で理由を明示していた**——安藤・間は営業利益の減少を資材価格と労務費の
  圧力と読んだが、材料は「販売費及び一般管理費の増加が売上総利益の増加を上回った」と
  書いており、売上総利益はむしろ増えていた。ＺＯＺＯは粗利率の低下をセールと広告のせいに
  したが、材料は「手数料率の低いLystの連結に伴う事業構成比の変化」と書いていた。
  **増減を見つけたら、もっともらしい理由を当てる前に、その段落が理由を述べていないかを
  読む。** 述べていればそれが答えで、こちらが考える余地は無い。

  **減収・増収の中身を見ずに「量ではなく採算」と書かない。** ファーストコーポレーション
  （41回目）の「扱った**工事の量**ではなく、その採算が上がっている」——**売上が減ったのは
  不動産事業で、建設の売上はむしろ増えていた**（型A5）。全社の増減を1つの原因で説明する前に、
  **セグメント別の表でどこが減ってどこが増えたかを見る。**

  **「◯◯ではなく△△だ」の形は、材料が理由を書いていないと作れない。** 第一実業（39回目）の
  「扱う量ではなく、**取る仕事の中身が変わった**と読める」——粗利率が上がったことは材料に
  あるが、**その理由はどこにも書かれていない**。**言い換えの形をとっていても、否定した側と
  肯定した側の両方に根拠が要る。**

  **業界の一般知識で穴を埋めない。** あいちフィナンシャルグループ（25回目）は
  その他業務収支の損失を「債券の入れ替えが続いている」と説明したが、**内訳は4節のどこにも
  無い**。銀行の決算ではよくある話であっても、**その会社がそう書いていなければ材料の外**
  になる。ADR-0015 は外部の材料へ広げた一方で「モデルの記憶から補わない」の線は残して
  いる——**取ってきた文書に無い事象は、業界の常識であっても書かない。**

  **「してまいります」は当期の原因にならない。** 鉄建建設（25回目）は建築工事の黒字転換を
  「選別受注を徹底するという方針が数字に出た形」と書いたが、選別受注は課題の節が将来の
  方針として書いているものだった。**節をまたいで A と B を結ぶときは、B が過去の話か
  将来の話かを見る**（17回目の第一建設工業と同じ構図）。

- **型A3 材料が述べていない日付・出来事を、近い記述から移した。** グロービングの4節に
  あるのは「2024年11月に実施した**公募増資**」と営業外費用の「上場関連費用」だけで、
  **上場の時期はどこにも書かれていない**。公募増資と上場を同じものと見て日付を移すのは、
  記憶から補うのと同じことになる。**書こうとしている出来事そのものが材料にあるかを見る**
  ——近くにある別の出来事の日付を借りない。

  **出来事に属性を足すのも同じ型である。** 原文が「2025年11月に公表した修正予想を上回り」
  としか書いていないのに「途中で**引き上げた**業績予想」と書いた（修正の向きは4節のどこにも
  無く、同じ節に「売上高の達成率は計画をやや下回る」ともある）。**材料にある出来事は、
  材料が述べている限りの姿で書く。**
- **型A4 条件の良さから、材料の外にある事実を導いた。** 三菱商事の「報酬も定着も労働時間も
  そろっている分だけ、**入り口の競争は厳しい**」。待遇の3指標は `figures` にあるが、
  **採用の競争率はどの材料にも無い**。**待遇・数字から労働市場の話へ渡らない**——
  読者が確かめる先が無い。同じ形でも「長く勤める人が多い職場」（在籍年数が支える）や
  「案件の当たり外れが個人に返ってくる」（原文の売上インセンティブが支える）は材料の
  内側に留まっている。

- **型A5 向きを取り違えた（分析版の型S1）。** 出どころは2つある。①**`figures` の推移**——
  住友商事の平均年収を「高い水準で横ばいに近く」と書いたが、実際は10年で47%上がっている。
  **同じページが推移のグラフを出すので、図と文が正面から食い違う。** ②**本文だけを読むと
  逆に読める箇所**——東京海上の国内生命保険事業を「損失に転じた」と書いたが、MD&A 本文は
  「1,238億円減少し、2,048億円の損失」としか書いておらず、**セグメント表を見ると前期も
  損失**である。**「転じた」「初めて」と書く前に、前期の値を表で確かめる。**
- **型A6 材料が述べていることを、無いと断定した。** ジャストシステムの「配当以外に大きく
  使う先はまだ見えない」——MD&A は内部留保の使途として既存事業の強化・新規事業の開発投資・
  M&A を挙げており、当期もソフトウエア開発に支出している。**「〜が無い」「〜が見えない」
  「〜していない」は、材料がそう書いているときだけ書ける。** 材料に書かれていないことは、
  書かれていないというだけで、無いことの根拠にはならない。

  **「材料に書かれていない」と書くこと自体ができない。** GMOフィナンシャルゲートの
  「減収の理由は材料に書かれておらず、そこは読み取れない」——**理由は有報にきちんと
  書いてあり、切った先にあっただけ**だった（前期の大口案件の反動とイニシャル売上の減少）。
  **こちらが読んでいるのは節ごとに切った原文で、その先を見ていない。** 材料の不在を
  述べる文は、原理的に確かめられない。**書けないことは書かずに済ませる**——別の、
  確かめられることを書く。

  **30回目は6社中3社でこれをやった。** 任天堂「材料は利益率の内訳を書いていない」・
  東光電気工事「材料はこの転落の理由を書いていない」・大末建設「材料は利益がここまで
  伸びた理由を説明していない」——**3件とも、切った版の同じ節に理由が書いてあった**
  （順に、販管費の増加とハード・ソフトの利益率差／複数の大型工事の工事採算悪化に伴う
  工事損失引当金／工事採算の改善と売上高の増加）。**この形の文を書きたくなったら、
  それは材料を読み切っていない合図である。** 書く前に、その節をもう一度、増減の直後の
  文まで読む。**書き終えてから「材料は書いていない」を含む文を検索して、1つずつ
  確かめてもよい。**

  **要約が落とした行は、分析が推測で埋める。** 東光電気工事の分析は「全体では増収増益」
  と書いたが、**連結の営業利益は1,724百万円減っていた**。要約が当期純利益だけを書いて
  営業利益に触れなかったため、分析はその1行を見ないまま全体像を作っている。
  **要約に載せなかった段階利益を、分析で「増益」「減益」と束ねない**——束ねるなら、
  その数字を要約にも載せる。

- **型A17 数字を評価する基準を、材料の外から持ち込んだ。** 三菱ＵＦＪ銀行（41回目）の
  「連結総自己資本比率は…**規制上の要求水準に対して厚みがある**」——**要求水準の値は
  4節のどこにも無い**。**数字そのものが材料にあっても、それを評価するための基準が
  材料に無ければ評価できない**（型A11 の「材料が持っていない比較」の、比較先が
  記憶から来る版）。**`figures` の業種中央値のように、材料が比較先を持っているときだけ
  「上回る」「下回る」と書ける。**

  **42回目にも出た**（立てた次の回）。ユーザーローカルの「平均年収は**それに比べて
  高くなく**」——比べる先は材料のどこにも無い。**水準を語るときは、比較先を材料の中で
  名指しできるかを先に確かめる。**

- **型A18 減収の要因を、材料が理由を書いていない減益にも掛けた。** 矢作建設工業（48回目）の
  「分譲マンションの新規供給戸数が減って**減収減益**となった」——原文が書いているのは
  **減収の要因だけ**で、利益の落ち方（−22.2%）は売上（−13.0%）より大きい。四国電力も
  「託送収益などが減って**経常利益が**7割近く落ちている」と書いたが、**原文はそれを売上の
  減少要因として置いている**。**「◯◯が減って減収減益」は、材料が利益の側にも理由を
  書いているときだけ書ける**——書いていなければ「減収となり、利益もそれを上回る幅で
  落ちた」のように**幅の対比だけ**にする（型A2 の、減収と減益をひと息に繋ぐ版）。

- **型A12 出来事の時点を、期をまたいで取り違えた。** アクシスコンサルティング（37回目）の
  「**前期に**連結子会社を吸収合併して」——2024年7月1日付の合併は、**6月決算のこの会社では
  当期首**である。**決算期が3月でない会社では、日付を見て期を決める**（`figures` の
  `period_end` が決算日）。型A3（材料の外の属性を足す）の時点版で、材料にある日付を
  こちらが期に読み替えるときに起きる。

  **日付が1つも出てこない形もある。** コーエーテクモ（45回目）は当期の新作として
  『真・三國無双 ORIGINS』を挙げたが、**材料がそれについて書いているのは受賞・追加DLC・
  移植版だけ**だった。**原文が当期の発売と書いている作品だけを当期の新作と呼べる**——
  同じ節に名前が出ていることは、それが当期の出来事だという意味ではない。

- **型A11 材料が持っていない比較を作った。** 名工建設（36回目）の「長期借入れが
  **増えていて**」——材料にあるのは当期の長期借入れによる収入だけで、**前期の借入額は
  どこにも無い**（財務キャッシュ・フローの前期は合計しか出ていない）。**型A6 の裏返し**で、
  あちらが「材料が書いていることを無いと断定した」のに対し、こちらは**材料が持っていない
  比較の結果を述べている**。**「増えた」「減った」と書く前に、比べる先の値が材料にあるかを
  見る**——当期の値しか無いなら「◯◯による収入があり」で止める。

  **開示されていない段階利益を束ねない。** 同じ会社の MD&A は受注高・売上高・経常利益・
  当期純利益しか出しておらず、**連結の営業利益が無い**。「受注も売上も利益も伸びた期」は
  その無い利益まで含んでしまう（型A6 の付記と同じ線）。

- **型A13 改善要因を、悪化の中身として並べた。** オリンパス（38回目）は
  「持分法投資損益とその他の損益の合算が悪化した」の説明に、**前期より約86億円
  「減少」した品質保証・法規制対応のプロジェクト費用**を挙げていた。増減要因の欄には
  改善と悪化が並ぶので、**拾った項目がどちらの向きかを、その項目自身の増減で確かめる**
  ——型S1 の「拾った要因の向きと、その項目そのものの向きは別」が、分析側でも同じ形で出る。

- **型A7 1期の増減から趨勢を述べた。** 三井住友トラストグループの「預かる資産の規模は
  **増え続けている**」——材料にあるのは当期の1期ぶんの増加だけで、複数期の推移はどこにも
  書かれていない（課題の節に「信託財産残高推移」という**図の見出しだけ**があり、値は本文に
  出てこない）。**「増え続けている」「伸び続けている」「連続して」は、材料が複数期を
  述べているときだけ書ける。** 当期の増減しか無いなら「当期も◯◯増えた」で止める。
  **`figures` の平均年収の推移は10年ぶんあるので、そちらの趨勢は述べてよい**——材料に
  何期ぶんあるかで書けることが変わる。

  **会社が継続を書いていれば書ける。** ＪＩＧ－ＳＡＷ（44回目）は「上場以来過去最高の
  月額課金売上のプラス成長に着地する潮流が**続いております**」と原文にあるので通り、
  同じ回のＴＯＫＹＯ ＢＡＳＥは表が2期ぶんしか無いので落ちた。**この型は材料が複数期を
  述べているかだけで決まり、その会社の実態では決まらない。** 落ちたときの直しは
  **「当期は◯◯だった」と主張を弱めるだけで足りる**——他の文に手を入れずに済む。

- **型A8 増減の幅を、材料の数値と食い違う言い方でまとめた。** 兼松の「売上総利益から下は
  **すべて二桁の増益**になった」——売上総利益は9.0%増で**二桁ではない**。しかも**同じページの
  要約が「売上総利益は9.0％増」と書いている**ので、文と文が正面から食い違う。型A5 と同じ
  「その場で見える食い違い」だが、取り違えたのは向きではなく**幅**である。**「すべて」
  「いずれも」「そろって」で束ねる前に、束ねた全部の値を1つずつ当てる。** 束ねられない
  ものが1つでもあれば、範囲を狭める（「営業利益から下は」）。

  **目標がレンジで示されているときは、レンジの中か外かで当てる。** 日立製作所（35回目）の
  「EBITA率とROICはまだ下側にある」——Adjusted EBITA率 12.4％は目標13〜15％の**下**だが、
  **ROIC 12.4％は目標12〜13％の中**である。同じ 12.4 という数字が、当てる先のレンジによって
  未達にも達成にもなる。**2つを束ねた時点で片方が嘘になった。**

- **型A14 セグメントの損益を、その中の事業名で呼んだ。** 日本特殊陶業（39回目）の
  「**半導体向けの赤字**も縮んでいる」——コンポーネント・ソリューションの損失について
  材料が書いているのは PPA償却費と酸素濃縮器事業の減損で、**半導体向けはむしろ増収要因**
  だった。**セグメントの中の内訳は、金額が材料にあるときだけ名指しできる**（型A1）。
  しかも改善側の事業を損失の名前に据えている（型A13）。**具体的に書こうとして
  中の名前に踏み込むと、かえって材料から離れることがある**——セグメント名で書けば足りる。

- **型A9 材料が限定していることを、無限定に断定した。** ダイビルの「借入で資産を積む
  戦略は**金利の動きにそのまま晒される**」——リスクの節は**有利子負債の大半を固定金利に
  している**として、影響を受けるのは一部の変動金利ぶんと将来の資金調達コストに限っている。
  **型A6（材料が述べていることを無いと断定した）の裏返し**で、材料が「限定付きで
  そうだ」と書いているものを、限定を落として言い切った形である。**会社が対応策や
  但し書きを添えているリスクは、その但し書きまで読む。**

- **型A19 並べられているものに包含関係を作った。** ＴＫＣ（48回目）の「宇都宮大学との
  共同研究**を含む**生成ＡＩの活用」——原文は「宇都宮大学とのＡＩ活用の共同研究**や**
  プログラミングにおける生成ＡＩの活用」と**並列**で書いている（C6 の型⑧の分析版）。
  **同じページの要約は正しく並列で書けていた**ので、**分析だけがずれる形**でもある。
  **「◯◯を含む△△」「◯◯などの△△」と書く前に、原文がその2つをどう並べているかを見る。**

- **型A16 区分をまたいで出来事を移した。** 東海旅客鉄道（40回目）の分析は、
  通勤型電車315系の全車両投入を**東海道新幹線の成果として書いていた**（原文は
  「在来線については…全車両の投入を完了しました」）。**同じページの要約は正しく在来線と
  書いており、分析だけがずれていた**——C6 の型④（区分の取り違え）の分析版である。
  **出来事を書くときは、原文がそれをどの区分の下に置いているかを見る。**

- **型A15 会社が並べているものに、重みを付けた。** サッポロホールディングス（39回目）の
  「**ビールと不動産という2本柱**のうち」——材料は酒類・食品飲料・不動産・外食を並べて
  いるだけで、2本柱という重みはどこにも無い（C6 の型②の分析版）。**同じ分析が2文前で
  食品飲料のコスト構造改革を挙げているのに、直後に2本柱と括る**という自己矛盾にもなる。
  **「主力」「柱」「中核」と書く前に、材料がそう位置づけているかを見る。**

  **限定は文ごとに揃える。** ＭＩＸＩ（47回目）の一言と本文2文目は「**売上**を押し上げた
  のはスポーツ事業」と限定できていたのに、**冒頭の1文だけが「収益の柱が入れ替わりつつある」**
  と外していた（材料は「デジタルエンターテインメント事業の収益規模を**維持拡大しつつ**、
  第二、第三の収益の柱となる事業を創出」）。**ある文が正しく限定していても、別の文が
  それを外していれば落ちる**——書き上げたら、限定の語（売上・利益・受注）が全部の文で
  揃っているかを読み返す。

  **この型は書き直しのときに入りやすい。** 日鉄ソリューションズ（42回目）は、別の型を
  直した書き直しで「**中期経営計画の柱は収益モデルそのものの組み替え**」を新しく入れた
  ——材料は事業収益モデル・顧客アプローチ・技術獲得・社内業務の**4つを対等に並べている**
  だけである。**言い切ろうとすると重みが付く。** 4つあるなら4つと書く。

- **型A10 別の時点の区分を、いまの区分として並べた。** ＫＤＤＩ（31回目）の要約は
  「パーソナルセグメント、ビジネスセグメント、**テレコムコアセグメント**等で事業を営む」
  と書いたが、**当期の報告セグメントはパーソナル／ビジネス／その他の3つ**で、
  `テレコムコア` は課題の節が次期中期経営戦略（2026年度-2028年度）の区分として挙げた
  ものだった。**この3つが同時に存在した期は無い。** 有報は当期の区分と次期の区分を
  別々の節に書くので、両方を読んで1つの並びにすると起きる。**セグメント名を並べるときは、
  それが当期の実績の区分かを見る**——MD&A のセグメント別業績に出てくる名前だけを使う。

**「押し上げたのは◯◯」は、押し上げられた側を1つずつ当てないと書けない。** 荏原製作所
（40回目）は本文を直したあと**一言が2度落ちた**——1度目は受注（増加額は環境のほうが
大きい）、2度目は利益（精密・電子のセグメント損益増は営業利益の増加の半分未満）。
**受注・売上・利益で主因の答えが違う**ので、束ねると必ずどれかが嘘になる。
3巡目に売上だけへ狭めて通った。

**言い過ぎは一言（`headline`）に出る。** 34回目は6社中2社が落ち、**どちらも一言だけ**が
材料を離れていた——コナミグループ「支えているのは長く配信を続けているタイトルである」
（型A2。材料は主力コンテンツが好調としか書いておらず、新作と継続配信のどちらが伸びを
作ったかは述べていない）と、大塚商会「伸びの主役は入れ替え需要をつかんだパソコンである」
（型A1。パソコンとパッケージソフトが並んでいるだけで、内訳は書かれていない）。
**本文はどちらも材料の内側で、しかも一言と食い違っていた**（前者の本文は「両方が回っている」、
後者は「パソコンの更新需要とパッケージソフト」と併記）。**一言は言い切る規格なので、
主因を1つに絞る圧力が掛かる。** 書き終えたら**一言と本文を並べて読む**——そこがずれて
いたら、材料を離れているのは一言のほうである。

**直したときは、一言と本文をもう一度並べて読む。** ナガセ（38回目）は本文の型A5 を
直したが、**一言は前の主張のまま残り、直した本文と正面から食い違った**。上の
「書き終えたら並べて読む」は**書き直したときにも同じだけ要る**——直すのは指摘された
1文だけでも、その1文と対になっていた一言が古くなる。

**型A1〜A17 はどれも「材料が足りない」ではなく「言い過ぎ」だった。** 直し方は2つ——
材料が述べている範囲まで**主張を弱める**か、**帰属を付ける**。**型S1 だけは別で、
あれは言い過ぎではなく誤読なので、原文どおりに直す。**

| 書いてはいけない形 | 書く形 |
| --- | --- |
| 会計処理の変更を差し引いても縮小は続いている | この落ち込みには販売促進費を売上から差し引く会計処理の変更も含まれる |
| 労務費と資材価格の高騰が利益を削っている | 会社自身も労務費と建設資材価格の高騰を今後の課題に挙げている |
| 上場も2024年11月と新しく | 当期は上場関連費用を計上しており、2024年11月の公募増資で得た資金が手元にある |
| 待遇がそろっている分だけ入り口の競争は厳しい | 報酬も定着も労働時間もそろっており、待遇の面で崩れているところが見当たらない |

**要約と分析は対で出す。片方だけ書いて出さない**（spec 1.19）。片方が書けないなら、
**書ける範囲まで弱めて両方出す**。それでも書けないなら**両方とも空にする**——
`merge` が対で落とす。

## 書き方の順序

1. `sections.mdna` を読み、**当期に何が起きたか**を掴む。増収か減収か、利益はどう動いたか、
   **利益の段（営業・経常・純）で動きが食い違っていないか**
2. `figures` を見る。**有報の文面と食い違うものがあれば、そこが一言になる**
3. `sections.risks` と `sections.issues` から、うまくいっていないことと今後の挑戦を拾う
4. **足りなければ Web を探す**（上限の範囲で）。直近の発表・採用の状況・**主力製品や
   ブランドの名前**（公式サイトの製品ページ）
5. `headline` を書く。**言い切る。** 「〜と思われる」「〜の可能性がある」で逃げない
6. `analysis` を書く。数値を並べたくなったら、**語で言えないかを先に試す**。
   **「新ブランド」「主力製品」「本体の事業」と書いたら、材料に名前が無いかを見る**
7. `summary` を書く。**ここには評価も解釈も入れない**
8. 規格に収める。**足りないから足す、ということをしない**——足りなければ空にする
