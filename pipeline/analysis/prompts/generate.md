# 要約と分析の生成（C9・#241）

1社につき**2つのものを書く**。規格が違うので、混ぜない。

- **要約** — 有報の4節に**書いてある事実**を、評価語なしでまとめる
- **分析** — 材料から**導ける解釈**を、評価を入れて書く。冒頭に一言

**1回で両方書く**のは原文を2回読ませないためであって、規格が近いからではない。
**書き分けられないなら、片方を空にする。**

**この文書だけを読めばよい。** ADR-0015・ADR-0016 の決定は下に取り込んである。


## この規格の育て方（**規則を足す前にここを読む**）

**規則は放っておくと厳しくなる一方になる。** 失敗は目に見えて記録され、そのたびに「次はこうしない」が1行増える。**通ったもの・良かったものは記録されないので、緩める側の力が働かない。** 実測でこの偏りは出力を壊していた——分析が要約に戻り、主観の語が減った。

**だから、規則を足すときは次の3つを守る。**

1. **足す前に、既存の規則で防げないかを確かめる。** 同じ事故の言い換えなら足さない。**規則の数ではなく、規則が読まれる順序が効く**。
2. **足すなら、同時に1つ緩めるか、緩める側の条件を書く。** 「〜しない」だけの追記は、**その規則が効かない場面**を併記する（`ただし〜のときは構わない`）。**例外の無い禁止は、書いた瞬間から過剰適用が始まる。**
3. **1つの事故から一般則を作らない。** 実例が1件しか無いなら、**その1件を判例として書き、規則にはしない**。3件そろってから規則にする。

**定期的に緩める。** 10回に1度は、この規格を通しで読んで**過剰に厳しくなった条項を緩める**。緩めた記録も docs に残す——**厳しくした記録だけが残ると、次に読む人は「厳しくするのが正しい」と読む。**

**「原文にこう書いてあるから」を、書き方の縛りに使わない。** 原文の表記・語順・区分の呼び方は、**事実が合っているかとは別の話**である。読者に伝わる書き方を選んでよい。


## 入力

`work/batch_NNNN.json`。`companies[]` の各要素が1社。

- `edinet_code` / `sec_code` / `name`
- `sections` — 有報の4節（`mdna` 経営者による分析 / `risks` 事業等のリスク /
  `issues` 対処すべき課題 / `sustainability` サステナビリティ。**節ごとに先頭を切ってある**）
- `figures` — **同じページが既に表示している数値**。平均年収・平均年齢・平均在籍年数・
  従業員数・業種・決算期・平均年収の10年推移・稼ぐ力（一人当たり経常利益）と業種中央値・
  残業と有給

## 出力

`work/gen_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json
{"edinet_code": "E02181",
 "summary": "……。……。……。",
 "headline": "業績は堅いが、平均年収は10年で13%下がっている。",
 "analysis": "……。……。……。",
 "sources": [{"url": "https://……", "title": "……", "accessed": "2026-08-28"}]}
```

書けないと判断したものは空文字にする。**無理に書かない。** ただし**要約と分析は対で出す**ので、片方だけ空にしても `merge` が両方落とす（spec 1.19・AC-28）。

## 材料

**要約が使えるのは `sections` の4節だけ。** 分析は4節＋`figures`＋**Web から取得した文書**を使える（ADR-0015 決定2）。

- **切った版に無いことは書かない。** `pipeline/data/analysis_text_2026.csv`（切らない版）を**自分で読みに行かない**——機械ゲートは通ってしまうが、**検証パスは切った版だけで判定する**うえ、切った版しか無い環境で再現しない。節が途中で切れていて書きたいことが書けないなら、**書ける範囲で書く**
- **切れた述語を補ってよいのは、続きが一意に定まるときだけ。** `…身近な風土であ` は続きが「である／であり」しかなく**時制も態も一意**なので `身近な風土になっているとしており` と受けてよい。`…注目を集` は「集めた／集めている」で**時制が確定しない**ので補えない。**切れた文を丸ごと諦めるのではなく、完結している成分を探す**——`30周年のイベントを実施している『ポムポムプリン』が注目を集` の連体修飾は完結しているので、`『ポムポムプリン』は30周年のイベントを実施している` とは書ける
- **社名に入っている語を、会社の性格として書くときは、それが一般に通っているかを見る。** **要約では原文に閉じる**（原文に書いてあることの規格だから）。**分析では、一般に通っている事実なら書いてよい**（プレス工業がプレス加工をしていることは一般に通っている）。**止めるのは、社名から連想しただけで裏が取れないとき**——要約で `プレス加工を軸に` と書くなら、4節に `加工` が0件である以上その修飾は落とす。**社名が正しそうに見せるので気づきにくい**
- **原文にその語があることを根拠にしない。掛かり先の範囲まで確かめる。** `有機、無機、バイオの技術知見` が掛かるのが `新規事業創出については…` の側なら、会社全体の性格として冒頭に置くのは**原文が一段下に閉じて述べているものを上位で書く形**になる。**語の存在ではなく、その語が原文でどこまでを覆っているかを見る**
- **業態を名乗る語は4節に無いことがある。** `化学メーカー` が0件で `メーカー` の唯一の用例が子会社の説明なら、そこから自社を名乗ると主体が滑る。**製品の列挙から括り直すのが安全**だが、**括りから外れる製品が残るので `など` で開く**。**動詞は要約自身が各部門で使っているものに揃える**——原文の `製造` が子会社の文脈にしか無いなら `製造・販売する` は全社に掛けられない
- **Web から取れるのは会社自身が出しているもの**——公式サイト・ニュースリリース（PR TIMES 等の配信サービスも可）・採用求人（HRMOS・Indeed 等も可）。**出しているのは会社自身なので、配信サービスや求人サイトを理由に落とさない**
- **年収まとめ記事・転職メディア・個人ブログは材料にしない。** 実測で「ファナック 採用 初任給」の上位8件中5件がこの型で、**平均年収を互いに違う値で書いている**——有報から出している数字と食い違うものを材料にすると、有報ベースだという立て方が崩れる
- **報道記事も本文の根拠にしない。** 会社自身の発表があるならそちらを当たる
- **会社が自分で言っている評価は帰属を付ける。** 「業界シェアNo.1」は材料の条件を満たすが、地の文で書くと我々の評価になる（「同社はシェア首位としている」）
- **記憶から数値を補わない**（ADR-0016 決定3）。**文脈・語の説明・相場観・固有名詞は記憶から書いてよい**が、**金額・率・順位・シェア・従業員数は材料にあるものだけ**。数字は事実の顔をして出るので、外れたときの害の形が違う（読者は同じページの表と見比べる）
- **使った URL は `sources` に全部入れる。使わなかった URL は挙げない。** 4節と `figures` だけで書いたなら空でよい
- **期末後の出来事を当期として書かない**（`figures.period_end` が決算日）
- **取り方の線**（ADR-0008 決定1）— UA を偽装しない。ヘッドレスブラウザを使わない。403・503・画像認証・WAF のチャレンジは**明示的な拒否**として受け取り、その材料は使わない。**転載しない**
- **業界の常識は「名詞」なら通るが「主張」なら通らない。** 「**窯を止められないまま**」は、「窯」という一般名詞は通る（ADR-0016 決定3）が、「止められない」は**連続運転＝固定費構造という含意を持つ主張**で、材料には「止め」も「稼働率」も「固定費」も0件だった。**一般名詞に業界知識由来の述語を付けない**
- **費用が上がったことは書いてあっても、値上げをしたことは書いていない。** 材料が `原材料価格や物流費の上昇等により減益` としか書かず `値上げ` `価格転嫁` `販売価格` `単価` が0件なら、「値上げでは吸収しきれていない」は業界の型から補った話になる。**費用・需要・利益は材料の語で書き、そこから会社の打ち手を逆算しない**
- **新旧の計画で分野の並びが変わったら、差分の向きを確かめる。** 旧が `エネルギー・情報通信・モビリティ`、新が `デジタル・AI・エネルギー・モビリティ` なら**情報通信は入れ替わりで外れている**ので、「デジタル・AIを加えた」は入れ替えを足し算として書いた誤りになる。**当期にその分野が伸びたことと、次の計画がそこを注力分野に置くことは別。両方の並びを書き出して差を取ってから書く**
- **表から引くときは、その表が持っている列だけを書く。** 相手先別販売実績の表（相手先名・金額・割合）に**その相手先が海外かどうかは書かれていない**し、生産実績の表の「会社所在地」は**そこで開発や販売もしていることを意味しない**。**表は列の名前どおりのことしか言っていない**
- **並列列挙を因果で結ばない。** `人口減少、人材確保の難化、工場の海外移転・操業停止等の事象が発生した場合` は並べているだけで、「人口減少に伴う人材確保の難化」ではない。**リスクの節は事象を列挙するので、隣り合うだけで因果に見える**。「や」でつなぐ
- **損益に効くものを、収益の減少の理由にしない。** 持分法投資利益の減少や関連会社株式の減損は**損益に効くもので、収益の減少とは段階が違う**。表の数字と本文の要因は、**どの段階の話かを見てから結ぶ**
- **原文が2つの述語で書き分けているものを1つに潰さない。** `次世代リーダーやスペシャリスト育成を**強化**し、チャレンジ人財育成を**計画的に推進**してまいります`——**「計画的に推進」が掛かるのはチャレンジ人財育成のほう**。**述語が2つ並んでいたら、掛かる相手も2つある**
- **資金の充当先を、原文が結んでいる先だけに結ぶ。** 長期借入金の増加の理由が `新工場建設に伴う資金調達により` の1つだけなら、投資有価証券の取得まで結べない。**「その」が直前の2つを受けてしまう**
- **地理や範囲を、市場データの記述から会社の話に移さない。** 「首都圏」が出るのが市場データの記述だけなら、当社の営業エリアとして「首都圏を中心に」とは書けない（材料はむしろ `営業エリアの拡大` と逆向きだった）。**業界の相場観から補ったものは、材料の中に同じ語があっても根拠にならない**——その語が**誰について書かれているか**を見る
- **会社の構造を、表の形から推測して書かない。** グループ別の表と `figures.employees` = 129人だけを根拠に「持株会社に在籍する人たちの数字」と書くと、4節に `持株`・`子会社` が0件のまま構造を主張することになる。**数値の読み方に留める**——「提出会社に在籍する129人の数字で、グループ全体の水準ではない」なら材料の範囲に収まる
- **原文の中で語と数値が食い違っていたら、帰属を付ける。** 原文の語が `取扱高は軟調に推移しました` でも**同じ段落の表が前年同期比 +7.6%** なら、地の文で断定すると **+7.6% を軟調と判断したのが我々になる**。「会社は『軟調に推移した』としている」と帰属を付ける
- **将来形と既存を1つの述語で束ねない。** 課題の節の `仕組みを作ります`（これからの戦略）と `「PLAJEX」のグローバル展開を図ります`（既存）を1つの `手がける` で束ねると、**同じ一文の中で支持の強さが割れる**。文を割って「戦略に掲げる」「展開を図るとしている」と書き分ける
- **材料が前期比を持たない残高に、増加を含意する語を当てない。** 受注残高が絶対値だけで前期比が無く、受注高 < 売上高なら**当期は取り崩されている**——「積み上がった受注残」は書けない。**残高には向きの語を当てない**
- **並列に置き直しても、1文に並べば対応関係が読める。** MD&A の `孫会社である INFORICH ASIA HONG KONG LIMITED の事業拡大` と、課題の節の `海外CHARGESPOT事業は…成長を牽引するセグメント` を1文に並べると、**海外事業をどの会社が担っているかは書かれていないのに読者は「海外事業＝その孫会社」と読む**。**別の節にある別の事実は、文ごと分ける**
- **1文に並べると、後半が前半の区分の中身に読める**（上の型の再発）。`表面波フィルタ製品に係る事業において` の減損は**全社の利益の要因**として置かれており、そのセグメントに属するとは書かれていない。文を分けて「利益にはこのほか、…も効いている」と全社の話に戻す
- **区分名・サービス名と、別の節にある概念や事実を結ばない**（同じ型の3つ目）。「科学的人事」を推進すると原文が書いているのが**当社グループか節そのもの**なら、`「タレントパレット」は…科学的人事を実現するサービス` とは書けない
- **句点で割るだけでなく、間に別の文を挟んで隣り合わせも解く**（同じ型の4つ目）。リスクの節の `一般得意先向け売上高は…約6割` と MD&A の `屋内線工事が順調に進捗` を並べると、**屋内線工事が一般得意先向けかどうかは書かれていない**のに対応が読める。**挟んだ文が別の対応を作っていないか**も当て直すこと
- **同じ会社が2つの切り方で区分を持つとき、どちらの並びかを毎回書く。** 報告セグメント（通信キャリア／都市インフラ／システムソリューション）と中期計画の3区分（通信インフラ／社会インフラ／システムソリューション）は**綴りが違い、同名なのは1つだけ**。原文が `三つの事業セグメント（…）` と括弧で並べているなら**括弧ごと写して両方の並びを字面で出す**。**片方を言い換えて揃えない**
- **セグメント別の文が並んだ後の締めは、主語を書かないと直前の区分に読まれる。** 「鉄鋼は…」「アルミ板は…」と並べた後の `営業利益・経常利益とも前期を下回った` が全社の値なら、**「全体では」と主語を戻すだけで解ける**
- **括弧の中の限定を落とさない。** `本線上(建設区間)の自動飛行(レベル3.5)の実証実験` から括弧を落とすと**供用中の高速道路でドローンを飛ばした**と読める。**括弧は補足ではなく条件のことがある**ので、括弧ごと写すか、括弧の中身を地の文に入れる
- **括弧が「申請」と「取得」を分けていることがある**（上の規則の続き）。`独自技術（特許申請済み）` を「独自技術」とだけ書くと、直前の `特許取得済み` の技術と並んで**取得済みと読める**。**範囲（`日本・米国・欧州`）には注意が向いても段階には向かない**ので、**括弧の中が名詞1つでも読む**
- **推移の年数は `salary_history_yen` の点の数で言う。** 9点（2017〜2025）しか持たない社に「10年で」は書けない——「2017年から」と左端を年で名乗る。**10点そろっている社の「10年前」は通る**（画面の見出しが「平均年収推移（過去10年間）」で、その左端がまさに10年前の年になる）
- **探す量の上限は、1社あたり検索2回・取得3ページ。** **材料が薄い会社は薄いまま書く**——埋めにいけば記憶から補うことになる

## 要約の規格

**答えるのは「この会社は何をしている会社か」であって、「当期の業績はどうだったか」ではない。** 読むのは**求職者**で、投資判断のために読む人ではない。**売上高と利益の推移は C10 が別途チャートで10年ぶん出すので、ここで厚く書かない。**

- **業績の数値から書き始めない。**「当連結会計年度の売上高は…」の形にしない
- **数値は原則として書かない。** 業績に触れるとしても**1文まで**で、そこでも「増収増益だった」のように語で言う。**機械ゲートが数を数える**（カギ括弧の中の固有名詞は数えない。`一太郎2025` は名前であって量ではない。**二重カギ括弧も同じ**——作品名は有報がこちらで書く）
- **拾うのは、その会社が何をどう作って誰に届けているか。**
  - **商品名・サービス名・ブランド名**を出す（「新サービス」ではなく名前）
  - それが**誰に何を提供しているか**（「幼児から高校生まで全16学年の通信教育」）
  - **当期に何を出したか・始めたか**（新製品、新コース、新拠点）
  - 会社が掲げている**考え方・こだわり・これからやろうとしていること**
  - **人にどう向き合っているか**（人的資本の節）。**制度名や重要テーマの名前だけを並べない**——「ひとづくり」はテーマの名前で、読者には何も分からない。**実際にやったことが書かれている箇所を探す**（「外国人運転士を受け入れて育成している」）
  - **リスクは、そこで働くことに関わるものだけ**（人材の確保、事業環境の変化）
- **全角200〜700字 / 3〜10文**（**500字前後を目安に。上限に近づけない**）
- **計画と方針に偏らせない。** 課題の節は施策と計画の列挙なので、そこから拾うと後半が計画名の並びで終わる。**いま何をどう作って誰に届けているかを先に置き、計画は最後に短く**
- **材料が制度と枠組みばかりの会社では、セグメントごとの「機会」の欄を読む**——「天然ガス・LNG」「デジタルインフラ」のように、**どこで稼ごうとしているかは具体で書かれている**。記載の仕組みの説明（「経営者は…を挙げている」）で埋めない
- **評価語を含めない**（「業界最大手」「高い収益性」「優れた」「急成長」…）
- **カギ括弧の中の評価語は数えない。** 作品名・製品名・計画名に評価語が入っている型（`『ナンバーワン戦隊ゴジュウジャー』`）を落とすと、**具体的に書くほど機械が止める**という逆向きの圧力になる。**カギ括弧に入れれば評価語が書けるわけではない**——地の文の評価語はそのまま落ちるし、原文に無い括弧の中身は「原文に無い固有名詞」で落ちる
- **原文の自称の語でも、評価語なら機械ゲートに落ちる**（「創業以来の**強みである**伴走型…」）。**言い換えれば残せる**（「創業当初から続く」）——**評価の語を落とすために事実ごと捨てない**。`gate_reasons.jsonl` の `文を落とした` は、社が落ちていなくても読む
- **社名・子会社名・ブランド名は書いてよい**（`東急電鉄㈱`・`楽天市場`・`太陽ファルマ` もそのまま）。**ただし見出しに社名が出ているので、文頭で名乗り直さない**
- **原文に現れない固有名詞を含めない。固有名詞は原文の表記のまま写す**（`㈱` を `株式会社` に展開しない——展開した瞬間、原文に無い固有名詞になって文ごと落ちる）
- **1文に詰めると主語が滑る**（型④）。「株式会社メルコインは暗号資産取引サービスを提供**し**、…『メルカリ ハロ』で雇用仲介事業に**も参入した**」——**原文の主体は当社グループ**なのに主語が引き継がれて読める。**子会社名が並ぶ要約では起きやすい。文を割るか、主体を書く**
- **処分や事案ごとに主体が違うなら書き分ける**（同じ型の縮小版）。原文が「自動車保険金不正請求は当社および損保ジャパン」「情報管理は損保ジャパン」と分けているなら、束ねない
- **「区分が1つである」は書いてよい。「セグメント別の記載を省略している」は書かない**（型⑪が止めたいのは**有報という文書の作法の説明**で、読者にとって情報量が0の文）。**主語を「報告セグメント」にしない**（開示の話に寄る）。**「単一セグメントとして運営している」も言い過ぎ**——原文が言っているのは開示上の区分である
- 文体は常体。**ここには評価も解釈も入れない**——それは分析の仕事
- **原文が結んでいない因果を、要約が締めない。** `諸施策を着実に実行してまいりました。その結果、…経営成績は以下のとおり` が括っているのは経営成績の全体で、受注高18.1%増を施策の結果として名指してはいない。**規則は書いてある節にしか効かない**ので、分析の側で禁じたことは要約でも確かめる。直し方は「〜し、〜した」を**並列にする**だけでよい
- **原文が分けている帰結を、1文に潰すときに一方へ寄せない。** 原文が2文で貢献先を分けている（4分の3が空き家 → 空き家問題の解決／半額程度の住宅 → 暮らしの実現）のを1文にまとめると、**片方の帰結が落ちて両方が一方の帰結に掛かる**。因果を発明したのではなく**並んだ2文の帰結を一方へ寄せた形**。**繋ぐ前に、原文でそれぞれが何に掛かっているかを当てる。原文が分けているものは分けたまま写す**

### 何を拾うか——ジャストシステムの原文で

原文が書いているのは、日本語ワープロソフト「一太郎」等のパッケージソフトと「ATOK Passport」「スマイルゼミ」等のクラウドサービス、ECサイト「Just MyShop」の運営、「スマイルゼミ」が幼児から高校生まで全16学年の学びを提供していること、AIを活用した対話で導く教材「Coachez」の提供開始、米国向け「Smile Zemi」の Grade K 開講、そして「高機能で付加価値の高い商品・サービスを提供することにこだわり」という会社の言葉である。

**拾うのはこの側**——サービスの名前、それが誰に何を届けているか、当期に何を出したか、会社が何にこだわっていると言っているか。**同じ会社の売上高・営業利益・その増減率は、この要約には要らない。**

## 分析の規格

### 誰に向けて、何を書くのか（**書き始める前にここを読む**）

**読者は求職者である。**「この会社に入るとどうなのか」を知りたくて開いている（ADR-0015・`docs/company/intent.md`。マネタイズは転職マッチング）。**年収が高いか低いかは表が示している。** 読者がここで求めているのは、**その水準が続きそうなのか、会社が伸びているのか畳んでいるのか**——有報の本文を数万字読める人にしか分からないことである。

**書くのは「事実から導かれること」で、事実そのものではない。** ADR-0015 は**「有報の無機質な情報を多面的に読み、求職者に分かりやすい形へ消化することがこのセクションの狙い」**と書いている。三陽商会の有報を素直に読むと「最終利益は増えた」で終わり、それが保有株の売却益だと気づくには営業利益・経常利益・純利益の動きを突き合わせる必要がある。**その突き合わせを代わりにやることが、ここで言う「意味付け」の中身である。**

**ADR-0015 は「原文の並べ替え」を明示的に却下している**（理由は「**作れるのは原文の並べ替えだけで、読者の負担が減らない**」）。**次のような文は分析ではなく、要約である**——

> ~~一方の基礎化学品は、住宅着工の伸び悩みと中国からの安価な輸入品の流入で売上が1割以上減り、営業利益は半分以下になった。~~

**これは有報に書いてあることをそのまま並べただけで、読者は何も受け取っていない。** 同じ材料から書くべきなのは、**どの部門に配属されるかで見える景色がまるで違う**／**縮んでいる側は当面おそらく人を増やさない**／**伸びている側の増員は市況に乗っているだけなので、市況が返れば止まる**といったことである。**事実を並べるのではなく、事実が求職者にとって何を意味するかを言い切る。**

**推測してよい。むしろ推測がここの仕事である**（ADR-0016 決定1）。因果・評価・見通し・重み付け・比較・含意を**言い切る**。**「〜と会社は説明している」「〜としている」で逃げない**——それは要約の書き方で、分析でそれをやると2つ持つ意味が消える。**外れる推測が1つ混ざる損より、踏み込みが1つ減る損のほうが大きい。**

**有報だけに閉じない**（ADR-0015 決定3）。**求職者が知りたいことの多くは有報の外にある**——いまどんな人を募集しているか、直近に何を発表したか。**公式サイト・ニュースリリース・採用求人はどれも会社自身が出している一次情報**で、有報と出所の性質は変わらない（PR TIMES・HRMOS・Indeed のような配信サービスも落とさない）。**使った URL は `sources` に残す**——読者が開いて確かめられることが、材料を有報の外へ広げてよい前提になる。

**外部を取りに行くのは既定の手順である。** 実測で、最初の100社では26%が外部情報を使っていたのに直近650社ではほぼ0%になっていた。**「4節と `figures` で書けたから取りに行かなかった」は、狙いに照らすと理由にならない**——有報だけで書けるのは有報の言い直しである。**採用ページと直近のリリースは、少なくとも見に行くこと。**

**本文の1文目を、事実の記述から始めない。** 見出しで言い切ったのに、本文に入った瞬間「◯◯は減収で」と事実へ戻る型が実測で6社中6社に出た。**1文目は判断である。** 事実は、判断を裏づける従属節に落とす（`関税の負担まで吸収して1割以上伸ばせるということは、値決めの力がある` のように）。

**数値と事実は、主張の裏づけとして従属節に置く。** `営業利益を1割以上伸ばした。` と単独の文で置くと、それは要約の文になる。**主張が主節、数値が従属節**。この向きが逆になっている文が本文に3つ以上あれば、その分析は要約に戻っている。

**自社の計画の `〜します`・`〜してまいります` を実施として書かない。** 「業界一般に『求められている』ことを当社の実施として書く」型と同じ形で、**分析では止めたのに要約では止まらなかった**例がある（`全社に拡大します` を `広げている` と書いた）。**要約でも分析でも同じ線を当てる。**

**そのうえで、主従の向きを見出しにも当てる。** **求職者が知りたいのは数字や事実ではなく "So What?" であり、分析はそれに答えるものである。** 主張（推測・意味づけ・重み付け）が**主**で、事実は**その補足として書いてもよい**もの——この順番が逆になっている限り、どれだけ言葉を選んでも「だからなに？」で終わる。

**同じ会社の見出しで、運営者が良いほうと悪いほうを名指しした実例**（住友商事）——

> **良い**: 過去最高益を更新したが、それを作ったのは本業の伸びよりも税負担の軽さである。
> ~~**悪い**: 過去最高益の中身を開くと、税引前の利益は前期とほとんど変わっていない。~~

**悪いほうも「中身を開くと」で解釈を装ってはいるが、言っているのは「税引前利益がほぼ横ばい」という事実1つだけである。** 良いほうは同じ材料から**何が利益を作ったのかという重み付け**まで降りている（本業ではなく税負担）。**事実を1つ提示して読者に解釈を任せるのは、分析ではない。**

**"So What" の階段を、少なくとも2段降りる。**

1. **有報に書いてある事実**（税引前利益は前期並み、当期利益は過去最高）
2. **そこから読める会社の力学**（最高益を作ったのは本業ではなく税効果で、この押し上げは毎年続くものではない）
3. **求職者にとって何を意味するか**（この会社の「過去最高益」を業績の勢いとして受け取ると、入ってから見る景色と食い違う）

**1段目で止まった文を本文に残さない。** 2段目まで降りていれば主張になっており、3段目まで降りれば読者に届く。

**判定は述語で見る。** 文の末尾が `〜増えた`・`〜計上した`・`〜掲げている`・`〜である（数値）` のような**事実の記述**で終わっていれば、その文は1段目にいる。**主節が事実の記述で終わる文は、本文全体で1つまで**（従属節に入っている事実は何個あってもよい——むしろそれが正しい置き方である）。

**この線の緩和として、事実の正確さのために文や句を足しにいかなくてよい。** 主張に要らない区分の明示・範囲の限定・時点の断りは省いてよい（**書いた事実が誤っていれば落ちるのは変わらない**が、「誤りを避けるために事実を増やす」のは向きが逆である）。**`figures` の指標を消化する義務も無い**——使わない指標は書かない。

**この線が効かない場面**——**要約には当てない**（要約は1段目に留まるのが規格である）。また、**見出しの前半で事実を置き、後半で主張へ折り返す形は良い**（住友商事の良いほうがまさにそれで、`過去最高益を更新したが` は主張を立てるための足場である）。事実を置くこと自体が禁じられているのではなく、**事実で終わることが禁じられている。**

**帰属で言い切りを避けない。** `〜としている`・`〜と説明している`・`〜と書いており` は要約の書き方で、**機械ゲートが2個までに制限している**。会社の言い分をそのまま渡すのではなく、**それをどう読むかを書く**——`会社は構造改革を進めるとしている` ではなく `畳む側と張る側を選び分けている`。

**求職者に向けた語を出すことを避けない。** `入る側から見れば、製造業の現場の業務知識と製品開発の両方を同じ製品で長く積める職場で、会社自身も採用サイトで「育成する風土」を掲げている`——**読者が誰なのかが文面から消えている分析は、狙いを外している。**


- **`headline`** — 全角12〜75字の**1文**。その会社が**いまどうなのか**を言い切る
- **見出しが指す範囲を、本文と別に読めるようにしない。** 本文の根拠が5年幅（+54.2%）なのに直近1年が +0.6% なら、**見出しに範囲が無いと当期の話として読まれる**——読者は同じページの推移と突き合わせるので、そこで割れる。「5年で伸びた分を、そのまま給与に回してきた会社である」と**範囲を入れれば済む**
- **見出しで指標を違う統計名に言い換えない。** `figures` が渡すのは `industry_median_profit_per_employee_yen`＝**業種中央値**なので、「化学の平均」と名乗らない。**この指標を平均と呼ばないのはリポジトリの方針でもある**（平均だと業種の代表値が最上位の1社に引きずられる）
- **見出しだけが外れる型が14回。書き終えたら、見出しと本文を並べて突き合わせる。** 落ちたものはどれも**本文が正しく、見出しだけが外れていた**。**向きは2つある**——「見出しが本文より広がる」（本文は正しいので、本文を読んでいる限り気づけない）と、「見出しに本文の支えが無い」。**14の型は次のとおり。**
  1. **範囲**——本文の根拠は5年幅なのに見出しに範囲が無く、直近1年の動きと割れた
  2. **統計名**——本文は「業種中央値」、見出しは「化学の平均」
  3. **限定の指標名**——未達は ROE だけなのに、見出しが「目標未達」に読めた
  4. **掛かり先**——原文が3領域に掛けている1兆円を、見出しが2領域に絞った
  5. **範囲がふたたび**（本文「サービス売上の9割程度」→ 見出し「売上の大半」）と**修飾の掛かり先**（「一人あたりの」が2つ目の指標まで掛かった）
  6. **範囲を書かなかった**——「伸びの多くは委託手数料から」は受入手数料に対しては75.9%だが営業収益全体に対しては46.6%。**見出しに「受入手数料の」と書けば済んだ**
  7. **区分名を落とした**——原文のセグメント名は「グローバルすき家」で海外を含む。国内単独の損益は材料に無い
  8. **限定語を落とした**——原文は `次世代半導体パッケージの**パイロットラインの**立上げ`。落とすと量産ラインの立上げに読める。**この8つ目は、見出しを直す作業そのものが作った**——**見出しを直したら、直した理由とは別に、もう一度「本文より広い語になっていないか」を当てる**
  9. **段の数を超えた総称**——材料が持つ段階は営業・経常・純利益の3つだけなので「利益は全段階で」とは書けない。3段を名指しすれば済む
  10. **結び先**（直した見出しから出た）——原文は `分譲マンションの開発用地の取得資金、賃貸不動産の購入及び建設資金` で、**建設資金が結ばれているのは賃貸不動産のほう**
  11. **向きの含意**（同上）——受注残高が絶対値だけなら「積み上がった」は書けない。原文の語（`高水準の受注残高の寄与等により`）に寄せる
  12. **程度の語**——「大きく上回る」の目的語を絞ると 1.075倍を「大きく」と言うことになる。**程度の語は、その語が掛かる目的語の数値で確かめる**
  13. **本文に支えが無い**——見出しの後半が材料には当たっていたが、**本文はその意図を一度も述べていなかった**。**見出しの語の支えは、材料ではなく本文の中に名指しできること**。直し方は**本文の側に支えを足す**（見出しを削らない）
  14. **見出しだけが因果を作った**——「…が…を呼んだ」に対応する記述が本文にも材料にも無い。**語ではなく係り受けそのものが材料を超える**ので、**材料が別の理由を明示しているときは、見出しが作った因果のほうを外す**（本文に支えを足す形では解けない）
  - **14 は再発する。** 「災害復旧が重なり、売上より利益が大きく伸び、原価率も良化した」は、利益が売上より伸びた理由を原文が別に明示している。**見出しに3つ以上並べるときは、先頭の要因がどこまで掛かるかを1つずつ確かめる**
  - **量の対応を含意する語を使わない**（その直しが作った7度目）。「採算管理を重ねた**ぶん**利益はそれ以上に伸びた」の「ぶん」は量の対応を含意するが、原価率の改善は0.2ポイントで33.7ポイント差を説明できない。**並置か、掛かりの弱い語（「〜も加わって」）にする**
  - **支えは向きまで合っていること。** 「転身が**進んでいる**」の支えに足した本文が「これから測られることになる」なら、**進捗の断定ではなく留保**で支えにならない。**自己修正で足した文こそ、向きを当て直す**
  - **自己修正が別の広げ方を作ることがある。** 主語を補うとき「銀行業における」を「グループでは」にすると**主体が一段広がる**。**補う主語は原文の語をそのまま使う**
  - **1文を直したら、その文が支えていた対比の相手も当て直す。** 第2文をラジオに限定したら、第1文だけが残ってテレビ放送収入の増加が隠れた。**直した文が対比の片側だったときは、もう片側が単独で立って誤読にならないかを見る**
  - **この3段の確認は効いている**（書きながら自分で直した見出しの大半は検証を通っている）。**書き終えてから全部の見出しに当て直し、直した箇所こそもう一度当てること**
  - **見出しは本文の後に書かれるので、本文で守った限定がそこだけ抜ける。** 見出しの語ひとつずつに「本文のどの文が支えるか」を当ててから出す
- **比較の言明には指標を書く。** 「前期を下回ったのは不動産事業だけ」が真なのは**セグメント利益**で、完成工事高では土木も下回る。「セグメント利益で」の一語で解ける
- **文を割って主体を直すときは、後ろの文の主語を書く。** **日本語の省略主語は直前の主語を引き継ぐのが既定**で、「当期は」のようなトピックの立て直しだけでは消えない。**「当社は」と書けば消える**
- **読者が足し引きできる数値は、原文の枠組みで書く。** 収支ベースの2つを差し引くと △259億なのに経常利益は +170億、という形になるのは、**MD&A 自身が収益・費用ベースで説明している**ため。**原文の枠組みで書けば足し引きが合う**
- **支えは区分まで合っていること。** 見出しの「漁獲」の支えに足した記述の主語が別の事業のものなら、**語も向きも合っていても支えにならない**
- **段落の中でだけ成り立つ言明を、全体に広げない。** `全ての市場において` が国内市場の段落の中にあるなら、海外まで含む形にはできない。**「全ての」「いずれも」のような総称の語は、原文でそれがどの段落に置かれているかを見る**
- **区分名を言い換えると一部が落ちる。** 「流通・交通市場」を「店舗」と言い換えると交通が落ちる。**セグメント名は原文の語をそのまま使う**
- **限定語を外すだけでは、直前の文が主題として引き継がれる。** 「個人には…」の次の文から「法人には」を外すと個人の話として読める（逆向きの限定になる）。**原文と同じ順に文を入れ替えて解く**
- **本文に帰属を付けたら、見出しにも付ける。** 本文を「〜と会社は説明している」に直したのに見出しが断定のまま残る形。**直しは見出しと本文の両方に効いているか確かめる**
- **表は行だけでなく列も見る。** 4つが並ぶのが機会の行の**「現在の取り組み、対応方針」列**なら、それは事業機会として挙がっているものではない。**同じ行にあっても列が違えば別のことを言っている**
- **一部だけが下方なら「見直された」と総称しない。** 経常利益とROEが下方でも売上高が上方なら、頭の「目標も」が全目標を受けてしまう。**限定は主語に置く**
- **計画の目標と当期の実績を比べるときは、目標の年度を示す。** 目標が最終年度の値で当期が途中年度なら、年度を書かないと未達が計画割れに読める。**「最終年度に掲げる」のように時点を語で示す**（算用数字の上限が近いなら年度そのものを書かなくてよい）。中間年度の予想と取り違えていないことも、目標表の列で確かめる
- **2つの区分を束ねるとき、片方だけの定義で括らない。** `業務そのものを引き取ります` が定義しているのが片方だけなら、**両方に掛かる語を原文から取る**（定義の見出しを1対1で拾って「システム運用や業務プロセスを受託する側へ」）。**販売実績が合算されていて分けられない区分ほど、束ねる語を自分で作りたくなる**
- **業界の課題を会社に帰属するときは「業界の」を落とさない。** `建設業界におきましては、…構造的課題を抱えており` は業界についての記述で、「会社自身が挙げる」だけでは**その会社の課題として挙げている**と読める。**帰属の語は、誰が言ったかと、何について言ったかの両方を写す**
- **指示語は主体だけでなく対象も滑る。** 品目を4つ並べた次の「その生産は…へ委託している」で、原文が委託を述べているのが一部の製品だけなら範囲が広がる。**指し先を書き出して、原文が言明を与えている範囲と一致するか確かめる**——一致しないなら指示語をやめて範囲を名指しする
- **原文が別の語で括っているものに、内訳を掛けない。** `都市ガス販売量は、家庭用…業務用…` の内訳に対し `総販売量` は `他のガス事業者向け卸供給を含めた` 別の概念。**内訳が並ぶ文の主語は、その内訳を持つほうの語から取る**
- **増減を並べるときは、挙げた区分の外を確かめる。** **増減の一覧を作ってから、どちらの側が網羅かを決める**——網羅でない側は「など」で開き、**網羅している側には付けない**（付けると存在しない区分を含意する）
- **並列の「や」でつないだ2つに、材料が一方にしか与えていない述語を掛けない。** 「水素や炭酸ガスも販売を伸ばしている」は、原文が販売数量の拡大を書いているのが水素だけで、炭酸ガスには逆向きの制約があった。**機械ゲートでは絶対に止まらない**（どちらの語も原文にある）。**並べる前に、述語が両方に当たるかを1つずつ確かめる**
- **`profit_per_employee_yen` を「当期と時点が食い違って読めるから」で見送らない。** **この指標は定義からして5期の中央値**なので、当期の損益に触れる分析なら**どの会社でも使えてしまう理由**になる。見送ってよいのは**3条件だけ**（①③④。②は欠番）で、うち時点に関わるのは条件④——**同じ側に落ちるなら倍率がどれだけ離れていても書く**
- **4節の中で同じ出来事の時点が割れていたら、日付を持つ記述を採る。** MD&A が逐語で当期の出来事のように書いていても、課題の節が同じ製品の提供開始を期末後と日付で書いていればそちらが正。**逐語であることは時点の根拠にならない**
- **`analysis`** — 全角120〜500字 / 3〜10文。「うまくいっていること」「うまくいっていないこと」「今後の挑戦」を**地の文で**書く。見出しを付けて箇条書きにしない
- **評価語を書いてよい。これが本体である**
- **推測してよい。むしろ推測がここの仕事である**（ADR-0016 決定1）。因果・評価・見通し・重み付け・比較・含意を**言い切る**。材料が明示していなくても**そう読めるなら書く**——「労務費と資材価格の高騰が利益を削っている」「会計処理の変更を差し引いても縮小は続いている」「待遇がそろっている分だけ入り口の競争は厳しい」は**どれも書いてよい形**である
- **「〜とみられる」「〜だろう」で逃げない。** 読者はこれが AI の分析だと分かって読む（C10 が断りを置く）。**逃げの語尾は、踏み込みを避けた分だけ読者に渡るものを減らす**
- **業界の文脈や一般的な知識を書いてよい**（ADR-0016 決定3）。**数値だけは材料にあるものに限る**
- **段階評価にしない。** 「好調」「安定」「不振」のような語彙から選ばない——**語彙は自由で、観点だけが固定されている**
- **「材料」と書かない。読者はこの語を知らない。** 有報にそう書いてあることを示すなら **「会社は〜と説明している」「会社自身が〜」**（商材としての「材料」——半導体材料・原材料——はそのまま）
- **算用数字は合計5個まで**（`headline` ＋ `analysis`）。機械ゲートが数える。**少ないほど良い**（良い例5つの実測は0〜2個）。**分数は2個ぶん数えられる**（`digit_runs` が分子と分母に別々に当たる）——「3分の1近くまで縮んだ」は「大きく縮んだ」で足りる
- **同じ業種の会社を、同じ一言の型で書かない。締めの言い回しも揃えない。** 中身が別でも、一言や締めが同じ形だと読者には同じ会社に見える——**その会社にしか当てはまらない一言**を探す。**書き終えてから並べて確かめる**
- **揃いは「中身」ではなく「枠」で出る。中身を入れ替えても枠は残る。** 見出しの話題を1社だけ差し替えても**6本中5本が「Ａだが Ｂ」の逆接対比のまま**だった回がある。**見出しは構文から散らす**（逆接対比／体言止め／断定短文／並列／状態の提示）。分析の書き出しと締めも同じで、主題を替える前に構文を数える
- **`verify.md` の書き直し表に載っている誤りが、同じ会社で再発する。** **表に載っている社を書くときは、その行を先に読む。**
- **逆接語を消しても、対比は文の並びに移るだけ。1社は「対比を使わない」を割り当てる。** 逆接語をゼロにしても**対比フレームは 6/6 のまま残った**回がある。逆接語は語、対比は骨格。**単系列で押す・時間軸で追う・1つの指標を掘り下げる社を必ず1つ作る**
- **散らし方が均一なら、それ自体が揃い。** 「読点0の文が6社ちょうど1本ずつ」のように、**散らした証拠として数えている当のものが全社同じ本数なら指紋になる**——本数も社ごとに変える（0本の社・2本の社を作る）
- **`figures` の数値に触れる文を、全社で末尾に寄せない。** 「本文 → 最後に画面の数値」という段取りが6社同型になる。**数値に触れるなら中盤に置く社・冒頭で使う社を混ぜる**
- **要約の文数も揃う。** 分析側の散らしに気を取られると要約が6社中5社で7文になる。規格の範囲（3〜10文）の中で、**社ごとに文数を変える**
- **主語の揃いも位置で出る。「会社」を主語にした文を全社の同じ位置に置かない。** **会社の意図に触れない社を混ぜる**か、触れるなら位置と主語の形（事業を主語にする・目的語から入る）を変える
- **いちばん深いのは骨格の揃い。位置や文の作りを散らしても残る。** **①第1文＝全社の総括 → ②〜③要因 → 逆接語で折り返し → 末尾に目標／指標** が6社そろった回がある。**総括から入らない社・要因から入る社・逆接を使わない社を混ぜる。** 「判定を下す一文の位置を散らした」という自己申告は**どの文を「判定」と見るかに依存する**ので当てにならない——**第1文が全社で同じ働きをしていないか**を先に見ること
- **文の作りは、社間だけでなく社の中でも散らす。** 読点0の文と3個以上の文が4社に集中し、残る2社は全文が読点1〜2、という形になる。**社間で散らしても、社の中が単調なら読者にはその社が単調に見える**
- **手や位置を散らしても、文の作りが揃う層が残る。** 見出し6本すべてが読点ちょうど1つ・22〜33字、文末が「〜ている」「〜た」で 35/38本、最終文が5社とも「将来が何に依存するか」で締める、という状態になった回がある。**社ごとに「読点0の短文」「読点3つの長文」「体言止めで締める」「断定で締める」を割り当てて崩す**
- **手を消すと、同じ位置に別の手が座る。位置ごと数える。** 強調構文を6本→0本にしたら、次は**否定の言い切りが6社すべての「判定を下す一文」**に入れ替わりで座った。**消すべきは手ではなく、その位置で全社が同じことをすることのほう**——「判定を下す一文」「処遇に触れる一文」「留保の一文」が**どの位置に何本あるか**を数える
- **機械的に数えるなら n-gram では足りない。文の「手」で数える。** 強調構文「〜のは〈名詞〉だ／で、」は語が違うので n-gram には出ない。同じ層に **原文の引き方**（「会社（自身）が…挙げている」）、**段階利益の3段並べ**、**同じ指標の言い方**（「一人当たりの経常利益は〈業種〉の中央値の N 倍」）がある。**手は語を変えても残るので、手ごと替える**
- **数え方を狭くしない。** 見出しの対比を「逆接の『が』」だけで数えれば1本でも、**「ＡよりＢ」「Ａは X、Ｂは Y」「Ａは減り、Ｂは増えた」まで含めれば同じ対比フレーム**である。**語を散らしてもフレームは残る**（「つつある／段階に入った／途中にあり／近づいている」は語が4通りでも1つのフレーム）
- **締めから `figures` を外すと、締めの直前へ移るだけ。** **位置ではなく、その社について何を最後に言うかを散らす**
- **揃いは「語」ではなく「型」で出る。1巡直したら、直した後にもう一度並べる。** 消した語の代わりを1つに寄せると、**同じ揃いが別の語で戻ってくる**。見るのは5軸を**別々に**——①一言の型と終止形 ②分析の書き出し ③段の始まりの句 ④締めの主題 ⑤動詞・語尾・比喩
- **締めの主題を、全社で `figures` に寄せない。** 平均年収・在籍年数・残業・有給で終える形は書きやすく、**放っておくと6社中5社がそうなる**。**事業の話で終わる社を必ず混ぜる**——指標を別のものに替えても、`figures` で締めること自体が型として残る

- **機械ゲートが通した語が、あなたの材料にあるとは限らない。** ゲートの `unsupported_terms` が突き合わせる原文は**切っていない版**で、あなたが読むのは**切った版**である。**ゲートを通ったことを、材料から書いた証拠にしない**——固有名詞や言い換えを使うときは、**自分が読んだ材料の中を grep して確かめる**

### 事実に割く字数は本文の3分の1まで（**述語だけ整えても分析にはならない**）

**述語で判定する規則（主節が事実で終わる文は1つまで）は必要条件にすぎない。** **文末が主張の形でも、中身が事実の列挙なら1段目のまま**である。211回目、運営者が名指しした2文——

> ~~五島市沖の発電所は6社で組む合同会社の事業として当期のうちに商用運転へ入り、当社の投資でも浮体式洋上風力発電事業などに伴う有形固定資産の取得に資金が出て、環境・エネルギーを自社のセグメントとして抱えている~~
> ~~建築は売上を積み増しながら営業利益を当期より低く置き、国内投資開発は利益率を倍近くへ引き上げ、いまは営業損失の環境・エネルギーを黒字に置く計画で、稼ぎ頭の採算を低く見積もってでも持つ側の利益を厚くする絵になっている。~~

**どちらも文末は「〜抱えている」「〜になっている」だが、字数のほとんどは材料の書き写しである。** 運営者の言葉では「**これらは主観や推測、思想、主張ではありません。単なる事実です。要約に書く内容としては適切ですが、AI分析に書く内容としては不適切です。事実自体を一言触れるのはいいですが文字数を割きすぎています**」。

**線は3つ。**

- **1つの文に、材料由来の事実（固有名詞・数値・出来事・計画の数字）を3つ以上並べない。** 3つ並んだ時点で、それは裏づけではなく列挙である
- **事実に割く字数は本文全体の3分の1まで。** 残りの3分の2は**材料に書いていないこと**——推測・評価・含意・重み付け・見通し・読者にとっての意味
- **1つの主張を支える事実は1つでよい。** 2つ目を足したくなったら、**主張が弱いのではなく、主張をまだ書いていない**

**確かめ方**——**書き終えたら、材料に書いてある部分を消してみる。残りが半分に満たなければ、それは分析ではない。** 消えるのは固有名詞・数値・原文の言い回し。残るのは「だから何が言えるか」の側。

**この線は「事実を書くな」ではない。** 主張には足場が要る。**足場は1文に1つ、本文で3分の1まで**——それを超えたぶんは、読者が要約の側で読める。

### 主題は1つ。刺さらない観点は、真であっても捨てる（**幅出しをしない**）

**分析は「1つの主題」を立て、それを支える材料だけで組む。** 見出しがその主題で、本文は見出しの主張を展開して終わる。**見出しと結びつかない文は、真であっても、材料に裏づけがあっても、落とす。**

**同じ会社で、運営者が良いほうと悪いほうを名指しした実例がある**（東京海上ホールディングス）。

**良いほう**——主題は「稼ぎ手はすでに海外で、国内の生命保険が足を引っ張っている」の1本だけ。5文すべてがその主題を支えている。

> 稼ぎ手はすでに海外で、国内の生命保険が足を引っ張っている。
> 当期利益はグループ全体で増えたが、その大半を海外保険事業が稼いでいる。国内損害保険事業も当期利益を伸ばした一方、国内生命保険事業は前期に続いて損失を計上し、その幅を広げた。会社は保険引受能力の高度化とグローバルなリスク分散、戦略的なM&Aを掲げており、利益源を海外へ広げる路線は今後も続く。保険金を払うだけでなく損害そのものを減らすソリューションを国内保険事業と海外保険事業に次ぐ収益の柱にすると宣言しており、保険会社の枠を広げる側へ人と資本が向かう。ただし平均年収は10年で1割ほどしか上がっておらず、利益の伸びとは切り離されて動いている

**悪いほう**——1文ごとに話題が替わる。利益の出どころ → 一人当たり経常利益の水準 → CSM 残高の読み方 → ソリューション事業の職能 → 勤務地と転勤の制度。**どれも真で、どれも材料に裏づけがあるのに、読み終えて何が残ったか言えない。**

> ~~日本の保険会社に入るつもりで見ていると、利益の出どころを取り違える。当期の親会社の所有者に帰属する当期利益のうち、いちばん大きな塊を作ったのは海外保険事業で、国内損害保険事業がそれに続いた。保険業の中では一人当たりの経常利益が中央値の2倍を超える側にいる。国内生命保険事業は損失が前期より広がったが、将来の利益の源になる契約上のサービス・マージンの残高は積み増しており、当期の赤字がそのまま事業の縮小を意味するわけではない。会社が国内保険と海外保険に次ぐ柱に据えたいのは防災・減災やヘルスケアのソリューション事業で、保険を売る仕事とは別の職能が要る。処遇では、主要子会社の東京海上日動が職種を総合職に一本化し、転居を伴う転勤を本人の同意がある場合に限る制度へ変えた——勤務地の縛りを緩める方向へ動いている。~~

**なお、この節と次の節に載る例文は「主題の立て方」の見本であって、その中の事実関係まで正ではない**（良い版の `保険引受能力の高度化` は、原文が `高度な保険引受能力…を活かした保険料収入の拡大` と書いている）。**例文の言い回しを引き写すときも、原文に当たること。**

**運営者の言葉では、悪いほうは「AIのありがちな挙動で、強弱をつけずに幅出しの観点で書く」ものである。** 網羅は安全に見えるが、**選ばないことは主観を放棄すること**で、ADR-0015 がここに主観を求めた理由と正面から反する。**何を捨てたかが、その分析の主観そのものである。**

**具体的な線**——

- **本文で扱う話題は原則1つ、多くて2つ。** 3つ目を足したくなったら、それは見出しを支えているか自問する。支えていないなら捨てる。**2つ目は、1つ目に対する留保・裏返し・条件のときだけ**（良いほうの5文目「ただし平均年収は…」がそれで、主題と対立させることで主題を強めている）
- **話題が替わる合図の語に気をつける**（`処遇では`・`一方`・`また`・`なお`）。**書きかけたら、その先の文が見出しを支えるか確かめる**
- **材料を集めた量と、書く量は比例しない。** 外部を取りに行くのは既定の手順のままだが、**取ってきたものが主題を支えないなら本文に入れない**（`sources` にも残さない——使っていない URL を並べると、読者は本文と対応が取れない）。良いほうの実例は外部情報を1件も使っていない
- **`profit_per_employee_yen` も同じ扱い。** 主題に関係しないなら書かない。**「書ける条件がそろっているから書く」ではない**（悪いほうの3文目がそれで、水準の話だけが浮いている）
- **多面的に読むことと、多面的に書くことは違う。** ADR-0015 の「多面的に読み」は**材料の読み方**の話で、書くほうは絞る。読んだ4節すべてに触れる必要はない

**この線が効かない場面**——**主題そのものが「この会社は一言で言えない」であることが実際にある**（複数の事業が互いに無関係に動いている持株会社など）。そのときは**「一言で言えない」ことを主題として言い切る**のであって、観点を並べて読者に判断させるのではない。**また、1つの主題を支えるために2つの事業を対比する文は「話題2つ」ではない**（良いほうの2文目が3つの事業に触れているのは、すべて「稼ぎ手はどこか」という1つの問いへの答えだからである）。

### 数値と区分の扱い

- **利益に触れるときはどの段階かを書く。** 営業利益・経常利益・純利益で向きも幅も食い違う（飯野海運は外航海運業の営業利益 △33.4% に対して**連結経常利益は △2.8%**、川崎汽船は経常利益が半分以下でも**営業利益は 81.8%**）。**「利益」とだけ書くと、読者がどの行と突き合わせても合わない**
- **「横ばい」「増えた」は基準を明示する**（前期比か、計画比か、何年度比か）

### 数値は脇役。ここが最も外しやすい

**同じ材料でも、数値を並べるか意味を言い切るかで別物になる。**

| 書いてはいけない形（数値が主役・材料の言い直し） | 書く形（定性が主役・読み方まで書く） |
| --- | --- |
| 売上58,448百万円（3.4%減）、営業利益1,298百万円（52.2%減）、経常利益1,436百万円（49.2%減）、純利益4,113百万円（2.7%増）。 | **本業は苦しい。** 営業利益が半減し、値引きに頼った販売で粗利も落ちた。最終利益は増えているが、これは保有株の売却益によるもので、商売が上向いたわけではない。 |
| 売上132,328百万円（29.6%減）、営業損失18,692百万円、当期純損失19,810百万円。希望退職1,483名応募・1,319名退職。 | **縮小しながら建て直している最中で、次の柱はまだ立っていない。** 工場を畳み、人を減らし、資産を売って赤字幅を圧縮している段階。 |
| 売上7.6%増、経常利益15.6%増、純利益12.9%増。自己資本1.9兆円。平均年収は1,318万円→1,144万円で13%減。 | **業績は堅いが、平均年収は10年で13%下がっている。** 増収増益で財務も厚いのに、会社の好調が給与に回っていない期間が続いている。 |

**左は読者が自分で意味を組み立てる必要がある。右は組み立て済み。** 左の情報量は多いが、それは有報が既にやっていることで、ここで繰り返す意味が無い。

**組み立てるとは、材料の外へ一歩出ることである。** 上の右側はどれも材料が明示していない読み方を書いている——**そこまで書いて初めて要約と別物になる。**

**求職者に向けて言い直す。** 同じ推測でも、**その会社で働くことにどう効くか**まで届けば価値が出る。**読者が知りたいのは、この会社に入ってどうなるかである。**

**価値が出るのは、有報が数字を並べているのに結論を言わない箇所。** 三陽商会は素直に読むと「最終利益は増えた」で終わるが、売却益によるものだと気づくには営業利益・経常利益・純利益の動きを突き合わせる必要がある。**`figures` と有報の食い違いも同じ**——ファナックは有報の文面だけでは「増収増益で財務も厚い」までしか言えない。

### 固有名詞を積極的に出す

**具体性は固有名詞から来る。** 材料にある製品名・ブランド名・サービス名・事業名は**言い換えずにそのまま書く。**

| 抽象に逃げた形 | 書く形 |
| --- | --- |
| ファッションビル向けの新ブランド | 新ブランド「AUREME」 |
| 本体のEC支援 | ECサイトの構築・運用を請け負うEC支援 |
| 主力の解体機械 | 主力の圧砕機 |
| 大型プラント解体向けの周辺機種 | 鉄骨カッターと油圧ブレーカ |
| 新しい中期経営計画 | 中期経営計画「変革2030」 |

**分析の機械ゲートは固有名詞を見ない**（外部の文書も材料なので、有報の原文だけと突き合わせると誤判定する）。**だから抽象に逃げても機械は通す。** 具体的に書くかどうかはここで決まる。

**探すときは製品名・ブランド名を名指しで探す**（「◯◯ 製品」「◯◯ ブランド」）。有報の4節に無くても公式サイトには載っている。

**5社とも違う語彙になっている。** 段階評価では出せない言い方をすること。

## 落とす型

**番号は固定。回をまたいで内訳を数えるためにあるので、読む側で振り直さない。**

**ADR-0016 で9つを廃止した**（~~A1~~ 内訳の無い切り分け・~~A2~~ 材料が述べていない因果・~~A6~~ 不在の断定・~~A7~~ 1期から趨勢・~~A11~~ 材料が持たない比較・~~A15~~ 重み付け・~~A17~~ 外から持ち込んだ基準・~~A18~~ 減収の要因を減益に・~~A19~~ 並列に包含）。**番号は残すが、これらはもう落とさない**——どれも「解釈するな」と言っていて、従うほど分析が要約に近づいた。

### 要約の型（S）

C6（`summary/prompts/generate.md`）の型①〜⑪が**そのまま効く**。**まず C6 の表を読むこと。**

- **型S1 増減や影響の向きを取り違えた。** セグメント表で金属資源が 2,278 → 2,045 億円と**減っている**のに、`[+]` 要因だけを読んで「前年度を上回った」と書いた。**増減要因の欄には `[+]` と `[-]` が並ぶ。拾った要因の向きと、その項目そのものの向きは別である**——項目の向きは合計の側（表の増減欄）で確かめる
- **型S2 枠組みの名前だけが材料にあるのに、中身まで書いた。** リスクの節が「グループトップリスク」の中身を書いていないのに3項目を挙げた（実際は別の枠組みのもの）。**「◯◯として△△を特定している」と書く前に、△△がその◯◯の下に置かれているかを見る**

- **型S4 会社が定義した区分の membership を取り違えた。** 原文が `都市ガス・ＬＰＧなどのコア事業では…また、戦略事業では、電気事業において…海外事業において…` と2つの括りを分けているのに、`都市ガス・ＬＰＧ・電気の供給をコア事業とし` と書いた形。確かめ方は3つ。
  - **区分の名前が会社の定義語（コア事業／戦略事業／重点領域…）のときは、その語で4節を検索し、下に挙がっている要素を数えてから書く**
  - **原文が「など」で開いている括りを、閉じた列挙にしない。** `都市ガス・ＬＰＧ**など**のコア事業` をそのまま写せば、別の節の括りと衝突しない
  - **別の節が持つ違う括りから要素を持ち込まない。** **同じ会社が複数の切り方を持つのは普通で、切り方をまたいで要素を移すと、どちらの節を読んでも支持されない文になる**
  - **型S2 と地続き**（S2 が「枠の名前はあるが中身が材料に無い」なら、S4 は「枠も中身もあるが、どの要素がどの枠に属するかを取り違えた」）。**分析の型④（区分の取り違え）とは確かめ方が違う**ので番号を分けた——あちらは表の行と列がずれる形で、こちらは枠そのものの membership

- **型S3 材料が持つ区分の数を減らして断じた。** 「エラストマー素材と高機能材料の**二つの**事業部門を持つ」——**切った版の MD&A 末尾に「（その他の事業部門）」の見出しが見えている**。**型A10 の裏返しで、取り違えではなく数え落とし。**「**主力の**」「〜を**中心とする**」と書けば残余の区分と両立するので、直し方は**数の断定を外すだけ**。**切れた先に区分があるかは問わない**——見えている範囲に3つ目があるときだけ落ちる
  - **「合わせると」は読者に足し算の手続きを指示する**（2部門の合計が全社の売上に足りないのに「二つを合わせると全社は減収増益で」と書いた形）。**全社の値は「全社では」と一段上へ引き上げて述べる**

### 分析の型（A）

- **型A3 材料が述べていない日付・出来事・属性を足した。** 4節にあるのが「2024年11月に実施した**公募増資**」だけなのに上場の時期として書いた——**近くにある別の出来事の日付を借りない**。「公表した修正予想を上回り」しか書かれていないのに「途中で**引き上げた**業績予想」と書くのも同じ型（修正の向きは材料に無い）。**材料にある出来事は、材料が述べている限りの姿で書く**
- **型A4 条件の良さから、材料の外にある事実を導いた。** 「報酬も定着も労働時間もそろっている分だけ、**入り口の競争は厳しい**」——待遇の3指標は `figures` にあるが**採用の競争率はどの材料にも無い**。**待遇・数字から労働市場の話へ渡らない**（「長く勤める人が多い職場」は在籍年数が支えるので内側）
- **型A5 向きを取り違えた（分析版の型S1）。** ①**`figures` の推移**——「高い水準で横ばいに近く」と書いたが実際は10年で47%上がっていた（**同じページが推移のグラフを出すので図と文が正面から食い違う**）。②**本文だけを読むと逆に読める箇所**——「1,238億円減少し、2,048億円の損失」から「損失に転じた」と書いたが**セグメント表では前期も損失**だった。**「転じた」「初めて」と書く前に前期の値を表で確かめる**
- **型A8 増減の幅を、材料の数値と食い違う言い方でまとめた。** 上の「丸めた比率の線」の表を当てる
- **型A9 材料が限定していることを、無限定に断定した。** 「ほぼ全ての長期借入について金利を固定化し…ておりますが」と限定付きで書かれているものを、限定を落として書かない
- **型A10 別の時点の区分を、いまの区分として並べた**
- **型A12 出来事の時点を、期をまたいで取り違えた。** 2024年7月1日付の合併は**6月決算の会社では当期首**である（`figures.period_end` が決算日）。**日付が1つも出てこない形もある**——当期の新作として挙げた作品について、材料が書いているのは受賞・追加DLC・移植版だけだった。**原文が当期の発売と書いている作品だけを当期の新作と呼べる**
- **型A13 改善要因を、悪化の中身として並べた。** 「合算が悪化した」の説明に、**前期より約86億円「減少」した費用**を挙げていた。**増減要因の欄には改善と悪化が並ぶので、拾った項目がどちらの向きかを、その項目自身の増減で確かめる**
- **型A14 セグメントの損益を、その中の事業名で呼んだ**
- **型A16 区分をまたいで出来事を移した**

## 書き方の順序

1. **4節を通して読む**（切れているところで止まる。先を推測しない）
2. **`figures` を1点ずつ見る**——推移の形、各指標の水準、業種中央値との関係
3. **要約を書く**——何をしている会社か。数値を書かない
4. **外部を取りに行く**——**採用ページと直近のリリースは、少なくとも見る**（公式サイト・ニュースリリース・採用求人。配信サービスも落とさない）。**ここを飛ばすと、分析は有報の言い直しにしかならない**。使った URL は `sources` に残す
5. **主題を1つ決める**——集めた材料のうち、**求職者にとって最も刺さる1点**はどれか。これを見出しにする。**選ぶことがここの仕事で、網羅は仕事の放棄である**
6. **分析を書く**——一言 → **その事実が求職者にとって何を意味するか**。**主題を支える文だけを書く。支えない文は、真でも落とす**。「〜と会社は説明している」で逃げない。言い切る
7. **見出しを隠して本文だけを読む**——**話題が3つ以上に散っていないか。読み終えて何が残るか一言で言えるか**。言えなければ、見出しを支えない文を落とす
8. **書いたものを材料に当て直す**——固有名詞は4節にあるか（**語で検索する**）、数値は `figures` か原文にあるか、丸めは9割の線の内側か、利益の段階を書いたか、時点は当期か
9. **同じバッチの他社と並べる**——一言の型と締めが重なっていないか
