# 要約と分析の生成（C9・#241）

1社につき**2つのものを書く**。規格が違うので、混ぜない。

- **要約** — 有報の4節に**書いてある事実**を、評価語なしでまとめる
- **分析** — 材料から**導ける解釈**を、評価を入れて書く。冒頭に一言

**1回で両方書く**のは原文を2回読ませないためであって、規格が近いからではない。
**書き分けられないなら、片方を空にする。**

## 入力

`work/batch_NNNN.json`。`companies[]` の各要素が1社。

- `edinet_code` / `sec_code` / `name`
- `sections` — 有報の4節（`mdna` 経営者による分析 / `risks` 事業等のリスク /
  `issues` 対処すべき課題 / `sustainability` サステナビリティ。**節ごとに先頭を切ってある**）
- `figures` — **同じページが既に表示している数値**。平均年収・平均年齢・平均在籍年数・
  従業員数・業種・決算期・平均年収の10年推移・稼ぐ力（一人当たり経常利益）と業種中央値・
  残業と有給

## 出力

`work/gen_NNNN.jsonl`。**入力と同じ社数・同じ順**で、1行1社の JSON。

```json
{"edinet_code": "E02181",
 "summary": "……。……。……。",
 "headline": "業績は堅いが、平均年収は10年で13%下がっている。",
 "analysis": "……。……。……。",
 "sources": [{"url": "https://……", "title": "……", "accessed": "2026-08-28"}]}
```

書けないと判断したものは空文字にする。**無理に書かない。** ただし**要約と分析は対で出す**ので、片方だけ空にしても `merge` が両方落とす（spec 1.19・AC-28）。

## 材料——ここが C6 といちばん違う

**分析は有報の外の文書も材料にしてよい。むしろ使う**（ADR-0015 決定2）。

1. `sections` の4節
2. `figures` の数値
3. **Web から取得した文書** — 公式サイト・ニュースリリース（自社ページでも PR TIMES 等の
   配信サービスでも）・採用求人（自社ページでも HRMOS・Indeed 等でも）・その他、検索で
   辿れる一次情報

**配信サービスや求人サイトを理由に落とさない。** 出しているのは会社自身で、第三者の
編集物より一次に近い。**見るのは出所の格ではなく、取れて出典を示せるかどうか。**

**ただし「会社自身が出している」までが線である**（パイロットで足した）。年収まとめ記事・
転職メディアの解説・個人ブログは**会社が出したものではない**ので材料にしない。実際に
「ファナック 採用 初任給」で検索すると上位8件のうち5件がこの型で、**平均年収を
1,238万・1,163万・1,164万と互いに違う値で書いている**——このサイトが有報から出している
数字と食い違うものを材料にすると、有報ベースだという立て方そのものが崩れる。

**報道記事も本文の根拠にしない。** 会社自身の発表があるならそちらを当たる（新業態の
出店を日経が報じていても、リリースが出ているならリリースを引く）。

**会社が自分で言っている評価は、そのまま書かない。** 「業界シェアNo.1」のような自称は
**その会社が出した文書にある**ので材料の条件は満たすが、こちらが地の文で書くと我々の
評価になる。書くなら「同社はシェア首位としている」と帰属を付ける。

**そのうえで、モデルの記憶から補ってはならない。** 世間で知られている話・報道の記憶・
世評を、**取ってきた文書の裏付け無しに**書かない。**これが唯一残っている ADR-0010 の線**で、
分析セクションでも覆らない。書こうとしている事実の出所が「知っているから」なら、
**取りに行くか、書かない。**

**使った URL は `sources` に全部入れる。** 有報の4節と `figures` だけで書いたなら空でよい。

**取り方の線**（ADR-0008 決定1）。

- ブラウザの UA に偽装しない。ヘッドレスブラウザで取りに行かない
- 403・503・画像認証・WAF のチャレンジは**明示的な拒否**として受け取り、その材料は使わない
- **転載しない。** 導いた解釈を自分の言葉で書くのであって、原文を長く写さない

**探す量には上限がある。** 1社あたり**検索は2回まで、取りに行くページは3つまで**
（パイロットの実測で決めた。8社中5社は有報と `figures` だけで書けている）。
**材料が薄い会社は薄いまま書く**——埋めにいけば記憶から補うことになる。

## 要約の規格

- **全角200〜700字 / 3〜10文**
- **評価語を含めない**（「業界最大手」「高い収益性」「優れた」「急成長」…）。C6 と同じ表
- **社名を含めない**（見出しに出ている）
- **原文に現れない固有名詞を含めない**
- **数値は書いてよいが、`sections` に無い数は書けない**（機械ゲートが落とす）
- 4節のうち求職者に効くところを拾う。**MD&A で当期に何が起きたか、リスクで何を挙げて
  いるか、課題で何をやろうとしているか、人的資本で人にどう向き合っているか**
- 文体は常体。**ここには評価も解釈も入れない**——それは分析の仕事

## 分析の規格

- **`headline`** — 全角12〜75字の**1文**。その会社が**いまどうなのか**を言い切る
- **`analysis`** — 全角120〜500字 / 3〜10文。「うまくいっていること」「うまくいって
  いないこと」「今後の挑戦」を**地の文で**書く。見出しを付けて箇条書きにしない
- **評価語を書いてよい。これが本体である**
- **算用数字は合計3個まで**（`headline` ＋ `analysis`）。機械ゲートが数える。**少ないほど良い**——パイロット8社の実測は1〜3個だった
- **段階評価にしない。** 「好調」「安定」「不振」のような語彙から選ばない——
  **語彙は自由で、観点だけが固定されている**

### 数値は脇役。ここが最も外しやすい

**同じ材料でも、数値を並べるか意味を言い切るかで別物になる。**

| 書いてはいけない形（数値が主役） | 書く形（定性が主役） |
| --- | --- |
| 売上58,448百万円（3.4%減）、営業利益1,298百万円（52.2%減）、経常利益1,436百万円（49.2%減）、純利益4,113百万円（2.7%増）。 | **本業は苦しい。** 営業利益が半減し、値引きに頼った販売で粗利も落ちた。最終利益は増えているが、これは保有株の売却益によるもので、商売が上向いたわけではない。 |
| 売上132,328百万円（29.6%減）、営業損失18,692百万円、当期純損失19,810百万円。希望退職1,483名応募・1,319名退職。 | **縮小しながら建て直している最中で、次の柱はまだ立っていない。** 工場を畳み、人を減らし、資産を売って赤字幅を圧縮している段階。 |
| 売上7.6%増、経常利益15.6%増、純利益12.9%増。自己資本1.9兆円。平均年収は1,318万円→1,144万円で13%減。 | **業績は堅いが、平均年収は10年で13%下がっている。** 増収増益で財務も厚いのに、会社の好調が給与に回っていない期間が続いている。 |

**左は読者が自分で意味を組み立てる必要がある。右は組み立て済み。** 左の情報量は多いが、
それは有報が既にやっていることで、ここで繰り返す意味が無い。

**「半減」「増収増益」「2割」「倍増」のように語で言えるものは語で言う。** そうすると
数値が要らなくなる——上の良い例5つに含まれる算用数字は**0〜2個**だった（あれは一言と短い裏づけだけの63〜90字で、ここで書く本文は3観点まで含めて約250字になる）。

### 固有名詞を積極的に出す。「新ブランド」ではなくブランド名を書く

**具体性は固有名詞から来る。** 材料にある製品名・ブランド名・サービス名・事業名は、
**言い換えずにそのまま書く。**

| 抽象に逃げた形 | 書く形 |
| --- | --- |
| ファッションビル向けの新ブランド | 新ブランド「AUREME」 |
| 本体のEC支援 | ECサイトの構築・運用を請け負うEC支援 |
| 主力の解体機械 | 主力の圧砕機 |
| 大型プラント解体向けの周辺機種 | 鉄骨カッターと油圧ブレーカ |
| 新しい中期経営計画 | 中期経営計画「変革2030」 |

**分析の機械ゲートは固有名詞を見ない**（外部の文書も材料なので、有報の原文だけと
突き合わせると誤判定する）。**だから抽象に逃げても機械は通す。** 具体的に書くかどうかは
ここで決まる。

**ただし材料にあるものに限る。** 「知っている製品名」を書かない——これは**記憶から補う**
ことそのもので、ADR-0015 が唯一残した線に当たる。**書きたい固有名詞が材料に無いなら、
`sections` を読み直すか、公式サイトを取りに行くか、書かない。**

**探すときは製品名・ブランド名を名指しで探す。** 「◯◯（社名） 製品」「◯◯ ブランド」
「◯◯ サービス」。有報の4節に無くても、公式サイトには必ず載っている。

### 価値が出るのは、有報が数字を並べているのに結論を言わない箇所

三陽商会がその典型で、**有報を素直に読むと「最終利益は増えた」で終わる。** 売却益に
よるものだと気づくには営業利益・経常利益・純利益の動きを突き合わせる必要がある。
**ここを一言で言い切ることが、この節の存在理由である。**

**`figures` の数値と有報の食い違いも同じ。** ファナックは有報の文面だけでは
「増収増益で財務も厚い」までしか言えないが、平均年収の10年推移を並べると
**求職者にとって最も効く食い違い**が出る。

## 「好調かどうかの一言」の実例（2026-08-27・人手）

**5社とも違う語彙になっている。** 段階評価では出せない言い方をすること。

- **ジャパンディスプレイ（6740）** — 縮小しながら建て直している最中で、次の柱はまだ
  立っていない。
- **三陽商会（8011）** — 本業は苦しい。
- **ファナック（6954）** — 業績は堅いが、平均年収は10年で13%下がっている。
- **ディスコ（6146）** — 数字の上ではほぼ隙がない。
- **出前館（2484）** — 赤字は続いているが、規模を追う段階は終えた。

## 実際に落ちた型

**番号は固定。回をまたいで内訳を数えるためにあるので、読む側で振り直さない。**
**要約と分析で表を分けてある**——規格が違うものを1つの表に混ぜると、12回ぶんの積み上げが
混ざる（C6 の教訓）。

### 要約の型（S）

C6（`summary/prompts/generate.md`）の型①〜⑪が**そのまま効く**。あちらは「事業の内容」
1節から2〜3文を書くもので、こちらは4節から3〜10文を書くが、**まとめ方・括り方・帰属が
原文を離れる**という失敗の質は同じである。**まず C6 の表を読むこと。**

このプロンプト固有の型は、回を重ねてここに足す。

- **型S1 増減や影響の向きを取り違えた。** 三菱商事のセグメント表で金属資源は 2,278 → 2,045
  億円と**減っている**のに、`[+]` 要因（銅事業の戻入・市況上昇）だけを読んで「前年度を
  上回った」と書いた。伊藤忠のリスクの節は生活消費分野を「相対的に**国内景気の影響を
  受けやすい**」としているのに「影響を受けにくい」と逆に書いた。**増減要因の欄には
  `[+]` と `[-]` が並ぶ。拾った要因の向きと、その項目そのものの向きは別である**——
  項目の向きは合計の側（表の増減欄）で確かめる。
- **型S2**（未観測）

### 分析の型（A）

- **型A1 内訳が書かれていない影響を、切り分けたように書いた。** 出前館の原文は
  「付与型クーポンの導入に伴い、販売促進にかかる金額を売上高から減額する処理を採用」と
  書いているが、**その金額は書いていない。** そこから「会計処理の変更を差し引いても
  縮小は続いている」とは言えない。**「◯◯を除いても」「◯◯の影響を差し引いても」は、
  その◯◯の大きさが材料にあるときだけ書ける。**
- **型A2 材料が述べていない因果を作った。** 第一建設工業の MD&A は減益を数字で示すだけで、
  理由を書いていない。課題の節にある「労務費・建設資材価格の高騰」は**今後の見通し**として
  挙がっているもので、当期の減益の原因としては書かれていない。**「AだからB」と書く前に、
  材料がその繋がりを述べているかを見る**——同じ文書の別の節に A と B が載っていることは、
  A が B の原因だという意味ではない。

  **原因が書かれていないときは、起きたことだけを書く。** 「売上と受注は増えているのに、
  利益はそろって前期を下回った」で止めるほうが、原因を作るより強い。

  **型A2 は最後の1文に出やすい。** 2回目の8社で落ちた3件はすべてこの型で、しかも
  **`figures` の数字に理由を付けた1文**だった——在籍年数が短いのは「急に人が増えたから」、
  年収が上下するのは「市況に釣られて」、振れ幅が小さいのは「船種を広く持つから」。
  **どれも材料にはその理由が無い**（在籍年数の推移も、市況指標も、船種と振れ幅の関係も）。
  **数字を並べたあとに「〜だから」を足したくなったら、その理由が材料にあるかを見る。**
  無ければ**数字だけで止める**か、会社が課題として挙げているものに帰属を付ける。

- **型A3 材料が述べていない日付・出来事を、近い記述から移した。** グロービングの4節に
  あるのは「2024年11月に実施した**公募増資**」と営業外費用の「上場関連費用」だけで、
  **上場の時期はどこにも書かれていない**。公募増資と上場を同じものと見て日付を移すのは、
  記憶から補うのと同じことになる。**書こうとしている出来事そのものが材料にあるかを見る**
  ——近くにある別の出来事の日付を借りない。
- **型A4 条件の良さから、材料の外にある事実を導いた。** 三菱商事の「報酬も定着も労働時間も
  そろっている分だけ、**入り口の競争は厳しい**」。待遇の3指標は `figures` にあるが、
  **採用の競争率はどの材料にも無い**。**待遇・数字から労働市場の話へ渡らない**——
  読者が確かめる先が無い。同じ形でも「長く勤める人が多い職場」（在籍年数が支える）や
  「案件の当たり外れが個人に返ってくる」（原文の売上インセンティブが支える）は材料の
  内側に留まっている。

**型A1〜A4 はどれも「材料が足りない」ではなく「言い過ぎ」だった。** 直し方は2つ——
材料が述べている範囲まで**主張を弱める**か、**帰属を付ける**。**型S1 だけは別で、
あれは言い過ぎではなく誤読なので、原文どおりに直す。**

| 書いてはいけない形 | 書く形 |
| --- | --- |
| 会計処理の変更を差し引いても縮小は続いている | この落ち込みには販売促進費を売上から差し引く会計処理の変更も含まれる |
| 労務費と資材価格の高騰が利益を削っている | 会社自身も労務費と建設資材価格の高騰を今後の課題に挙げている |
| 上場も2024年11月と新しく | 当期は上場関連費用を計上しており、2024年11月の公募増資で得た資金が手元にある |
| 待遇がそろっている分だけ入り口の競争は厳しい | 報酬も定着も労働時間もそろっており、待遇の面で崩れているところが見当たらない |

**要約と分析は対で出す。片方だけ書いて出さない**（spec 1.19）。片方が書けないなら、
**書ける範囲まで弱めて両方出す**。それでも書けないなら**両方とも空にする**——
`merge` が対で落とす。

## 書き方の順序

1. `sections.mdna` を読み、**当期に何が起きたか**を掴む。増収か減収か、利益はどう動いたか、
   **利益の段（営業・経常・純）で動きが食い違っていないか**
2. `figures` を見る。**有報の文面と食い違うものがあれば、そこが一言になる**
3. `sections.risks` と `sections.issues` から、うまくいっていないことと今後の挑戦を拾う
4. **足りなければ Web を探す**（上限の範囲で）。直近の発表・採用の状況・**主力製品や
   ブランドの名前**（公式サイトの製品ページ）
5. `headline` を書く。**言い切る。** 「〜と思われる」「〜の可能性がある」で逃げない
6. `analysis` を書く。数値を並べたくなったら、**語で言えないかを先に試す**。
   **「新ブランド」「主力製品」「本体の事業」と書いたら、材料に名前が無いかを見る**
7. `summary` を書く。**ここには評価も解釈も入れない**
8. 規格に収める。**足りないから足す、ということをしない**——足りなければ空にする
