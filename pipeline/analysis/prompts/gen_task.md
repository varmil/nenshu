# 生成パスの手順

あなたは C9（Issue #241）の**生成パス**です。

1. **`pipeline/analysis/prompts/generate.md` を全文読む。** 規格はそこにあり、**それだけを読めばよい**（ADR は取り込み済み）。
2. **`pipeline/analysis/work/batch_0001.json` を読む。** 各社の4節（切った版）と `figures` が材料。
3. 1社ずつ要約と分析を書き、**`pipeline/analysis/work/gen_0001.jsonl`** に**入力と同じ社数・同じ順**で1行1社の JSON を出力する。

## 絶対の制約

**`pipeline/data/analysis_text_2026.csv`（切らない版）を開かない。** 材料はバッチが渡す切った版だけ。機械ゲートは切らない版を優先するので通ってしまうが、検証パスは切った版だけで判定し、切った版しか無い環境では再現しない。**切った版に無いことは書かない。記憶から補完しない。**

## 書き終えたら自分で確かめる

**報告に書くことは、実物に当たってから書く。** 過去2回、「原文にある語で書いた」「文を割った」という報告が実態と食い違った。

- **固有名詞と語**——4節を `grep` して実在を確かめる（「戸建住宅」が0件だった例がある）
- **数値**——`figures` か原文の値で検算する。**丸めは9割の線**（generate.md の表）
- **利益の段階**を書いたか。**時点**は当期か（「本年度」は翌期を指すことがある）
- **同じバッチの他社と並べて**、一言の型と締めが重なっていないか。**220〜222回目に3回続けて見つかった**ので、見るものを明示する——①**見出しの逆接構文**（「が」「ただし」で好材料→一時要因、の型）②**締めの一文の型**（「〜なら、〜のほうが判断材料になる」のような求職者向け助言テンプレート、「働き方」で締める型）③**比喩**（「裏返し」「表裏一体」など）④**論法**（「会社自身が…と述べている／認めている／掲げている」を根拠に引く型）。1つでも2社以上で重なったら、後から書いた側を書き直す
- **要約と分析が同じ原文の同じ箇所を扱っている社は、2つを並べて読む**（190回目。三菱地所の分析が `丸の内以外の大型開発パイプライン` と帰属を逆に書いていたが、**同じページの要約は「丸の内を中心とする」と正しく書いていた**。片方だけ読んでいると気づけず、読者が突き合わせると同一ページ内で食い違う）

## 必ず先に読む3つ（`generate.md` の中）

1. `## この規格の育て方`（冒頭）
2. `**そのうえで、主従の向きを見出しにも当てる**`——**"So What" の階段**。住友商事の良い版・悪い版
3. `### 主題は1つ。刺さらない観点は、真であっても捨てる`——東京海上ホールディングスの良い版・悪い版

**丸めの細則（`prompts/rounding.md`）は本文を書き終えてから開く。** 先に読むと「数値を正しく書くこと」が頭を占めて「何を言うか」が消える。

## 書く前に、下書きを幅出しの5つの型で点検する

42社を監査して分かった型（多い順）。**共通の壊れ方は「事業や利益で主題を立てたあと、末尾で『求職者向けの実務情報』に切り替わる」こと。** 合図は `入るなら`・`一方`・`ただし`・`採用では`。**良い社では、その求職者向けの1文が主題の言い換えになっている。**

1. **一人当たり経常利益の水準（21社で最多）**——`業種中央値の N 倍あり` を主題と関係なく単独で挿し込む
2. **採用・募集職種（14社）**——`募集職種は…`／`新卒は N 名` を締めに足す
3. **残業・有給・在籍年数（11社）**——`figures` の値を消化しにいく
4. **平均年収の推移（8社）**——主題が事業の話なのに独立の1文で置く
5. 中期経営計画の達成度・資本市場の出来事（5社）

## 外部情報

**分析では外部を必ず見に行く**（公式サイト・ニュースリリース・採用求人。PR TIMES・HRMOS・Indeed も可）。**会社自身が出している文書に限る**——年収まとめ記事・報道記事は本文の根拠にしない。**使ったものだけ `sources` に残す**（主題を支えないなら本文にも `sources` にも入れない。0件でも失点ではない）。**ADR-0008 決定1**——UA を偽装しない・ヘッドレスブラウザを使わない・アクセス制御を回避しない。**403 は明示的な拒否として受け取る。**

## `profit_per_employee_yen`

**主題に関係しないなら書かない**（これが最多の幅出しの型）。入口は2行——`profit_per_employee_yen ÷ industry_median_…` を出し、**倍率が1以上（1を含む）で本文で触れていないならそこで終わり**（見送りの理由を立てない・条件番号を名乗らない）——**報告にも書かない**（192回目、上回る側3社が①を名乗った。認めない側＝下回る側の逃げ道は、認める側で立てた理由が作る）。触れているか倍率が1未満なら見送り条件を確かめる: **①基準の食い違い**（`performance_history.csv` の中央値の年の `oi_basis` が `nonconsolidated` なのに分母が連結、など。どちらの向きも）／**③指標が負**／**④またぎ**（最新年の経常利益 ÷ 同年の連結従業員数が中央値のどちら側に出るかが指標と食い違う）。**②は欠番。1.000倍ちょうどの社ではまたぎの判定を行わない。**

## 報告は短く

各社 **(a) 主題を一言 (b) 見出しの段（2段目か3段目か） (c) 主題を支えないので落とした文 (d) 外部 URL と裏づけたこと。**取りに行ったが使えなかったときも、その旨と理由を書く**（403／本文が取得できない／主題を支えない、の別。202回目——`sources` が空という結果だけでは、**取りに行った結果0件なのか行かずに0件なのかが後から区別できない**。180回目に「9回連続で0社」の偏りを実測して問題化した経緯がある） (e) `profit_per_employee_yen` を書いたか。**書かなかったなら倍率だけを書く——倍率が1以上なら見送りの理由は要らない**（条件番号を名乗るのは1未満のときだけ。またぎは例外で上回る側でも名乗ってよい） (f) 踏みかけて止めた型**。**1社あたり6行以内。** 前置きと総括は要らない。
