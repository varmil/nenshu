# T3 推移の表の平均年齢 — plan.md

参照: Issue #827（親: #826）, `docs/timeseries/spec.md` 1.3・2.5・AC-5・AC-12・AC-13・AC-15・AC-16
依存: #74（T0 データ）, #138（T2 の表）

## Context

推移の表の3列目はいま「前年比」で、平均年間給与が前年から何%動いたかを出している。親 Issue #826 の指摘は、**この数字は読者にも検索エンジンにもあまり役に立たない**というもの。有報の平均年間給与は会社の平均なので、年齢構成が変われば昇給が無くても動く。年収が上がった年に平均年齢も上がっていれば、それはベースアップとは限らない——**それを読むには同じ年の平均年齢が隣に要る。** 検索結果の抜粋でも「約1,507万円（平均年齢37.0歳）」の形で年次の値が引かれている。

**過去の平均年齢は取り直さなくてよい。** T0 が作った `pipeline/data/salary_history.csv` は `avg_age` 列を最初から持っている（T0 の design.md で「v1 では表示しない」としていた列）。着手前に数えて、平均年収のある 26,865行すべてに値があることを確かめた。

## 進め方

1. **年齢の値を点検してから出す。** 2017・2018年は本文の表から拾った値で、平均年収では小数桁の取り方で読みが割れていた（`textblock._best`）。次の3つを先に見る。
   - 採用書類（`ranking_unified_2026.csv` の `doc_id`）の行の平均年齢が `companies.json` と全社で一致するか
   - 隣の年との差の分布が、本文由来の年（2017・2018）とタグ由来の年（2019〜）で同じ形か——本文の読み違いがあれば本文由来の側だけ裾が重くなる
   - 小数第2位の値が本文由来の年に偏っていないか。偏っていれば読み違い、偏っていなければ有報の書き方
2. **`history.json` に平均年齢を出す。** 平均年収と同じ書類の同じ行から取るので、同じ `buildHistory` の同じループで組む。別のファイルに分けない——片方だけの会社や年を作れてしまう。
3. **gzip のサイズを測り、上限を決め直す。** 足す前の見積もりで 150KB に届く。F1（ADR-0014）以降このファイルが誰に読まれているか（ビルド時だけか、クライアント・Worker バンドルにも入るか）を確かめてから、上限を上げるか分けるかを決める。
4. **パイプラインのテストで AC-15 を固定する。** 平均年収の AC-3（採用書類の年で `companies.json` と一致）と同じ形で平均年齢も突き合わせる。null の位置が平均年収と一致することも見る。
5. **表を組み替える。** 前年比の列と、それを出していた行の組み立て（`yoy`）を落とし、平均年齢を入れる。**基準年比の列は残す。** 書式はカードと同じ `formatDecimal1` を使う——最新年の行とカードが1文字でもずれると、同じ数字を別の値として読ませる（AC-16）。
6. **節の説明を直す。** 前年比の断り（「前年比は会社の平均が動いた幅で、個人の昇給率ではありません」）を累積の列に付け替え、平均年齢も実測値であることを1文目に入れる。
7. **このページの出典（C12）の実測値の行を直す。** 「平均年収とその推移・平均年齢…」は、推移が平均年収だけだった頃の書き方になっている。
8. **E2E を寄せ替える。** T2 の当たり判定は4セル目までを「年 / 金額 / 前年比 / 基準年比」として読んでいる。前年比の列が無いこと・平均年齢の値・カードとの一致（AC-16）を足す。
9. **測って出す。** `/company/6861` の HTML を前後で raw・gzip で測り、`/` が変わらないことを確かめる。

## 着手前に見えている判断

**平均年齢は有報の桁のまま持つ。** 小数第2位で書く会社がある（1,614行）。`companies.json` も丸めずに持ち、画面で `formatDecimal1` に通している。パイプラインで丸めると、同じ値を2回丸めることになり、カードと表の片方だけがずれる余地ができる。

**年齢の飛びを均さない。** 隣の年と3歳以上動く組が 222組あるが、見た限り大半は持株会社化で単体の従業員数が桁で変わった年（オープンアップグループ 5,092人→12人・35.7歳→50.5歳）。平均年収で決めた「浮いて見えるだけでは直さない」（T0 の design.md）をそのまま当てる。

**グラフには出さない。** 棒は平均年収だけにする。2つ目の軸を足すと、縦に並んだ稼ぐ力の推移の図と形が揃わなくなる。
