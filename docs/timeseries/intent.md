# intent.md — 平均年収の10年推移

## 狙い

いま出しているのは**ある1年の断面**である。「キーエンスは2,178万円」は分かるが、それが**上がってきた結果なのか、下がってきた結果なのか**が分からない。

転職検討者が知りたいのは水準だけではない。「この会社の給与は伸びているか」は、いま何円かと同じくらい判断を左右する。有価証券報告書は10年ぶん公開されているので、**追加の調達コストなしにこの問いに答えられる。**

企業詳細ページに「平均年収推移（過去10年間）」を置く。

## North Star KPI

ranking・company 施策と同じ**自然検索からの月間セッション数**。

補助指標として、企業詳細ページの**滞在時間**を見る。推移は断面より読む時間が長い情報なので、ここが動かなければ仮説が外れている。

## 仮説

**H1.** 「◯◯（社名） 年収 推移」「年収 上がっている 会社」のような検索需要があり、断面しか持たない現状では受け皿が無い。

*検証*: 公開3ヶ月後、企業詳細ページの検索クエリに「推移」「上がる」「下がる」を含むものが現れるか。

**H2.** 推移は断面より信頼を生む。10年ぶんの実測値を並べれば、このサイトが一次情報を持っていることが読者に伝わる。

*検証*: 企業詳細ページの直帰率を、推移の追加前後で比較する。

**H3.** 推移は**実測値だけで語れる。** 年齢補正を通さないので推定の限界（ADR-0005）を持ち込まずに済み、ADR-0007 で既定にした「実測値」の路線とまっすぐ噛み合う。

*検証*: 仮説というより設計方針の確認。実装時に、推移が表示基準の切替と独立に出せることを確かめる。

## 前提の確認（調査済み）

**データは取得できる。実測で確認した。**

| 項目 | 実測値 |
| --- | ---: |
| 書類一覧のキャッシュ（10年 × 通年） | 2,609日ぶん・**約2分** |
| 期間内の有報（全提出者） | 29,931件 |
| **現行の母集団1,867社に絞った件数** | **17,917件** |
| 1件あたりのZIP（CSV形式・type=5） | 約73 KB |
| 総容量 | 1.4 GB |
| 取得時間（3並列） | 約45分 |

**CSV形式（`type=5`）で落とすのが効く。** XBRLの完全パッケージではないので1件73KBに収まる。当初「約18,000書類のダウンロード」を重い作業と見ていたが（Issue #54）、実際には30分弱で済む。

**母集団で絞るのが効く。** 全提出者を落とすと29,931件だが、いま掲載している1,867社に限れば17,717件で足りる。時系列で見せたいのは掲載中の会社の推移であって、既に対象外の会社ではない。

**名寄せは `edinet_code` で足りる。** ADR-0006 でこのために CSV に足した列。証券コードと違い年をまたいで変わらない。

## 既知の限界

**古い年ほど欠ける。** T0 で実測した各年の値は次のとおり（全10年は `docs/timeseries/salary-history/design.md`）。

| 年 | 提出あり | 値を取れた社数 | カバー率 |
| --- | ---: | ---: | ---: |
| 2017 | 1,710 | 1,637 | 87.7% |
| 2020 | 1,757 | 1,748 | 93.6% |
| 2023 | 1,828 | 1,815 | 97.2% |
| 2026 | 1,867 | 1,867 | 100% |

上場が新しい会社・当時は有報を出していなかった会社は、その年の値を持たない。**欠けている年は線をつながず、欠けていること自体を見せる。** 内挿して滑らかな線にしない。

**2020年が凹んで見えたのは取得の窓のせいだった。** 6/1〜7/10 に限ると1,655社だが、COVID期の提出期限延長で96社が窓の外（7〜10月）に出ていた。窓を通年に広げて解消した（T0 手順5）。

**2019年より前は平均年間給与のXBRL要素そのものが無い。** 2017・2018年は全社を「従業員の状況」本文から拾うことになる。ここが10年に広げたときの最大の技術的障害で、抽出率をどこまで上げられたかは design.md にある。

**インフレを調整しない。** 名目値をそのまま並べる。実質化すると出典が「有報そのまま」でなくなり、ADR-0007 で決めた実測値の路線から外れる。物価の注記だけ添える。

## 作らないもの

**業績・株価の推移。** `market-data` 施策で別に扱う（Issue #55）。この施策は有報の「従業員の状況」に閉じる。

**予測。** 過去10年から将来を外挿しない。「根拠を隠した推定値を表示しない」（CLAUDE.md）に反する。

**ランキングページへの推移の持ち込み。** 1,867社 × 10年をトップページに載せるとペイロードが壊れる（Issue #22）。**推移は企業詳細ページだけが読む。**

**平均年齢・従業員数の推移。** 取得したデータには含まれるが、v1では平均年収だけを出す。項目を増やすのは読者の反応を見てから。
