# U13 ランキングのモック合わせ — plan.md

参照: Issue #88（親: #84）, `docs/ranking/spec.md` AC-7・AC-12〜AC-14, `docs/site-chrome/spec.md` 2, ADR-0007
依存: #80（U12 ランキングのレイアウト刷新）

## Context

U12 は Claude Design の `改善案.dc.html` を**直接読まずに**組んだ。実装したセッションで MCP が繋がっておらず、計画に書き起こした仕様（サイドバー216px・チップ・バー・偏差値列・ヘッダ検索）から作ったため、機能は spec を満たしているが**見た目がモックとズレている**（Issue #84）。この Unit はモックの現物を読んで合わせ直す。

**新しい機能は足さない。** 動くものは既にあり、変えるのは器の形と情報の置き場所だけである。したがってこの Unit で最も壊れやすいのは、**U12 が守っている性質を器の入れ替えで落とすこと**——操作でネットワークを起こさない（AC-7）、バーの基準を表示基準ごとに取り直す（AC-13）、偏差値に上位◯%を併記する（AC-14）の3つ。作業の順序はこれらを最後まで確かめられるように組む。

**アートボードは 5a / 5c を正とする。** 4a / 2a は表示基準スイッチが足される前の版で、見出しや列見出しが実測値モードを知らない。4a にしか無いもの（年齢そろえのときの meta 行の「実績」）だけそちらを見る。

## 進め方

1. **モックを読み、合わせないものを先に決める。** 偏差値の上位◯%・バーの正規化・実測値のときの年齢スイッチは、モックより先に決めた約束のほうが強い。**どこを意図的に外すかを design.md の対照表に書いてから手を動かす**——後から見た人が「直し忘れ」と読むのを防ぐ。
2. **在庫を確かめる。** 帯（muted のパネル）・丸いチップ・検索欄の帯が `design-system/ui/` の在庫で組めるかを見る。足りなければその場で作らず起票する。
3. **共通ヘッダから直す。** 3カラムの骨格と検索欄の帯を先に入れ、モバイルで2段に折り返さないことを確かめる。**ヘッダは全ページに出る**ので、ここが決まらないと C3 が始められない。
4. **表示基準・年齢の帯を作る。** ラベルと説明文を持つ器に両方を入れる。**実測値のときに年齢スイッチが無効で残ること**を先に固定してから見た目を変える（AC-11）。
5. **サイドバーを縦積みにする。** 選択肢を全幅ボタンにし、「適用中」を先頭へ移す。**216px の枠からはみ出さないことを毎回見る**——U12 でトグルが本文の表に重なってクリックを吸う事故を起こしている。
6. **表を4列に組み替える。** 平均年齢・在籍年数・従業員数を meta 行へ移す。列が減るので `table-fixed` の幅を取り直し、**社名が省略記号で切れないこと**を確かめる（切れているのが今の症状そのもの）。
7. **下部を組み直す。** 業種チップを本文カラムの中の帯に入れ、脚注をその下へ。**チップの左クリック横取りが生きていること**（AC-7）をここで確かめる。
8. **モバイルを合わせる。** 並び替えと「絞り込み」を1行に収め、行のカード枠を外す。**横スクロールが出ないことを毎回確かめる。**
9. **固める。** 見た目の骨格は E2E で、ロジックに触った箇所は単体テストで固定する。`e2e/ranking-refresh.spec.ts` は当たり判定が動くので同じ PR で直す。
10. **測って出す。** トップページの HTML gzip サイズを測り直し（U12 の 72.2KB から動くはず）、`npm run measure:prefetch` を回してプリフェッチが0件のままであることを確認してから PR にする。

## 着手前に見えている判断

**表の列を減らすかどうか。** 減らす。モックは 順位 / 会社名・業種 / 平均年収 / 偏差値 の4列で、平均年齢・在籍年数・従業員数は社名の下の meta 行にある。いまの7列は**社名が入りきらず省略記号で切れており**（「三菱商事…」）、一覧で最も重要な情報が読めない状態になっている。情報量は落ちない——同じ数字が meta 行に移るだけである。

**「適用中」をサイドバーへ移すのは PC だけ。** モバイルではサイドバーごとシートの中に隠れるので、何が効いているかが画面から消える。本文の上に残す（U12 の判断のまま）。

**偏差値の「上位◯%」は残す。** モックは偏差値の数字だけだが、`docs/product/glossary.md` が「単独で出さない」と決めている。列幅はこの2行が入る前提で取る。

## 検証

```bash
cd web && npm run typecheck && npm run lint && npm test && npm run test:e2e
cd web && npm run build            # / が ƒ (Dynamic)、/about が ○ (Static) のまま
cd web && npm run measure:prefetch # プリフェッチ0件のまま
```

- dev server を起動し、1280px と 390px の両方をブラウザで触る（並び替え・サイドバー・シート・業種チップ・戻る/進む）
- **ライトとダークの両方を見る。** 帯（muted）と枠（border）を増やすので、ダークで沈まないことを確かめる
- トップページの HTML gzip サイズを測り、design.md に記録する

企業詳細ページ（#89 / C3）、モックの「上限2,500万円」のバー正規化、会社ごとの紹介文、掲載企業数を増やしたときのペイロード（#22）。
