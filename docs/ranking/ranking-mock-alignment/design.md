# U13 ランキングのモック合わせ — design.md

参照: Issue #88（親: #84）, `docs/ranking/spec.md` AC-7・AC-12〜AC-14, `docs/site-chrome/spec.md` 2, ADR-0007
依存: #80（U12）

## 出来上がりの構造

### ページの骨格（`RankingApp`）

```
SiteHeader（site-chrome）          ブランド / 検索 / 表示モード＋計算方法
─────────────────────────────────
h1 + 説明文
ControlBand「並べ方」    BasisSwitch      + 説明文
ControlBand「年齢」      AgeSwitch        + ヒント（実測値のときは破線＋減光）
─────────────────────────────────
grid [13.5rem | 1fr]
  aside                       本文カラム
   ActiveFilterChips           件数 ／ 並び替え＋絞り込み（1行）
   RankingFilters（PCのみ）     RankingTable（md以上）／ RankingCardList（md未満）
                               RankingPagination
                               IndustryChips（muted の帯）
```

`aside` は `md:sticky`。**モバイルでも `aside` は消えない**——中身のうち `ActiveFilterChips` だけが残り、`RankingFilters` が `hidden md:block` でシートに移る。効いている絞り込みを2か所に描いて出し分けると、同じ解除ボタンが2つ存在することになり、読み上げからもテストからも曖昧になる。

### 表（`RankingTable`）

| 列 | 幅 | 中身 |
| --- | --- | --- |
| 順位 | `w-11` | `rank`（`text-lg font-bold`） |
| 会社名・業種 | 残り | ロゴマーク＋社名＋「本社のみ」＋`CompanyMetaLine` |
| 平均年収（有報）／推定年収（◯歳） | `w-44` | 金額＋`SalaryBar` |
| 偏差値 | `w-20` | 偏差値／上位◯%（2行） |

`table-fixed` のまま。**U12 の7列から4列に減らした。** 平均年齢・在籍年数・従業員数は `CompanyMetaLine`（社名の下の1行）に移っている。7列では社名の列に 200px 弱しか残らず、`truncate` が効いて「三菱商事…」のように**一覧で最も重要な情報が省略記号で切れていた**。移した3つはどれも「その会社がどんな会社か」を言う属性で、行どうしを見比べるために縦に揃える必要が無い。

`CompanyMetaLine` は `block truncate`。`truncate` は `overflow: hidden` を効かせるが、インライン要素のままでは溢れた文字がそのまま外へ出る（360px でページに横スクロールが出た）。

**年齢そろえのときだけ meta 行の末尾に「実績 ◯万円」が付く**（アートボード 4a）。補正後の数字だけを見せると、元がいくらだったのかを確かめる手段がページから消える。

### 帯（`ControlBand`）

ラベル・中身・ヒントを持つ器。`tone="solid"` は `bg-muted` の塗り、`tone="dashed"` は破線＋減光で「いまは使えない」を表す。**実測値のとき年齢スイッチを消さずに残す**（AC-11）ための無効の見た目をここに持たせている。

ラベルは `aria-hidden`。中のスイッチが `aria-label` で自分を名乗っているので、読み上げに同じ語を二度載せない。

### 並び替え（`SortSwitch`）

見えている文字は軸（平均年収／平均年齢／従業員数）だけで、**方向（高い順／若い順／多い順）は選択中かつ `sm` 以上でだけ**添える。3つとも方向まで書くと 390px で「絞り込み」と並ばず横スクロールが出る。

`aria-label` は常に `${軸} ${方向}`。見えている文字は必ずその部分文字列になっている（WCAG 2.5.3 Label in Name）。

### 業種チップ（`IndustryChips`）

本文カラムの中の `bg-muted` の帯に入れ、**社数を併記する**（`industryCounts`）。`<a href="/?ind=…">` の実体と左クリックの横取りは U12 のまま——実体はクロール経路（ADR-0006）、横取りは AC-7。

社数は `companies.json` に持たせず**描画時に数える**。1,867回のインクリメントで、`buildRankedCompanies` が同じ配列に対してやっている仕事より軽い。並びはデータの順のまま（社数の降順にしない）——チップの位置が固定されているほうが、何度も来る読者には探しやすい。

### 共通ヘッダ（site-chrome に触る）

`grid-cols-[auto_minmax(0,1fr)_auto]` の3カラムで、中央の検索だけが伸び縮みする。検索は入力欄と虫めがねボタンを突き合わせた1つの丸い帯（`sm` 未満ではボタンを落として入力欄だけ）。振る舞い（`/` では `pushState`、それ以外では `/?q=` へ遷移）は U12 のまま変えていない。

## モックに合わせなかったもの

**先に決めた約束のほうが強い箇所。** 直し忘れではないことを残す。

| モック（`改善案.dc.html`） | この実装 | 理由 |
| --- | --- | --- |
| 偏差値の数字だけを出す | **モックに合わせた**（当初は上位◯%を併記していたが、公開後に外した。下記） | — |
| 脚注「帯は…上限2,500万円で伸ばしたもの」 | そのページの1位を100% | spec.md 1.11。固定上限だと下位ページで棒が全部短くなる |
| モバイルでは年齢スイッチを出さない（5c） | 破線＋減光で残す | AC-11。消すと「年齢そろえ」で何が増えるのかが分からない |
| 表の脚注をページ末尾（業種チップの下）に置く | 表の `<caption>` のまま | `<caption>` は `<table>` の中にしか置けない。外に出すと表と注記の対応が読み上げから切れる。位置は表の直下・ページネーションの上 |
| h1 直下に会社の紹介文（4b・2b） | 出さない | 企業詳細ページ側の話（#89）。データを持っていない |

## 実測値

| | U12 | U13 |
| --- | --- | --- |
| `/` の初期HTML（gzip） | 72,232 B | **71,671 B**（−561 B） |
| `/company/[id]` の初期HTML（gzip） | 12,873 B | **13,283 B**（+410 B） |
| `/company/` へのプリフェッチ | 0件 | 0件 |

`/` が減ったのは、行あたりのセルが7つから4つになり `<td>` の繰り返しが減ったため（meta 行の文字と業種チップの社数を足してもなお減る）。**`/company/[id]` が増えたぶんは共通ヘッダの検索ボタン**で、全ページに等しく乗る。

## 公開後に直したもの（2026-08-20）

本番を見た運営者からの指摘。**どれもモックとの差を埋める向きの修正**で、機能は変えていない。

| 指摘 | 直したもの |
| --- | --- |
| 表にスクロールバーが出る | `Table` の器は `overflow-x-auto` だけを持つが、**CSS の仕様で片方が `visible` でないと `visible` は `auto` に計算される**（CSS Overflow 3）。つまり縦も `auto` で、端数で1pxはみ出すと表だけが縦スクロールする小窓になっていた。`design-system/tableContainer.ts` のクラスで器の overflow を打ち消す（プリミティブは触らない） |
| 偏差値の「上位◯%」が要らない | ランキング表・モバイルの行・企業詳細のカード・要点・h1 直下から外した。**モックに無いものを足さない**（運営者の指示）。100を超えうることは脚注に残し、水準は順位で読ませる（`docs/product/glossary.md` を改訂） |
| サイト名を押してもフィルタが解けない | `<Link href="/">` は同じルートへの遷移なので `RankingApp` が作り直されず、URL だけ `/` になっていた。`BrandLink` が `/` の上ではクリックを横取りし、`pushRankingReset()` で URL を書いて合図を投げる |
| meta 行の業種が要らない | 行が長くなって末尾の従業員数が見切れていた。業種は左のサイドバーで選ぶものなので、列見出しも「会社名」に戻した |
