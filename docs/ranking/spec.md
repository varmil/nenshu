# spec.md — 年齢補正ランキング

対象面: user-web（ユーザー画面）

MVP はランキング1ページと計算方法ページの2枚で構成する。企業詳細ページ・業種ページ・年齢別ページは Bolt 2 以降に回す。
用語は `docs/product/glossary.md` に従う。

---

## 1. ランキングページ（`/`）

### 1.1 何を出すか（WHAT）

1,867社を1つの表に並べる。並び順は選択中の目標年齢における推定年収の降順。

初期状態は目標年齢35歳、フィルタなし、検索語なし。

### 1.2 なぜ（WHY）

読者が知りたいのは順位ではなく、自分の年齢でその会社に入るといくらかという金額になる。既存のランキングはこの問いに答えていない。

### 1.3 表の列

| 列 | 内容 | 備考 |
| --- | --- | --- |
| 順位 | 現在の絞り込み・目標年齢での順位 | フィルタ適用後に振り直す |
| 会社名 | `name` | 「本社のみ」バッジをこの列に添える |
| 業種 | `tse33` | |
| **推定年収** | 目標年齢での補正後の金額 | **視覚的に最も強い列にする** |
| 平均年齢 | `avg_age` | |
| 平均年収 | `avg_salary` | 補正前の実額 |
| 在籍年数 | `avg_tenure` | |
| 従業員数 | `employees_nonconsolidated` | 単体 |

金額は万円単位・カンマ区切りの整数で表示する（例: 2,178万円）。年齢と在籍年数は小数第1位まで。

推定年収の列見出しには目標年齢を含める（例: 「35歳時点の推定年収」）。列見出しか直下に、この値が推定であることを示す注記を常時置く。

### 1.4 年齢スイッチ

25 / 30 / 35 / 40 / 45 / 50 / 55 / 60 歳の8段。単一選択。

操作すると推定年収の列と順位が更新される。ページ遷移も再取得も発生させない。

### 1.5 フィルタ

4種すべて絞り込み方向に働く。複数指定は AND で結合する。

**業種** — 東証33業種から単一選択（プルダウン）。

**従業員数（単体）** — 単一選択。

| 区分 | 条件 | 該当社数 |
| --- | --- | ---: |
| 〜300人 | < 300 | 517 |
| 300〜1,000人 | 300 以上 1,000 未満 | 734 |
| 1,000人以上 | 1,000 以上 | 616 |

**在籍年数** — 単一選択。

| 区分 | 条件 | 該当社数 |
| --- | --- | ---: |
| 〜13年 | < 13 | 545 |
| 13〜17年 | 13 以上 17 未満 | 732 |
| 17年以上 | 17 以上 | 590 |

**平均年齢** — 単一選択。

| 区分 | 条件 | 該当社数 |
| --- | --- | ---: |
| 〜40歳 | < 40 | 450 |
| 40〜43歳 | 40 以上 43 未満 | 709 |
| 43歳以上 | 43 以上 | 708 |

境界値は三分位に寄せている。実データの平均年齢は中央値42.0歳・四分位40.0〜44.0歳に固まっており、「30歳未満」のような一般的な区切りでは該当が6社しかなく機能しない。

### 1.6 フリーワード検索

会社名に対する部分一致。以下を正規化してから照合する。

- 全角英数 → 半角
- 半角カナ → 全角カナ
- 英字 → 小文字
- 空白（半角・全角）の除去
- 法人格の除去（株式会社・(株)・㈱・有限会社・合同会社）

「商船三井」で「株式会社　商船三井」が引ける必要がある。社名に全角スペースを含むものが74件ある。

### 1.7 URLへの反映

年齢・フィルタ・検索語をクエリパラメータに載せる。

```
/?age=35&ind=情報・通信業&emp=1000-&ten=-13&aage=40-43&q=商船
```

初期値と同じ項目はクエリに出さない（初期状態の URL を `/` に保つ）。
ブラウザの戻る・進むで状態が復元される。URL を共有すれば同じ絞り込みが再現される。

### 1.8 空・端の状態

- 絞り込み結果が0件のとき、条件を緩める案内を出す。エラー表示にはしない。
- 表示件数が多いため、初期表示は上位100件とし、以降はスクロールまたは追加読み込みで伸ばす。全件を一度に描画しない。

### 1.9 対象外（MVP）

企業詳細ページ、業種別ページ、年齢別の静的ページ、複数選択フィルタ、任意の列でのソート、CSVダウンロード、広告枠。

## 2. 計算方法ページ（`/about`）

装飾ではなく必須とする。既存サイトの弱点は根拠が見えないことにあり、方法の公開そのものが差別化になる。

載せるもの。

- 補正の式と、賃金カーブをどこから作ったか
- 対象範囲（2026年6〜7月提出の有報、単体従業員100人以上、1,867社）
- 「本社のみ」バッジの意味と、持株会社と事業会社で数百万円ずれる実例
- 限界の明示。平均値であること、単体の数字であること、カーブが会社間の差から作られていること
- **年齢スイッチが同業種内の順位を動かさないこと**
- 出典（EDINET / 賃金構造基本統計調査）

## 3. 非機能要件

**配信** — 完全な静的配信。サーバーサイドの実行環境を持たない。

**データ量** — 初期ロードのペイロードは gzip 後 100KB 以内に収める。1,867社ぶんで概算60KBを見込む。

**応答** — 年齢スイッチ・フィルタ・検索の操作から表の更新まで、通常の端末で100ms以内。ネットワークアクセスを伴わない。

**対応環境** — モバイルを主とする。1,867行の表を狭い画面で読ませるため、モバイルではカード状の表示に切り替える。

**SEO** — トップページの初期表示（35歳・絞り込みなしの上位100社）はHTMLに含める。クライアント側の描画待ちにしない。

**アクセシビリティ** — 年齢スイッチとフィルタはキーボードで操作できる。表にはヘッダーの対応付けを持たせる。

## 4. 受け入れ基準

### AC-1 初期表示

```gherkin
Given トップページを開く
When 何も操作しない
Then 目標年齢35歳のランキングが上位100件表示される
And 1位に「株式会社キーエンス」が推定年収2,178万円で表示される
And 推定年収の列見出しに「35歳」が含まれる
```

### AC-2 年齢スイッチ

```gherkin
Given トップページを開いている
When 年齢スイッチで25歳を選ぶ
Then 1位のキーエンスの推定年収が1,642万円に変わる
And ページ遷移が発生しない
And URLに age=25 が反映される
```

```gherkin
Given 年齢スイッチで60歳を選んでいる
When ランキング上位50社を見る
Then 35歳時点の上位50社のうち40社以上が含まれる
```

同業種内で順位が動かないことを、この基準で明示的に固定する。挙動が変わったら計算が壊れている。

### AC-3 業種フィルタ

```gherkin
Given トップページを開いている
When 業種で「海運業」を選ぶ
Then 7社だけが表示される
And 順位が1から振り直される
And URLに ind=海運業 が反映される
```

### AC-4 従業員数フィルタ

```gherkin
Given トップページを開いている
When 従業員数で「1,000人以上」を選ぶ
Then 616社が表示される
```

### AC-5 フィルタの結合

```gherkin
Given 業種で「情報・通信業」を選んでいる
When 平均年齢で「〜40歳」を追加で選ぶ
Then 両方の条件を満たす会社だけが表示される
And 件数が業種のみのときより少ない
```

### AC-6 フリーワード検索

```gherkin
Given トップページを開いている
When 検索欄に「商船三井」と入力する
Then 「株式会社　商船三井」が結果に含まれる
```

```gherkin
When 検索欄に「ｷｰｴﾝｽ」と入力する
Then 「株式会社キーエンス」が結果に含まれる
```

### AC-7 URL復元

```gherkin
Given /?age=45&ind=銀行業 を直接開く
Then 年齢スイッチが45歳を選択した状態になる
And 業種プルダウンが銀行業を選択した状態になる
And 銀行業82社が45歳時点の推定年収で並ぶ
```

```gherkin
Given フィルタを操作した後
When ブラウザの戻るを押す
Then 一つ前の絞り込み状態に戻る
```

### AC-8 0件

```gherkin
Given 業種で「鉱業」を選んでいる
When 検索欄に「存在しない社名」と入力する
Then 0件であることと、条件を緩める案内が表示される
And エラー表示にはならない
```

### AC-9 推定であることの明示

```gherkin
Given どの年齢を選んでいても
Then 推定年収が推定値であることを示す表記が画面上に存在する
And 平均年収（補正前）と推定年収が同じ書式で並んでいない
```

### AC-10 計算方法ページ

```gherkin
Given ランキングページを開いている
When 計算方法へのリンクをたどる
Then 補正の式・出典・対象範囲・限界が読める
And 年齢スイッチが同業種内の順位を動かさないことが書かれている
```
