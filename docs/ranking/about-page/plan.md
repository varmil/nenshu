## 事前調査で確定した事実（すべてコード・実データで検証済み）

**対象範囲**（`pipeline/salary/unified.py`）:
- EDINET に **2026年6月1日〜7月10日**提出の有価証券報告書、単体従業員 **100人以上**（`MIN_EMPLOYEES=100`）、平均年齢20〜65歳、平均年間給与100万円超、非上場を含む → **1,867社**

**「本社のみ」バッジ**（`unified.py` の `badge()`）:
- 単体従業員数 ÷ 連結従業員数 < 10%（連結データが無い会社には付けない）→ **173社**
- README.md の「かつ連結500人以上」は**実コードに無い**。glossary.md の記述（10%未満）が正しい
- 実例: みずほFG 平均1,167万円/42.5歳/単体2,867人/バッジ有 vs みずほ銀行 870万円/40.7歳/単体23,356人/バッジ無

**賃金カーブ**（ユーザー確認済み: コードの実態を書く）:
- 出荷されているのは `annual_curves.json` の `ANNUAL_INDUSTRY`。`fetch_estat.py` が e-Stat から取得（statsDataId `0003425893`、`cdTime=2023000000` = **令和5年**賃金構造基本統計調査）
- **年収 = きまって支給する現金給与額 × 12 ＋ 年間賞与その他特別給与額**（賞与・時間外を含み、有報の平均年間給与と定義が揃う）
- 男女計・学歴計・企業規模計・民営事業所・**一般労働者**
- 代表年齢 22,27,...,67 の10点、区分線形補間、範囲外は端の値で頭打ち
- **産業大分類17系列**。東証33業種から機械的に写像（ユーザー確認済み: /about では開示する）
- ⚠️ `pipeline/salary/curves.py` の先頭 docstring は「令和6年・所定内給与（月額）」と書いているが、これは現在フォールバック扱いの旧定数 `INDUSTRY_CURVES` 向けの記述。**このUnitで修正する**

**年齢スイッチが同業種内の順位を動かさないこと**（計算で検証済み）:
- 8つの目標年齢すべてについて、33業種すべてで同業種内の並び順に変化なし（0件）
- TOP50は25歳時点と60歳時点で **41社**重なる（intent.md の記述と一致）

**モデルの構造的な偏り（今回発見・定量化済み）**:
- 式は実質「その会社の産業平均に対する倍率は何歳でも同じ」と仮定している
- 倍率の実測分布: 中央値 **1.22倍**、p90 **1.64倍**、最大 **4.32倍**（キーエンス）。2倍超が49社、3倍超が9社
- 産業計の25歳は382万円。倍率をそのまま掛けるため、キーエンス**25歳1,642万円**、三菱商事**25歳1,491万円**と出る
- 現実には新卒初任給が業界横断で圧縮され、企業間の差は年次・等級を重ねて開く。**倍率一定と置くと高倍率企業ほど若年側が過大**になる。中央値付近（1.2倍）では誤差は小さく、**歪みは高給企業に集中**
- 外挿距離（平均年齢の中央値は42歳）: 目標**25歳で平均16.8歳**、35歳7.0歳、45歳3.7歳、**60歳で18.2歳**。両端が最も苦しい
- 60歳側は別の問題もある。カーブは57歳ピークから62歳で急落（産業計605万→462万）。定年・再雇用で下がった人を含む産業平均の形をそのまま当てている
- **実装ロジックにバグは無い**（U0のテストが1,867社全件で`salary35`とCSVの一致を固定済み。補間も仕様どおり）。壊れているのは順位ではなく絶対額

## 決定事項（設計の骨子）

### ページ構成

`web/app/about/page.tsx`（Server Component）。`searchParams` を読まないため静的プリレンダーされる（ビルド出力で `○ (Static)` になることを確認）。文章が本体なのでこのファイルに直接書く。

載せる順:
1. リード（このページは何か）
2. 補正の式 — `推定年収(目標年齢) = 平均年間給与 × カーブ[産業](目標年齢) ÷ カーブ[産業](平均年齢)`。みずほ銀行の実データで具体例
3. 賃金カーブの作り方と出典（令和5年賃金構造基本統計調査・年収ベース・産業大分類17系列であることを含む）
4. 対象範囲（提出期間・従業員100人以上・1,867社）
5. 「本社のみ」バッジ + みずほFG / みずほ銀行の実例
6. **年齢スイッチは同業種内の順位を動かさない**（理由と、TOP50が41社重なる事実）
7. **限界の明示** — 上記「モデルの構造的な偏り」を含める:
   - 平均値であって分布ではない
   - 単体の数字（連結子会社の社員は入らない）
   - カーブが会社間の差から作られている（生態学的推論）
   - 33業種が17カーブに集約されている
   - **倍率一定の仮定により、産業平均より大幅に高い会社ほど若年側（特に25歳）が過大に出る。** 会社の平均年齢から離れた年齢ほど不確実
   - 推定値であって実測ではない
8. 出典リンク（EDINET / e-Stat）

### 数値をハードコードしない

**データから算出できる数値は `companies.json`/`curves.json` から引く。** 年1回のデータ更新で/aboutの数字が静かにずれるのを防ぐ。

新規 `web/features/ranking/lib/aboutFacts.ts`（React非依存の純粋関数）:

```ts
export function buildAboutFacts(companies: CompaniesData, curves: CurvesData): AboutFacts
```

- 掲載社数 = `rows.length`、バッジ社数 = `rows.filter(r => r[8] === 1).length`
- 業種数 = `industries.length`、カーブ数 = `curveKeys.length`、代表年齢 = `curves.agePoints`
- みずほの実例2社は**会社名で引く**（`id` は非上場だと `doc_id` 由来で更新時に変わる）。見つからなければ **throw**（Server Component なのでビルド時に落ちて気づける。`pipeline/scripts/build-data.ts` がデータ異常で落とすのと同じ方針）
- 金額は既存の `lib/format.ts` の `formatManYen` を使い、ランキング表と書式を揃える。Issue本文は「みずほFG 1,166万」だが `formatManYen`（四捨五入）では **1,167万円**。表と食い違わせないため実装側を正とし、design.md に理由を書く

**データから出ない値は本文に直書き**（パイプラインの定数のため）: 提出期間、単体従業員100人以上、平均年齢20〜65歳、e-Stat の調査年・系列名。design.md にこの線引きを書く。

### ランキングページからのリンク（AC-10）

`RankingApp.tsx` のヘッダーに `next/link` の `<Link href="/about">計算方法</Link>`。about 側にもランキングへ戻るリンク。ページ間の離散的なナビゲーションなので `<Link>` でよい（CLAUDE.md「採用スタック」の但し書きどおり。フィルタ操作の `pushState` とは別物）。

### エッジキャッシュ

`next.config.ts` の `headers()` は現在 `source: "/"` だけなので `/about` を追加する。ただし**静的プリレンダーページが Worker を経由せず Assets バインディングから配信される場合 `headers()` は効かない**（`_next/static/*` で実際に踏んだ）。ビルド後に `.open-next/` の配置を実測し、Assets 側なら `public/_headers` に書く。結果を design.md に記録する。

## 別Issueに切り出すモデル改良（調査結果を添えて起票する）

**タイトル案**: 「若年側の推定が過大になる問題（倍率一定の仮定）を見直す」

上記の定量結果に加え、調査したデータ源の候補を書く:

| 候補 | 内容 | 費用/許諾 | 評価 |
| --- | --- | --- | --- |
| **標準労働者カーブ**（賃金構造基本統計調査） | 学校卒業後すぐ入社し同一企業に継続勤務している労働者。学歴別・年齢階級別。中途入社の混入を除いた**同一企業内の年功に最も近い公的統計** | 無料・e-Stat | **本命候補。** 現行の「一般労働者」は中途を含み年功が緩く出る。標準労働者（大卒）に替えると年功が急になり25歳推定が下がる。**枠組みを変えずカーブ差し替えだけで改善** |
| **初任給を22歳の固定点にする2点アンカー** | 学歴別初任給（無料）で若年端を固定し、平均年齢の実測値と結ぶ | 無料・e-Stat | 倍率一定の仮定を部分的に壊せる。ただし「全社の初任給＝産業平均」と置くので高給企業では過小になる |
| **令和7年データへの更新** | 現在は令和5年（2023年）。令和7年は速報2026年1月・概況2026年3月公表済み、e-Stat に283データセット | 無料・e-Stat | **2年古いので単独でも実施価値あり。** 安価な改善 |
| **就職四季報**（東洋経済データサービス） | 約1,300社の**25歳・30歳・35歳の大卒総合職賃金**＋初任給。**企業レベルの年齢別賃金**そのもの | **有償**・要問い合わせ | 構造的には本命だが商用ライセンスが要る。1,867社中1,300社程度のカバー |
| **OpenWork** | 年齢別（25〜55歳）年収。キーエンスはn=454 | **不可** | 登録壁の内側・著作権表示あり・再利用許諾なし・口コミベース。intent.md が「口コミは作らない」と明記。**答え合わせの参照としてのみ使う** |

注意点として書き添える: 標準労働者カーブに替えても**倍率一定の仮定自体は残る**。また会社の平均年間給与は非大卒・中途を含むので、大卒標準労働者カーブと混ぜる整合性に注意が要る。
