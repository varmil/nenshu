## W2 異常値の除去と「区分別」の表記

親 Issue #185（#207 は同じ内容なので重複として閉じた）。spec.md の 1.4（値の扱い）と 2.（表示）にかかる。

女性活躍DBは**会社の自己申告**で、入力ミスがそのまま入っている。公開後に運営者が3件見つけた。

1. **ソニーグループの有給取得率が 100%** と出ていた。同じ会社が区分「全体」に 63.7% を登録しており、100% のほうが誤り（#185 例1）
2. **野村総合研究所の残業時間が 0.0h** と出ていた。残業の軸は小さいほど上位なので、この会社が最上位に出る（#185 例2・#207 例2）
3. **ラクスの有給がレーダーだけ「掲載なし」**。節には3区分の値が出ている（#207 例1）

**1と2はデータの問題、3は表記の問題**で、直す場所が違う（前者は取り込み、後者は図とリスト）。

### 事前に測った数値（`worklife_2026.csv` 2,369行に対して）

- **残業 0.0**: 全体値10社・区分別128セル/81社。**自社の中で矛盾している会社がある**——花王は全体15.4hなのに区分5件すべて0.0、東洋エンジニアリングは全体0.0なのに総合職8.0h
- **有給 100% ちょうど**: 4社（ソニーグループ・富士電機・ＩＭＶ・極東貿易）。**4社とも区分別に60〜78%を登録していて矛盾する。**反例は0件
- **全体値が区分の[最小,最大]の外**: 残業50社・有給33社。**これは矛盾の証拠にならない**——区分は会社の全労働者を覆っているとは限らない（滋賀銀行の区分は「パートタイマー、シニアスタッフ」だけ）
- **レーダーだけ「掲載なし」になる会社**（節には値がある）: 有給221社・残業114社
