# intent.md — 働きやすさ指標

親 Issue: #148

## 狙い

いま出しているのは**いくらもらえるか**だけである。転職検討者が同じくらい気にする**どう働くことになるか**——残業はどのくらいか、有給は取れるのか、男女で賃金がどれだけ違うのか——に、このサイトは1つも答えていない。

これらは厚生労働省「女性の活躍推進企業データベース」に一次情報として公開されている。**法人番号で有報の1,867社に直結できる**ので、追加の調達コストはZIP 1本ぶんしかない（ADR-0009）。

企業詳細ページに「働きやすさ」の節を置き、**平均残業時間・年次有給休暇の取得率・男女の賃金の差異**の3つを出す。

## North Star KPI

ranking・company・timeseries 施策と同じ**自然検索からの月間セッション数**。

補助指標として、企業詳細ページの**滞在時間**を見る。年収しか無かったページに別種の指標が増えるので、ここが動かなければ読者はこの情報を求めていない。

## 仮説

**H1.** 「◯◯（社名） 残業」「◯◯ 有給取得率」「◯◯ 男女 賃金」のような検索需要があり、いまのサイトには受け皿が無い。

*検証*: 公開3ヶ月後、企業詳細ページの検索クエリに「残業」「有給」「賃金 差異」を含むものが現れるか。

**H2.** 年収と働き方を**同じ1ページ**に置けることがこのサイトの強みになる。厚労省のデータベースは会社を1社ずつ引くことしかできず、年収と並べては見られない。

*検証*: 企業詳細ページの直帰率を追加の前後で比較する。

**H3.** 自己申告の値でも、**出典・時点・欠測を隠さずに出せば**読者の判断材料になる。「根拠を隠した推定値を表示しない」（CLAUDE.md）の裏返しで、根拠を出せる値なら自己申告でも載せてよい。

*検証*: 仮説というより方針の確認。W1 で、出典と時点が画面から辿れる形で実装できることを確かめる。

## 前提の確認（実測済み）

`4e6b3d07-99_20260820_utf8_bom.zip`（2026-08-20 生成・全件版）と `Edinetcode.zip` を実物で測った。**法人番号での本突合の結果である。**

| 項目 | 実測値 |
| --- | ---: |
| 女性活躍DB の行数 / 列数 | 64,879行 / **236列** |
| 法人番号を持つ行 | 62,534行（96.4%・ユニーク62,527） |
| 有報1,867社のうち法人番号を引けた社数 | **1,867社（欠損なし）** |
| **有報1,867社と突合できた社数** | **1,690社（90.5%）** |
| 男女の賃金の差異が埋まっている | 1,475社（突合比 87.3% / 全社比 79.0%） |
| 平均残業時間が埋まっている | 1,038社（61.4% / 55.6%） |
| 年次有給休暇の取得率が埋まっている | 1,032社（61.1% / 55.3%） |
| **3指標のいずれかを持つ** | **1,548社（91.6% / 82.9%）** |

中央値は 残業 14.5時間／月、有給 74.0%、男女の賃金の差異 70.2%。

**残業と有給は「全体」と「雇用管理区分ごと」の2箇所に分かれて入っている。両方を見ないと4割を取りこぼす**（全体だけだと残業56.2%・有給23.2%）。

**同じ法人番号が2行以上ある会社は、突合できた1,690社の中には1件も無かった。**

**突合キーは法人番号しかない**（ADR-0009）。**証券コードと社名で突合した場合と突き合わせたところ、29社が誤った相手に紐づいていた**（暫定突合1,679社の1.7%）。内訳は持株会社が子会社にマッチしたものが28社（おきなわフィナンシャルグループ→沖縄銀行、京都フィナンシャルグループ→京都銀行、テレビ東京ホールディングス→テレビ東京、ニトリホールディングス→ニトリ、ハウス食品グループ本社→ハウス食品 など）と、証券コードの誤登録が1社（阪急阪神ホールディングスの9042で阪神電気鉄道が返る）。

**しかも法人番号のほうが突合率が高い**（90.5% > 89.9%）。精度と網羅のトレードオフですらなかった。

## 既知の限界

**残業と有給は4割の会社で埋まっていない。** 公表義務の履行先は自社サイトでもよく、データベースへの掲載は任意なので、載せていない会社がある。**欠けていることを見せる**——項目ごと消すと、読者は「残業が少ない会社」と区別できない。

**自己申告であり、第三者の検証を経ていない。** 有報の平均年間給与は監査を経た法定開示だが、こちらは企業が自分で登録した値である。同じページに並べる以上、この違いを明示する。証券コードの誤登録2件は、その性質が実際に表れた例になる。

**持株会社は載らない。** 有報の提出者が持株会社で、女性活躍DBには事業子会社が別法人として登録されている場合、法人番号が一致しない。未突合177社の筆頭は大和証券グループ本社・東京海上ホールディングス・野村ホールディングス・三井住友トラストグループで、未突合群の単体従業員数の中央値は246人（全体は588人）。**子会社の数字を親会社の行に出さない**（ADR-0009）。

**時点が会社ごとにばらばら。** データ集計時点は2026年3月が最多だが、2023年のものもある。有報の決算期（2026年3月期）とは別の時点なので、**会社ごとの時点を必ず画面に出す**。

**男女の賃金の差異は単独で読むと誤読される。** 値は「女性の平均賃金 ÷ 男性の平均賃金 × 100」で、差異の主因は職種構成や勤続年数の差であることが多い。718社は自由記述の説明を付けているので、**ある会社はそれも一緒に出す**。

**雇用管理区分は自由記述で、会社ごとに数も名前も切り口も違う。** 区分数は0〜5、区分名は1,548社で1,009種類。切り口は 雇用形態（総合職 / 派遣社員）・職能（営業・管理系 / 技術系）・組織（カンパニー / ユニット / グループ）の3通りがあり、1社の中でも混ざる。

**これは欠点ではなく、そのまま出すべき情報である。** 平均して1つの値にしないのはもちろん、**こちらで統一もしない**（`docs/worklife/spec.md` 2.2b）。その会社が自社をどう切っているかは、残業時間そのものと同じくらい読者の役に立つ。

## 作らないもの

**働きやすさランキング。** 残業の少ない順・有給の高い順に1,867社を並べない。記入率が6割で、載せていない会社が上位にも下位にも消える。自己申告値でもある。

**順位・偏差値・スコア。** 年収で作っている `stats.json` の仕組みをこの指標に広げない。母集団が「登録した会社だけ」になり、年収の順位と同じ顔をした別物ができる。

**ホワイト企業・ブラック企業の判定。** 3つの数字から総合評価を作らない。評価は読者がする。

**女性活躍DBの他の項目。** 236列のうち今回出すのは3つだけ。管理職の女性比率・育児休業取得率・えるぼし認定なども取れる（いずれも記入率7〜9割）が、v1では出さない。項目を増やすのは読者の反応を見てから。

**若者雇用促進総合サイト（卒3年以内離職率・平均継続勤務年数）。** 同じ `worklife` 施策に合流させる想定だが、この Intent の対象外とする。ユースエール認定は突合できた会社のうち3社しかなく（中小企業向けの認定のため）、掲載率が女性活躍DBよりかなり低い可能性がある。調達可否の調査から始める。
