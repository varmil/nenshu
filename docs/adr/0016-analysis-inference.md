# ADR-0016: AI 分析は推測してよい——落とす線を「事実の誤り」だけに引き直す

- 状態: 採用
- 日付: 2026-09-01
- 関連: [ADR-0015](0015-company-analysis-subjectivity.md)（分析セクションの主観と材料。**決定1 の「材料から導ける」という線と、決定2「モデルの記憶は材料にしない」を上書きする**。決定3〜7 は据え置き）, [ADR-0010](0010-company-summary-sourcing.md)（会社説明文の出所。**決定2 の最後に残っていた「モデルの一般知識から補わない」が、分析セクションに限ってここで解ける**）, Issue [#214](https://github.com/varmil/nenshu/issues/214)（親）・[#241](https://github.com/varmil/nenshu/issues/241)（C9）。施策は `docs/company/`

## 背景

**50回まわして、分析が要約と大差ないものになっていた**（運営者の指摘・2026-09-01）。**わざわざ2つに分けたのに、分析も事実を述べるにとどまっている。**

原因は規格ではなく、**検証パスが落としてきた型の系統**にある。C9 は回すたびに落ちた型を `prompts/generate.md` へ書き戻してきたが、積み上がった型A1〜A19 のうち **9つが「材料が述べていないことを書くな」という同じ系統**だった。

| 型 | 落としていたもの |
| --- | --- |
| A1 | 内訳が書かれていない影響を切り分けた |
| A2 | 材料が述べていない因果を作った |
| A6 | 材料が書いていないことを「無い」と断定した |
| A7 | 1期の増減から趨勢を述べた |
| A11 | 材料が持っていない比較を作った |
| A15 | 会社が並べているものに重みを付けた |
| A17 | 数字を評価する基準を材料の外から持ち込んだ |
| A18 | 減収の要因を、理由の書かれていない減益にも掛けた |
| A19 | 並べられているものに包含関係を作った |

**どれも「解釈するな」と言っている。** 1つずつは正しく見え、実際そのたびに文は材料へ近づいた。**近づいた先が要約だった。**

**運営者が示した対照がそれを一目で示す。** `prompts/verify.md` は次の表を「落ちた文 → 直した形」として載せていたが、**望まれているのは左側であり、しかもまだ弱い。**

| verify.md が「落ちた文」として挙げていたもの | 実際に望まれている側 |
| --- | --- |
| 会計処理の変更を差し引いても縮小は続いている | **これ** |
| 労務費と資材価格の高騰が利益を削っている | **これ** |
| 上場も2024年11月と新しく | **これ** |
| 待遇がそろっている分だけ入り口の競争は厳しい | **これ** |

**4つとも、材料の数字を突き合わせれば読者が納得できる推測である。** そして4つとも、**有報を数万字読める人なら自分で辿り着くが、そうでない人には届かない**種類の話でもある。ADR-0015 が「意味付け」と呼んだのはまさにこれで、**実装の側が型を積むうちに、その狙いから離れていた。**

## 決定

### 1. 分析は推測してよい。「材料から導ける」を「材料から推測できる」へ広げる

**因果・評価・見通し・重み付け・比較・含意を書く。** 材料が明示していなくても、材料の数字と記述から**そう読めるなら書いてよい**。

書く先は **「うまくいっていること」「うまくいっていないこと」「今後の挑戦」**（ADR-0015 決定1 のまま）で、**求職者がその会社をどう見ればいいかが分かる言葉にする**。

- **因果を作ってよい**（型A2 を外す）。「労務費と資材価格の高騰が利益を削っている」は、材料が減益と労務費高騰を別々に書いていても**そう読めるなら書ける**
- **切り分けてよい**（型A1 を外す）。「会計処理の変更を差し引いても縮小は続いている」は、内訳の金額が材料に無くても**規模感から推測できるなら書ける**
- **重みを付けてよい**（型A15 を外す）。会社が4つ並べていても、**求職者にとって効くのがどれかを言ってよい**
- **趨勢・比較・水準を語ってよい**（型A7・A11・A17 を外す）。1期しか無くても「この流れが続くなら」と書ける
- **材料の外の文脈を持ち込んでよい**（決定3）

**「〜とみられる」「〜だろう」で逃げる必要はない。** 言い切ってよい。**読者はこれが AI の分析だと分かって読む**（ADR-0015 決定4・C10 の要件）。

### 2. 落とす線は「事実の誤り」だけに引き直す

**残すのは、材料と食い違う記述だけである。**

| 落とす | 例 |
| --- | --- |
| **数値の向き**（型S1・A5） | 2,278 → 2,045 億円と減っているのに「上回った」 |
| **数値の幅**（型A8） | 9.0%増を「二桁の増益」 |
| **出来事の時点**（型A12） | 翌期の発売を当期の新作として書く |
| **区分**（型A10・A14・A16・型④） | セグメントの損益をその中の事業名で呼ぶ／別の節の出来事を移す |
| **材料の外の属性を事実として足す**（型A3） | 原文に無い工場・製品・資本関係を書く |
| **改善要因を悪化の中身として並べる**（型A13） | 増益要因を減益の説明に混ぜる |

**この6つは推測ではなく誤りである。** 読者が材料に当たれば違うと分かり、しかも「そう読める」の余地が無い。

**それ以外は落とさない。** 型A1・A2・A6・A7・A11・A15・A17・A18・A19 と、要約側の型②（重み付け）は、**分析については廃止する**（要約側では引き続き効く）。

### 3. モデルの記憶と一般的な知識を使ってよい。ただし数値だけは材料にあるものに限る

**ADR-0010 決定2 の最後の線をここで解く。** 業界の文脈・語の説明・その会社が置かれている状況の一般的な理解・相場観を、**取ってきた文書の裏付け無しに書いてよい。**

**ただし具体的な数値は材料にあるものだけ。** 記憶から金額・率・順位・シェア・従業員数を書かない。

**この一線だけを残す理由は、害の形が違うことにある。** 記憶から書いた**文脈**が外れていても「そう読める話」の範囲に収まり、読者は分析として受け取る。**記憶から書いた数字は事実の顔をして出る**——読者はそれを有報の数値と区別できず、同じページの表と食い違えばサイトの立て方（根拠を全部画面に出す）そのものが崩れる。ADR-0010 が試作のキーエンスで踏んだ「原文と逆のことが書かれ、混ざったことを検出する手段が無い」型は、**数字で起きたときにいちばん重い。**

**外部の文書は引き続き積極的に使う**（ADR-0015 決定2 の 1〜3 と決定3・決定6 は据え置き）。**使ったら URL を残す**——記憶で書いてよくなっても、取ってきたものは出典を示せるほうが読者に強い。

### 4. 検証パスの役割を「材料に当たっているか」から「事実の誤りが無いか」へ変える

**検証パスは廃止しない。** 見る対象を決定2 の6つに絞る。

**「言い過ぎ」を落とさない。** ADR-0015 の時点では「落ちるのはたいてい言い過ぎで、主張を弱めるか帰属を付ければ通る」と書いていたが、**その弱め方こそが分析を要約に近づけていた。**

**申告の仕組みは残す**（49回目に verify.md へ書いた）。落とさなかったが気になったものを添えてもらうことで、線の引き直しがまた要るときに気づける。

### 5. 対で出すこと・断りを置くことは据え置き

ADR-0015 決定4（読者が要約と分析を見分けられることは要件）と、決定7 の「要約と分析は対で出す」は**そのまま**。**踏み込むほど、これが AI の評価であると読者に分かることの重みが増す。**

## 理由

**2つに分けた意味がそこにあるからである。** ADR-0015 は「有報には定量的・無機質な情報しか無く、定性的な意味付けが決定的に欠けている」ことを背景に置いた。**要約が事実を、分析が意味付けを引き受ける**という分業で、片方が事実に寄れば分業そのものが消える。**同じ材料から2つ作って両方とも事実なら、1つでよかったことになる。**

**規則を積む工程には、締まる方向にしか動かない癖がある。** 落ちた型を書き戻すのは C6 から続く C9 の中心的な仕組みで、実際に品質を上げてきた。**ただし落ちるのは常に「言い過ぎた」側で、「言い足りない」側は落ちない**——検証パスは材料と突き合わせるので、材料に近い文ほど通る。**50回ぶんの書き戻しが一方向に効き続けた結果が、いまの分析である。**

**推測の誤りと事実の誤りは、読者にとって同じものではない。** 「労務費の高騰が利益を削っている」が外れていても、読者は分析として読んでおり、材料を見れば自分で判断できる。**「営業利益は増えた」が実際には減っていれば、それは嘘である。** 落とす線をここに引けば、**踏み込みと正確さは両立する。**

## 却下した案

- **段階を作って「推測です」と印を付ける。** 文ごとに「事実／推測」を分けて表示する案。**分析セクション全体が推測であることは C10 が断る**ので、その中でさらに分けると、印の無い文が「事実」として読まれる——いま以上に危うい。
- **記憶も含めて全部許す。** 数値まで記憶から書けるようにすると、**同じページの表と食い違う数字が出たときに気づく手段が無い**。害の形が違うので、ここだけ線を残した。
- **型を全部消す。** 事実の誤り6種は、実際に50回のうちで繰り返し出た（型S1 は3回、型A12 は3回）。**消せば同じ誤りが戻る。**
