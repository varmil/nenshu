# ADR-0001 ホスティングは Cloudflare Pages にする

状態: Accepted
日付: 2026-08-16

## 文脈

運営者は1名で、2026年10月1日から本業が始まる。ランニングコストをゼロに保ちたい。

収益化は広告とアフィリエイトを想定している（`docs/product/product.md` の施策マップ、monetize）。まだ実装していないが、サイトの目的として最初から織り込まれている。

配信するのは静的ファイルのみで、サーバーサイドの実行環境は要らない。

## 決定

**Cloudflare Pages に静的サイトとしてデプロイする。**

## 理由

**Vercel の Hobby プランは商用利用が禁止されている。** Vercel のフェアユースガイドラインは、アフィリエイトリンクを主目的とすること、Google AdSense 等の広告掲載を、商用利用の例として明示的に列挙している。このサイトの収益源はまさにそこなので、Vercel を選ぶなら広告を貼った時点で月20ドルの Pro が必要になる。無料で始めて後から課金へ移る話ではなく、目的の時点で対象外になる。

Cloudflare Pages の無料枠には商用利用の制限がない。帯域も無制限で、月500回のビルドが付く。データ更新は年1回なので、ビルド回数が問題になる場面がない。

## 結果

- 本番デプロイは GitHub 連携による自動ビルド。
- Next.js は `output: 'export'` で静的書き出しする（ADR-0002）。Vercel 固有の機能に依存しない。
- 独自ドメインと SSL は無料で付く。ドメイン取得費（年間1,000〜2,000円程度）だけが継続コストになる。
- サーバーサイドの実行環境がないため、ログイン・会員機能・動的なAPIは選択肢から外れる。この制約は intent.md の「作らないもの」と整合している。
- 収益化を実装する前でも、この判断を先に固定しておく。後からホスティングを移すと、DNS・リダイレクト・SEO の再評価が発生して高くつく。

## 却下案

**Vercel Pro（月20ドル）** — 収益が立つ前から固定費が出る。開発体験の差は静的サイトではほぼない。

**Vercel Hobby のまま様子を見る** — 規約違反の状態で運用することになる。Vercel の運用停止は予告なく起こりうるうえ、Hobby は上限超過時に課金ではなくデプロイの停止で対応する仕様なので、止まったときに気づくのが遅れる。10月以降は監視の手が空かない。

**GitHub Pages** — 商用制限はないが、リダイレクトとヘッダーの制御が弱く、ビルドと配信の一体化も浅い。

**Cloudflare Workers** — 静的配信だけなら Pages で足りる。今の要件に対して過剰になる。
