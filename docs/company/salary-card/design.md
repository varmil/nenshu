参照: Issue [#818](https://github.com/varmil/nenshu/issues/818)（親: [#817](https://github.com/varmil/nenshu/issues/817)）, `docs/company/spec.md` 1.4・1.13・AC-32

## 出来上がり

`/company/[id]` の上部カード（平均年収のカード）の左側。**数字は1つも変わっていない。**

```

2,178万円                              2,178万円
全体平均 693万円 に対して ＋1,486万円  全体平均 693万円 に対して ＋1,486万円
─────────────────────────              ─────────────────────────

3位 /2,961社 1位 /193社 124.8   ←太字  35.0歳     3,306人
─────────────────────────              ─────────────────────────
平均年齢   在籍年数    従業員数（単体）全体順位   業界内順位  年収偏差値
35.0歳     11.3年      3,306人         3位 /2,961社 1位 /193社 124.8
```

右側（位置バーとヒストグラム）は並びを変えていない。ヒストグラムの説明から
「両端の階級はそれより外側をすべて含みます。」を外した。

モバイル（1カラム）の読み順は 金額 → 平均年齢・従業員数 → 順位 → 位置バー → 分布 になる。
**順位が位置バーの直前に来る**ので、同じ話（母集団の中のどこか）が続けて読める。

## 構成

| 場所 | 中身 |
| --- | --- |
| `web/features/company/lib/cardFacts.ts` | `buildCardFacts(view, current)` が `{ profile, standing }` の2段を返す。各項目は `{ label, value, total? }`。`total` は順位の母数（`/2,961社`）で、値より小さく添えるので値と分けて持つ |
| `web/features/company/components/CompanyDetail.tsx` | `CardFactList` が1段を描く。カードは `buildCardFacts` の出力を2つ並べるだけになった |
| `web/features/company/components/SalaryDistributionChart.tsx` | `figcaption` の3文目を削除 |

### 2段の中身

| 段 | 項目 | 表示基準で変わるか |
| --- | --- | --- |
| 1段目（`profile`） | 平均年齢・従業員数（単体） | 変わらない（有報の値そのもの） |
| 2段目（`standing`） | 全体順位・業界内順位・年収偏差値 | 変わる |

- **在籍年数はカードに出さない。** 値は下の「有価証券報告書の実測値」の節と、レーダーの
  「定着（在籍）」の軸にある。平均年齢と従業員数は下の節と重複するが、**金額の隣に無いと
  「35.0歳の会社の2,178万円」という読み方ができない**（C3 のまま）
- **1段目を「どういう会社の金額か」にした**のは親 #817 の指摘から。OpenWork・OpenMoney は
  平均年収・年収範囲・平均年齢・回答者数の4つに絞っている。**年収範囲は足さない**——有報は
  平均しか持たない
- **順位はカードの右の位置バーと同じ話**なので、そちらに近い段に置く。順位は h1 の直下の
  1行にもある

### 見た目

- **2段とも3列の器**（`grid-cols-3`）。1段目は2項目なので3列目が空く。2等分にすると従業員数が
  業界内順位より右にずれ、2つの段が別々の表に見える。E2E が `dt` の左端のずれを 1px 以内で固定している
- **太字は金額だけ。** 順位の `font-semibold` を外し、2段とも同じ書式にした。以前は太字の順位が
  金額の次に目に入り、金額の直後に来るべき「どういう会社か」が3段目まで届かなかった
- **ラベルも値も `whitespace-nowrap`**（C3 の公開後の指摘のまま）。1列あたり 110px ほどで、
  既定のままだと「38位 /1,867社」と「従業員数（単体）」が2行に折れる。1280px と 390px の
  両方で E2E が固定している（それまでは 1280px だけだった）

### 描画のたびに組み立てる

`buildCardFacts` はクライアントで描画するたびに呼ぶ。**島の props には載せない**——載せると
固定のラベル（「従業員数（単体）」など）が HTML の属性にも入る（W2・#224 と C7・#161 で踏んだ形）。
`CompanyView` と `CompanyAgeStats` は既に props に載っている値なので、増えるものは無い。

## 「両端の階級」の1文を外した理由

横軸の目盛が `〜500` / `1,200+`（実測値の場合）の形で既に同じことを言っており、読み上げ用の
一覧（`sr-only`）も「500万円未満」「1,200万円以上」と読む。**両端のビンが外側を吸収する仕組み
（C2 の `buildDistribution`）は変えていない。**

この1文が無くなったぶん、説明が PC で3行 → 2行になった。

## 固定しているもの

- **Unit テスト**（`cardFacts.test.ts`）——2段のラベルの並び、在籍年数が無いこと、キーエンスの
  実測値と35歳そろえの値、表示基準で1段目が変わらないこと、母数を持つのが順位だけであること
- **E2E**（`e2e/company-refresh.spec.ts` の「AC-32 平均年収カード（C14）」）——2段の中身と上下の順、
  在籍年数がカードに無く実測値の節にあること、列のそろい、太字が金額だけであること、年齢そろえで
  2段目だけが変わり1段目と金額直下の1文は変わらないこと、見出しと金額の間が 4px であること。
  分布の図の説明に「両端の階級」が無く両端の目盛が残ることは同じファイルの AC-13 が見る
- **カードの `dl` を「何番目か」で引かない。** `e2e/company-page.spec.ts` の `card()` は順位の段を
  `全体順位` を含む `dl` として引く。C14 で段の順が入れ替わり、`first()` のままだと平均年齢の段を
  指していた
