# C14 平均年収カードの整理 — plan.md

参照: Issue [#818](https://github.com/varmil/nenshu/issues/818)（親: [#817](https://github.com/varmil/nenshu/issues/817)）, `docs/company/spec.md` 1.4・1.13・AC-32
依存: なし（C3・#89 で作った上部カードを変える）

## Context

企業詳細ページの上部カードの左側は、C3 から 金額 → 順位3つ（太字）→ 実測3つ（平均年齢・在籍年数・
従業員数）の順になっている。数字が6つ並び、しかも金額の次に目に入るのが太字の順位で、
「どういう会社の金額か」が3段目まで出てこない（親 #817）。OpenWork・OpenMoney は
平均年収・年収範囲・平均年齢・回答者数の4つに絞っている。

**数字は1つも変えない。** 並びと太さを変え、カードから在籍年数を外し、分布の図の固定の1文を外す。

## 進め方

1. **変更前を測る。** `astro build` で `/company/6861` の HTML（raw / gzip）を記録する。
   dev サーバーで 1280px・390px のカードを撮っておく
2. **spec を先に直す。** 1.4 にカードに並べるもの（2段の中身と、在籍年数を出さないこと）を、
   1.13 に「両端の階級」の文を置かない理由を書き、AC-32 を足す
3. **E2E を先に書き換える。** カードの2段の並び・在籍年数が無いこと・順位が太字でないこと・
   列のそろい・分布の図の説明に「両端の階級」が無いこと。カードの `dl` を「1つ目」で引いている
   既存のテストは中身で引くように直す。**この時点で走らせて落ちることを確かめる**
4. **カードの並びを純粋関数にし、Unit テストを先に書く。** 2段の項目と値の書式を
   `features/company/lib/` に置き、キーエンスの実データで固定する
5. **描画を直す。** `CompanyDetail.tsx` のカードを関数の出力から描き、`SalaryDistributionChart.tsx`
   の説明文から1文を外す
6. **検証。** lint・typecheck・vitest、E2E を dev サーバーに向けて企業詳細の spec 一式と全件で回す。
   1280px・390px、ライトとダークでカードを撮って 1. と見比べる。`/company/6861` の HTML を
   測り直し、`/` が変わらないことを見る
7. **docs を直す。** design.md、C3 の design.md と CLAUDE.md に残る「カードに在籍年数」の記述
