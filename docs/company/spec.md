# spec.md — 企業詳細ページ

対象面: user-web（ユーザー画面）

1社につき1枚、計1,867枚のページを `/company/[id]` に置く。用語は `docs/product/glossary.md` に従う。URL の構成は ADR-0006 に従う。

---

## 1. 企業詳細ページ（`/company/[id]`）

### 1.1 何を出すか（WHAT）

1社の年齢補正年収と、その会社が全体・業界内でどの位置にあるかを出す。載せる数値はすべて `companies.json` / `curves.json` から導けるものに限る。

初期状態は目標年齢35歳。

### 1.2 なぜ（WHY）

読者の多くは特定の1社を頭に置いて訪れる。「◯◯（社名） 年収」という検索の受け皿が無く、その問いは1,867行の表の中でしか解けない。順位だけでは水準が伝わらないため、上位◯%と全体平均との差を同時に出す。

### 1.3 ID

- 証券コードがある会社はそれ（1,760社。`6861`・新形式の `285A` を含む）
- 無ければ EDINETコード（107社。`E01798` 形式）

上場か否かではなく証券コードの有無で分ける。

ADR-0006 で決定。書類ID由来のIDは使わない（毎年変わるため）。

### 1.4 載せるもの

| 区分 | 項目 | 備考 |
| --- | --- | --- |
| 見出し | 会社名 | 「本社のみ」バッジを添える |
| | 業種（tse33） | ランキングの業種フィルタへのリンクにする |
| **主役** | **目標年齢時点の推定年収** | 推定であることを常時示す |
| 位置 | 全体順位 | `n位 / 1,867社`。上位◯%を併記する |
| | 業界内順位 | `n位 / m社`。業種名を添える |
| | 年収偏差値 | 上位◯%を隣に置き、100を超えうる理由を注記する |
| | 全体平均との差 | `＋◯万円` / `−◯万円`。母集団の平均額も出す |
| 実測値 | 平均年収（実額） | 補正前 |
| | 平均年齢 / 在籍年数 / 従業員数（単体） | |
| 推移 | 年齢別の推定年収チャート | 25〜60歳の8点 |
| 前提 | 出典と `/about` への導線 | EDINET・賃金構造基本統計調査 |

金額の書式はランキングと揃える（万円単位・カンマ区切りの整数）。年齢と在籍年数は小数第1位まで。偏差値は小数第1位まで。上位◯%は小数第1位まで（0.1%未満は「上位0.1%未満」とする）。

**推定値と実測値を同じ書式で並べない**（CLAUDE.md）。推定年収と平均年収（実額）は視覚的に区別する。

### 1.5 年齢スイッチ

ランキングと同じ 25 / 30 / 35 / 40 / 45 / 50 / 55 / 60 歳の8段。単一選択。

操作すると推定年収・全体順位・業界内順位・偏差値・全体平均との差が更新される。**ページ遷移も再取得も発生させない。**

URL には `?age=` として反映する。既定値の35歳は URL に出さない。

### 1.6 年齢別の推定年収チャート

25〜60歳の8点を結ぶ折れ線。縦軸は推定年収。選択中の目標年齢を強調する。

**このチャートは1社の中の推移であって、同じ人が歳を取っていく軌跡ではない**（賃金カーブの性質。`/about` に既に書いてある）。チャートの近くに注記を置く。

### 1.7 順位・偏差値の定義

母集団は**その目標年齢時点の推定年収**で並べた全1,867社。

- **全体順位** — 同額の会社は同順位にする（自分より高い会社の数 ＋ 1）
- **上位◯%** — `全体順位 ÷ 1,867 × 100`
- **業界内順位** — 同じ tse33 の会社に限った同じ計算
- **年収偏差値** — `50 + 10 ×（自社の推定年収 − 母集団の平均）÷ 母集団の標準偏差`。母集団は全1,867社
- **全体平均との差** — `自社の推定年収 − 母集団の平均`

年齢ごとに母集団の平均・標準偏差が変わるため、これらはすべて目標年齢に依存する。

### 1.8 存在しないID

`/company/存在しないid` は 404 を返す。

### 1.9 ランキングからの導線

ランキング表・カードの会社名から企業詳細ページに遷移できる。

### 1.10 対象外（v1）

平均年収の10年推移、株価推移、信用格付け、業績、口コミ、会社ごとの解説文、同業他社の比較表。

10年推移は `docs/product/product.md` の `timeseries` 施策、株価・格付けは `market-data` 施策として別に扱う。

## 2. 非機能要件

**配信** — ランキングと同じフルSSR（ADR-0004）。エッジキャッシュを効かせる。

**データ量** — クライアントに送るのは当該1社ぶんの数値だけにする。1,867社ぶんのデータを企業詳細ページに載せない。

**計算量** — 順位・偏差値の母集団統計はビルド時に確定させる。リクエストごとに1,867社×8年齢を計算しない（Workers Free の CPU 10ms/リクエスト制約。`docs/ranking/ssr-migration/design.md` 参照）。

**応答** — 年齢スイッチの操作から表示更新まで100ms以内。ネットワークアクセスを伴わない。

**対応環境** — モバイルを主とする。横スクロールを発生させない。

**SEO** — 数値はすべて初期HTMLに含める。クライアント側の描画待ちにしない。canonical・sitemap は ADR-0006 に従う。

**アクセシビリティ** — 年齢スイッチはキーボードで操作できる。チャートは画像ではなくSVGで、数値を読み上げられる代替を持たせる。

## 3. 受け入れ基準

数値は `2026-06` 版データの実測値。

### AC-1 初期表示

```gherkin
Given /company/6861 を開く
When 何も操作しない
Then 「株式会社キーエンス」と業種「電気機器」が表示される
And 35歳時点の推定年収が2,178万円と表示される
And 全体順位が「1位 / 1,867社」と表示される
And 業界内順位が「1位 / 150社」と表示される
And 平均年収（実額）2,178万円・平均年齢35.0歳・在籍年数11.3年・従業員数3,306人が表示される
```

### AC-2 位置の指標

```gherkin
Given /company/6861 を開いている
Then 年収偏差値が150.0と表示される
And 上位◯%が偏差値の隣に表示される
And 「年収の分布は右に裾を引くため偏差値は100を超えることがある」旨の注記がある
And 全体平均との差が「＋1,549万円」、全体平均が629万円と表示される
```

```gherkin
Given /company/7203 を開いている
Then トヨタ自動車株式会社の35歳時点の推定年収が859万円と表示される
And 全体順位が「120位 / 1,867社（上位6.4%）」と表示される
And 業界内順位が「2位 / 71社」と表示される
```

### AC-3 年齢スイッチ

```gherkin
Given /company/6861 を開いている
When 年齢スイッチで25歳を選ぶ
Then 推定年収が788万円に変わる
And 年収偏差値が127.3に変わる
And 全体平均との差が「＋369万円」に変わる
And ページ遷移が発生しない
And URLに age=25 が反映される
```

```gherkin
Given /company/6861?age=60 を直接開く
Then 年齢スイッチが60歳を選択した状態になる
And 推定年収が2,213万円と表示される
```

### AC-4 年齢別チャート

```gherkin
Given /company/6861 を開いている
Then 25歳から60歳までの推定年収の折れ線が表示される
And 選択中の目標年齢が強調される
And このカーブが1社の中の推移であって個人の軌跡ではない旨の注記がある
```

### AC-5 非上場企業のID

```gherkin
Given /company/E03532 を開く
Then 株式会社みずほ銀行が表示される（IDはEDINETコード）
And 35歳時点の推定年収が755万円と表示される
And 全体順位が「280位 / 1,867社（上位15.0%）」と表示される
And 業界内順位が「17位 / 82社」と表示される
```

### AC-6 「本社のみ」バッジ

```gherkin
Given /company/8058 を開く
Then 三菱商事株式会社に「本社のみ」バッジが表示される
And バッジの意味（単体従業員数が連結の10%未満）が読める、または /about へ導かれる
```

### AC-7 存在しないID

```gherkin
Given /company/s100yfah （旧形式の書類ID）を開く
Then 404 が返る
```

### AC-8 ランキングからの導線

```gherkin
Given トップページを開いている
When 1位の「株式会社キーエンス」をクリックする
Then /company/6861 に遷移する
```

### AC-9 推定であることの明示

```gherkin
Given どの年齢を選んでいても
Then 推定年収が推定値であることを示す表記が画面上に存在する
And 平均年収（実額）と推定年収が同じ書式で並んでいない
And 出典と計算方法ページへの導線がある
```

### AC-10 初期HTML

```gherkin
Given /company/6861?age=25 に対するHTMLをJS実行前に取得する
Then 「788万円」がHTMLに含まれている
```
