# C16 実測値の4項目を年収に関するQ&Aに — plan.md

参照: Issue [#838](https://github.com/varmil/nenshu/issues/838)（親: [#836](https://github.com/varmil/nenshu/issues/836)）, `docs/company/spec.md` 1.22・AC-34・1.17・1.20・1.21・AC-17・AC-31・AC-32, `docs/site-chrome/spec.md` 4.4・5.1
依存: なし（C13・#814 の帯と C10・#242 の要約の位置を前提にする。どちらも実装済み）

## Context

企業詳細ページの「有価証券報告書の実測値（2026年3月期）」の節は、4項目を1文にした地の文（C4）と
4セルの表（C1）で同じ数字を2回言い、その下に EDINET の帯（C13）が付いている。親 #836 はこれを
**項目ごとの Q&A** にし、検索結果の抜粋や AI の回答に引用されやすくしたいというもの。

意匠は Claude Design `Company Actuals QA.dc.html` の **1b（常時展開）** と **1d（置き場所）** を
運営者が選んだ。1b の注記にある「同じ4問を FAQPage の JSON-LD にも出す」は、Google が 2026-05-07 に
FAQ のリッチリザルトを終了していることを確かめたうえで、**運営者の判断で出さない**ことにした。

## 進め方

1. **変更前を測る。** main のまま `astro build` し、`/company/6861`・`7203`・`8058`・`4686` と `/` の
   HTML（raw / gzip）を記録する。dev サーバーで `/company/6861` を 1280×800 と 390×844 で開き、
   実測値の節の高さを記録する
2. **spec を先に直す。** company の 1.22 と AC-34 を足し、1.4・1.15・1.17・1.20・1.21・AC-17・AC-31・
   AC-32 の「実測値の節」を指す記述を Q&A に改める。site-chrome の 5.1（決算期の置き場所）と 4.4
   （FAQPage を出さないこと）、glossary（「平均勤続年数」と書く場所）も直す
3. **E2E を先に書き換える。** 節を見出し「有価証券報告書の実測値」で引いているもの（`company-page`・
   `company-filing`・`data-period`・`company-refresh`・`company-summary`）を Q&A に合わせ、AC-34 の
   テストを足す。**この時点で走らせて落ちることを確かめる**
4. **文言を組む純粋関数を書く。** 見出し・説明・4問の質問と回答を1つの関数から出し、Unit テストで
   キーエンスの文言を丸ごと固定する。地の文を組んでいた関数とそのテストは外す
5. **節を描き、置き場所を移す。** 表示基準で変わらない節なので、C10・C12 と同じく `[id].astro` から
   静的に差し込む形にする。島からは実測値の節と、それだけが使っていた書類 ID を外す。関連する
   コメント（決算期の置き場所・在籍年数の置き場所・帯の位置）を直す
6. **検証。** lint・typecheck・vitest、E2E を dev サーバーに向けて企業詳細の spec 一式と全件で回す。
   1. と同じ条件で測り直して並べる。`/` が変わっていないことを確かめる
7. **docs を直す。** design.md、C4・C13 の design.md への注、CLAUDE.md の記述
