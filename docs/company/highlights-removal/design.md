# C11 「この会社の要点」の削除 — design.md

参照: Issue [#799](https://github.com/varmil/nenshu/issues/799)（親: [#214](https://github.com/varmil/nenshu/issues/214)）, `docs/company/spec.md` 1.11・AC-11（削除した）・AC-15

## 出来上がり

`/company/[id]` の右サイドバーは「水準が近い会社」の1枚だけになる。モバイルではページの
末尾（「この数字の作り方」の後ろ。C12・#805 で「このページの出典」に作り替えた）に同じ1枚が出る。

```
PC（1280px）
┌──────────────────────────┬────────────────┐
│ 公開資料による全体像     │ 電気機器で     │ ← md:sticky
│ 平均年収カード           │ 水準が近い会社 │
│ …                        │ （10社）       │
```

| | 外す前 | 外した後 |
| --- | --- | --- |
| サイドバーの高さ（3003） | 1,029px | 669px |
| サイドバーの高さ（6861） | 964px | 669px |
| サイドバーの高さ（9107） | 801px | 551px |

（1280×800・dev サーバーで実測。外した後の値は水準が近い会社の1枚ぶん。）

## 外した理由

- **中身がカードの繰り返しだった。** 箇条書きの1・2項目（金額・全体順位・偏差値・業界内
  順位）は左の平均年収カードと同じ数字だった
- **要約の置き場所にするには器が小さい。** 幅316px・12pxの字では1行23字前後で、要約
  （中央値400字・最長722字）は18〜31行になる。要約の位置は C10（#242）で決める
- **サイドバーが画面より高かった。** `md:sticky md:top-4` で画面に貼り付く作りなので、
  はみ出した下端（水準が近い会社の後半）は本文を最後まで下ろさないと見えなかった

## 要点にしか無かった情報

| 中身 | 扱い |
| --- | --- |
| 平均年齢・勤続・従業員数の三分位（「最も短い層に入る」など） | 捨てた。値そのものはカードにある |
| 「本社のみ」の断り | フッタに同じ文がある（AC-6） |
| 「平均年齢が低い（高い）ぶん実測値は低め（高め）に出る。年齢そろえで比べ直せる」 | 捨てた。移す先の見せ方の帯のヒントは全社共通の文なので、会社ごとに出し分ける形にはならない |

## 固定しているもの

- **要点が出ない**——見出しが無いことを、ハイドレーション後の DOM と生の HTML の両方で見る
- **サイドバーが画面に収まる**——1280×800 で `aside` の高さが画面の高さから `top-4`（16px）を
  引いた値以下であること。**水準が近い会社は最大10社**なので、行が最も多い会社（6861）で見る
