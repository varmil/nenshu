# intent.md — レーダーに「平均年収の伸び」を足す（6軸）

親 Issue: [#912](https://github.com/varmil/nenshu/issues/912)

## なぜ作るか

**企業詳細ページのレーダー「公開資料による全体像」が、一部の会社で線（2点）にしかならなくなるため。**

いまのレーダーは5軸で、出どころは有報が3本（平均年収・定着・稼ぐ力）、女性活躍データベースが2本（有給・残業）ある。performance 施策は「有報3本なら、データベースの2本が欠けても最悪で三角形が残る」ことを狙って稼ぐ力を入れた（`docs/performance/intent.md`）。

**#911 でこの前提が崩れる。** 連結の経常利益が無い会社（IFRS・米国基準の240社）は稼ぐ力を掲載しないと決めた。240社のうち有給・残業も無い会社は、平均年収と定着の2点しか打てない。

| 軸の組み方 | 2点以下の会社 |
| --- | ---: |
| いま | 1社 |
| #911 の後（5軸） | **72社** |
| 平均年収の伸びを足して6軸にする（#911 の後） | **20社** |

2026-09-30 のデータ（ランキング内 2,978社）で数えた。72社の多くは大企業の持株会社で、キリンHD・日清食品HD・DeNA・エムスリー・キオクシアHD など、**検索から読まれやすい会社の図が崩れる。** 持株会社は女性活躍データベースに子会社の側で登録していることが多く、有給・残業の2軸も欠けやすい。

もう1つ、読者にとっての意味がある。**いまのレーダーには年収の水準はあるが、動きが無い。** 「この10年で平均年収が上がってきた会社か」は転職を考える読者がまず知りたいことの1つで、推移の節（本文の後半）まで下りないと読めない。推移の節の数字から1軸を作れば、レーダー（本文の2番目）の時点で読める。

## 成功指標

North Star KPI は ranking 施策と同じ **自然検索からの月間セッション数**（`docs/ranking/intent.md`）。この施策はページを増やさない。寄与は企業詳細ページの図が崩れないことと、情報が1つ増えることから来る。

- **レーダーの点が2つ以下の会社を、#911 の後の72社から20社まで減らす**
- 平均年収の伸びの軸を持つ会社が、ランキング内の **85%以上**（実測 2,627社・88.2%）
- 追加のデータ調達をしない（T0〜T4 が持つ10年推移と、P2 が持つ年次の従業員数だけで出す）
- トップページ（`/`）の HTML を1バイトも増やさない

## 前提の確認（実測）

2026-09-30 のデータで測った。スクリプトは残していない（数え方は各項に書く）。

### 置き換えではなく、足す

最初の案は「稼ぐ力を外して、平均年収の伸びに置き換える（5軸のまま）」だった。**置き換えると2点以下の会社は減らず、顔ぶれが入れ替わるだけになる。**

| 軸の組み方（#911 の後） | 2点以下 |
| --- | ---: |
| 5軸のまま | 72社 |
| 稼ぐ力を伸びに置き換える（伸びは5年以上の幅がある会社だけ） | 167社以上 |
| **稼ぐ力を残して伸びを足す（6軸）** | **20社** |

置き換えると、72社（大企業の持株会社）は伸びの軸で3点に戻る。代わりに**上場して数年の会社**（推移が3〜4年ぶん）が2点になる。こうした会社は女性活躍データベースにも登録が無いことが多く、欠ける場所が重なる。

6軸でも2点のまま残る20社は、すべて #911 の対象で、伸びも出せない会社になる。伸びを出せない理由は、持株会社化などで提出会社の範囲が変わった（下の「会社の形が変わった会社」）か、推移が5年に満たない（キオクシアHD など）かのどちらか。

### 年率で測る。万円の差でも累積の%でもない

- **万円の差は、いまの平均年収との順位相関が0.46ある。** 平均年収の軸とほぼ同じ並びをもう一度測ることになる。**年率なら0.23**
- **累積の%は会社どうしで比べられない。** 推移の窓の中で最初に値のある年（基準年）は会社ごとに違い、最新年との幅は1〜9年に散らばる（9年が2,261社、5〜8年が448社、4年以下が269社）

年率の分布（5年以上の幅がある会社、下の線で外した後の2,627社）:

| 5% | 25% | 中央値 | 75% | 95% | 下がった会社 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| −0.36% | 0.74% | 1.41% | 2.21% | 4.12% | 221社 |

上位は メルカリ 11.9%・ＧＭＯフィナンシャルゲート 9.9%・霞ヶ関キャピタル 9.8%・ディスコ 8.7%・商船三井 7.7% と、実際に水準を上げてきた会社が並ぶ。

### 幅が5年に満たない会社は出さない

最低の幅を3年にすると、3〜4年幅の会社（全体の4.8%）が上位5%の19%・下位5%の14%を占める。幅が短いほど1年の動きで年率が大きく振れるため。**5年以上に限る。**

### 会社の形が変わった会社は出さない

持株会社化や、持株会社への吸収合併では、提出会社の単体に数えられる人がごっそり入れ替わる。平均年収はその前後で別の集団の平均になり、「伸びた」「下がった」とは読めない。

- オープンアップグループ: 420万 → 860万円（年率 8.3%）。単体の人数が3%に減り、単体÷連結の比が 0.379 → 0.004
- パナソニックHD: 単体の人数が2%に減り、比が 0.223 → 0.008（2022年の持株会社化）
- LIXIL: 1,199万 → 730万円（年率 −6.9%）。単体の人数が270倍、比が 0.001 → 0.315

**単体の人数だけで線を引くと、会社ごと育った会社を落とす**（運営者の指摘）。単体の人数が3倍超／3分の1未満に動いた173社のうち、**91社は単体÷連結の比の動きが3倍以内**——KIYOラーニング（連結なし・単体3.9倍）・北の達人コーポレーション（4.2倍）・アトラエ（3.3倍）のように、グループごと大きくなった会社になる。

**比だけで線を引くと、M&A で連結だけが増えた会社を落とす。** ウィルグループ（単体1.6倍・比 0.054 → 0.012）・ペプチドリーム（単体2.8倍・比 1.0 → 0.26）は、提出会社の中の人は入れ替わっていない。

**そこで両方を満たす会社だけを外す**——単体の人数が3倍超／3分の1未満に動き、**かつ**単体÷連結の比も3倍超動いた会社。82社になる。

### 平均年齢の動きを隣に添える

伸びの上位100社のうち39社は、同じ期間に平均年齢が3歳以上上がっている（全体では24%）。メルカリは 2018 → 2026年に平均年齢が7.0歳上がった。**平均年収は年齢構成が変わるだけでも動く**ので、同じ期間の平均年齢の動きを隣に置き、読者が自分で読めるようにする——推移の表の前年比を平均年齢に置き換えた T3（#827）と同じ理由。

### 業種の中央値は添えない

業種ごとの中央値は 0.92%（医薬品）〜 2.19%（不動産業）に収まる（海運業だけ 3.39%・9社）。**業種の中の散らばり（標準偏差の中央値 1.16%）のほうが、業種どうしの差（0.45%）より大きい。** 業種差が30倍ある稼ぐ力と違い、業種の文脈を数字で添えなくても順位が業種の当たり外れにはならない。

### 「昇給率」とは呼ばない

会社の平均年収の動きは、個人の昇給より構造的に小さく出る。勤続で上がる定期昇給のぶんは、定年で抜ける人と新しく入る人の入れ替わりで平均から打ち消されるため。

- 会社ごとの前年比の中央値は、決算期末が2025年の有報で 2.83%、2026年で 3.13%
- 同じ時期の春闘の賃上げ率（連合の最終集計、定期昇給込み）は 2024年 5.10%・2025年 5.25%

「昇給率 1.4%」と書くと、読者は春闘の5%や求人票の昇給と比べ、実際より昇給の少ない会社だと読む。**出す数字は会社の平均の動きなので、名前もそのとおりにする**（T2 の「数値の意味より強い名前を付けない」と同じ線。運営者も調べたうえで同意した）。

## 作らないもの

- **平均年収の伸びのランキング・並び替え・フィルタ。** レーダーの1軸に留める
- **年齢構成で補正した伸び。** 業種の賃金カーブを通すと推定値になる。軸の値は有報の実測値から機械的に出す計算値に留め、年齢の動きは数字として隣に添える
- **稼ぐ力の軸を外すこと。** 上の実測のとおり、外すと図の崩れる会社が増える
- **窓の途中の形の変化を見つけること。** 始点と終点だけを見る。途中で持株会社化して元の形に戻った会社は拾えない
- **分析（C9）の材料に足すこと。** 材料はすでに10年推移を持っている
