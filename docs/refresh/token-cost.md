## 原因

1. **CLAUDE.md が大きすぎた。** 236KB（11.4万字）のうち「現在地」が89%。**どのサブエージェントも最初の呼び出しの時点で約13.5万トークンあり、その大半がこれ**（48体すべて 13.5万〜14万）。サブエージェントは毎回、これを書き込み（cache_creation）、呼び出しのたびに読み直す。新しいプロセスで実測した最初の文脈は、旧 CLAUDE.md で 123,175、新 CLAUDE.md（28KB）で 45,384 トークン——**1回の呼び出しあたり約77,800トークンの差**
2. **メインの文脈が、日をまたいで 521k〜780k のまま回っていた。** 定期実行は同じセッションに毎日届く。Sonnet 5.5 は 1M の窓があり、自動圧縮の既定は約967Kトークン。今日の回は 521k で始まり、170回の呼び出しがそれぞれ 520k〜780k を読み直した（圧縮の後は 177k〜225k）。**メインの重み付きの 13.29 のうち約11が圧縮の前の170回**
3. **生成エージェントが規格を丸ごと読む。** `generate.md` 97KB・`rounding.md` 44KB を読むので、最初の文脈（13.5万）の上にさらに約10万トークンが載る。検証は `verify.md` 62KB。呼び出しは1体あたり20回前後
4. **メインの文脈の伸びは、依頼文・報告・Bash の出力。** 圧縮の前までの結果は、エージェントの報告と起動の返答 4.5万字・Bash の出力 5.4万字・ツールの入力（エージェントへの依頼文を含む）7.4万字。サブエージェントの報告は1体あたり20〜50行あり、そのまま残って以降の全呼び出しに読み直される

### 反映の条件

- **CLAUDE.md の変更は、動いているセッションには届かない。** セッションの開始時に一度読んで持つ。`/clear`・`/compact`・自動圧縮・再起動のときにディスクから読み直す（`context-window` の「What survives compaction」）。**定期実行のセッションは長生きなので、マージ後の最初の圧縮まで旧 CLAUDE.md を読み続ける**。早く反映したければ、そのセッションで `/compact` を実行する
- `autoCompactWindow` は `.claude/settings.json` に書いた。設定ファイルの変更が動いているセッションに届くかは確かめていない。届かなければ再起動（コンテナの再起動は数日おきに起きている）で入る

## 変えなかったもの

- **推論の強さ（`effortLevel: xhigh`）とモデル。** 運営者の決定（spec 1.14）。考える量は出力トークンに乗るが、サブエージェントの出力は記録に正しく残らず（途中の値しか書かれない）、メインの出力は 8.8万トークンで重み付きに直すと 0.4 ほど。削る相手としては小さい
- **規格（`pipeline/*/prompts/`）。** 通る基準のファイルで、品質に直接関わる
- **1社ずつ全工程を終えてから次へ移る順序**（spec 1.6）

## まだ手を付けていないもの（効果の大きい順・運営者の判断が要る）

1. **規格を縮める。** `generate.md` 97KB・`rounding.md` 44KB・`verify.md` 62KB は、読むだけで1体あたり 3.5万〜10万トークンを文脈に載せ、その後の呼び出し（gen は20回前後）が毎回読み直す。今日の回の gen（分析・要約）が 8.0 で最大の項目。**縮めると出力の品質が変わりうる**ので、書き直しの前後で同じ会社を回して比べる手順が要る
2. **2社を1組にして生成・検証する。** 1体あたりの固定費（最初の文脈・規格の読み込み）を2社で分け合える。`generate.py plan` は1バッチ6社まで対応している。**spec 1.6（1社ずつ全工程）の改訂になる**
3. **使っていないコネクタを止める。** このセッションには Gmail・Drive・Calendar・Vercel・Cloudflare・draw.io・Playwright などの説明とスキルの一覧（約2万文字）が毎回載る。claude.ai のコネクタ設定で止められる（リポジトリからは変えられない）
4. **書き直しを減らす。** 説明文の検証は13体が10社ぶん（3社が書き直し）。生成の依頼文に毎回足している注意（修飾語を共有しない・時点を書く等）を、`pipeline/summary/prompts/generate.md` に取り込めば、1回目で通る率が上がる。規格の変更になる
