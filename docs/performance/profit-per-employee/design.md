# design.md — P0 一人当たり経常利益の取り込み

Issue: [#155](https://github.com/varmil/nenshu/issues/155) ／ 親 [#154](https://github.com/varmil/nenshu/issues/154)
参照: `docs/performance/spec.md` 1.（データ）・AC-1〜AC-5

出来上がった内部構造。段取りは `plan.md`。

## 1書類に5期ぶん入っている（追加のダウンロードが要らなかった）

**`jpcrp_cor:OrdinaryIncomeLossSummaryOfBusinessResults` が `Prior4YearDuration` 〜 `CurrentYearDuration` の5つのコンテキストで来る。** 連結（接尾辞なし）と単体（`_NonConsolidatedMember`）の両方。

**直近5期の中央値は最新年の書類1件だけで出せる。** #155 が「T0 のキャッシュで足りるかを最初に確かめる」と書いていたのはここで、**足りた**。

**従業員数はそうではない。** `NumberOfEmployeesSummaryOfBusinessResults` に相当する要素は無く、当期の `jpcrp_cor:NumberOfEmployees` しかタグ付けされていない。5期ぶんは本文（`BusinessResultsOfGroupTextBlock`）の中にしかない。**年次の従業員数が要る P2（稼ぐ力の推移）だけが、10年ぶんの書類を取り直すことになる。**

## 計算

```
稼ぐ力 ＝ 連結の経常利益（直近5期の中央値） ÷ 連結の従業員数
```

- **連結で組む**（#154 の決定）。理由は `intent.md`。実測でも上位20社に「本社のみ」バッジが1社も無い
- **直近5期は「その会社が持つ年のうち新しい5つ」。** 固定の年で切らない——決算期は会社ごとにずれる
- **連結の従業員数が無い会社（191社）は単体で代用する**（`employeesConsolidated ?? employeesNonConsolidated`）。連結財務諸表を作っていない会社なので、単体がグループ全体でもある
- **連結の経常利益が無い年は単体で埋める**（`extract.py` の `_put` が基準の優先を見る）
- **赤字は負のまま持つ。** 捨てると「データが無い」と区別できなくなる

**同じ年が複数の書類から来る**（2026年の書類の `Prior1` と 2025年の書類の当期）。**遡りの少ないほう＝その年の書類の当期を優先する**——遡った値は会計基準の変更で組み替えられていることがあり、当期のほうが一次の記載になる。

## `performance.json` が持つのは金額と業種中央値だけ

**相対位置（レーダーの頂点をどこに打つか）の算出は表示側（P1）に置く。** 目盛りの決め方を後で変えてもデータを作り直さずに済む。

```
meta:           { count: 1867, matched: 1864, years: [2022..2026] }
perEmployee:    (number | null)[]   companies.rows と同じ並びの1,867件
industryMedian: (number | null)[]   companies.industries と同じ並びの33件
```

**`companies.rows` と同じ並びにする。** `stats.json`・`worklife.json` と同じ制約で、**行がずれると別の会社の稼ぐ力を出す。** 同じループで作り、テストで長さと代表値を固定してある。

| --- | ---: |
| 経常利益を取れた会社 | **1,865社（99.9%）**（P2 で10年ぶんを取ったあとの値。当初は1,864社） |
| 5期そろう | 1,855社 |

**P2（#168）で10年ぶんの書類を取ったあと、54社で値が変わり、電気機器の業種中央値は 181万円 → 191万円 になった。** 「遡りの少ないほう＝その年の書類の当期を優先する」が効くようになったためで、精度が上がった変更になる。**要素名の取り違えも2つ見つかって直した**（`docs/performance/profit-trend/design.md` の「取り込みで直したもの」）。

### 業種別のカバー率（AC-2）

**銀行業82社・保険業13社・その他金融業33社とも欠損なし。** 営業利益が無いことを理由に欠ける会社は出なかった——経常利益は業種を問わず「主要な経営指標等の推移」に載る。

| 業種 | 中央値 | | 業種 | 中央値 |

**中央値を採るのは1社の外れ値に引きずられないため。** 電気機器はキーエンスが業種中央値の21.2倍で、平均を使うと業種の代表値がキーエンスに引きずられる。

### 業種中央値に対する倍率の分布（P1 が目盛りを決めるための材料）

| 1%tile | 5%tile | 25%tile | 中央 | 75%tile | 95%tile | 99%tile |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| −0.59 | 0.08 | 0.53 | 1.00 | 1.72 | 4.46 | 11.47 |

**10倍超が25社、0.1倍未満が97社、負が59社。** 線形に当てると上位が振り切れ、下位が中心に潰れる。**相対位置の決め方は P1 の未決事項**（spec 5.）。

### 臨時雇用人員は従業員数に入らない

小売業の上位はワークマン（5,660万円）・ZOZO（3,155万円）・セリア（3,002万円）で、**フランチャイズ型・EC型で正社員が少ない業態**が並ぶ。有報の従業員数は正社員等の数で、パート・アルバイトは年間平均人員の外書きになる。

**値そのものは正しい**（実際に少人数で高収益）が、店頭の人手を含まない数字であることは画面に断る（P1）。
