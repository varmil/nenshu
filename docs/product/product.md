# product.md

有価証券報告書の平均年間給与を年齢で補正し、「その年齢時点でいくらか」を出す公開サイト。サイト名は **OpenReport**（`docs/site-chrome/spec.md` 1）。
常設の前提だけを置く。施策の中身は `docs/<施策>/` に書く。

## データの前提

対象は **直近12か月に有価証券報告書を提出した内国法人・組合 2,961社**（上場2,801社・非上場160社。
ADR-0011・E2）。決算期は会社ごとに違い、3月期が 63.5%。単体従業員100人以上に限る。

**窓は取得を回す日から遡って12か月**で、日付を直書きしない。以前は 6/1〜7/10 という3月期決算の
提出ピークに貼り付いており、キヤノン・日本たばこ産業・楽天グループ・イオン・ファーストリテイリング
のように決算期が3月でない会社が **1,095社** 落ちていた（親 Issue #22）。**窓を広げても、それまで
載っていた1,867社は1社も落ちていない**（実測）。

**掲載の条件は変えていない。** 窓の中の内国法人 4,133社のうち **1,047社が単体従業員100人未満**で
落ちる（数人しかいない持株会社が上位を埋めるのを避けるため）。この数は `/about` の「対象範囲」に出す。

補正カーブは厚生労働省「賃金構造基本統計調査」の産業別・年齢階級別の年収。
産業16分類＋産業計の17系列、年齢階級10点。

働きやすさ指標は厚生労働省「女性の活躍推進企業データベース」のオープンデータ（全件版・236列）。
有報の掲載社と**法人番号**で突合する（ADR-0009）。**新しく入った会社ぶんの再突合は E5（#177）**——それまでは1,548社ぶんしか無い。企業の自己申告値で、掲載は任意。

更新頻度は年1回。有報の提出が集中する6〜7月に再取得する。

会社の識別子は **証券コード／EDINETコード**（ADR-0006）。証券コードを持つのは2,819社、持たない142社は EDINETコードを使う。EDINETコードは年をまたいで変わらないため、公開URLと将来の年次データの名寄せの両方でこれを主キーにする。

## 制約

- 運営者は1名。2026年10月1日から本業が始まるため、それ以降の運用工数はほぼ取れない。
- **ランニングコストをゼロに保つ。** 有料のホスティング・データベース・外部APIを使わない。無料枠に収まるもの（Cloudflare Workers・D1 等）と、無料で取得できる外部データ（EDINET API・e-Stat・J-Quants の無料枠など）は使ってよい。**Workers 無料枠の CPU は 10ms/リクエストで、これは実際に超えた**（Issue #118）。企業詳細ページを事前生成して当てた（ADR-0012）。
- **取得したデータを再配布してよいかの判断は運営者が行う。** ライセンス・利用規約の解釈は運営者の責任で、エージェントの判断に委ねない。
- ランキングは常に1つの表に統合する。持株会社も除外せず、バッジと注記で区別する。
- 公開URLの構成とインデックス戦略は ADR-0006 に従う。一度公開したURLは変えない。
