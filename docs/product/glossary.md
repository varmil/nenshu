# glossary.md

並列に走る Unit のエージェントが別々の語を発明しないための共通語彙。
spec・overview・design・実装・UI文言のすべてがこれに従う。

## ドメイン用語

**平均年間給与**
有価証券報告書の「従業員の状況」に載る、提出会社**単体**の年間給与の平均額。賞与と時間外手当を含む。連結子会社の従業員は入らない。

**平均年齢 / 平均勤続年数**
同じく単体の数字。UI では平均勤続年数を「在籍年数」と表示する（一般の読者に通じる語を優先）。

**賃金カーブ**
産業ごとの、年齢に対する年収水準の折れ線。賃金構造基本統計調査から作る。代表年齢は 22, 27, 32, 37, 42, 47, 52, 57, 62, 67 歳の10点で、その間は区分線形補間する。範囲外は端の値で頭打ちにする。

**年齢補正年収**
目標年齢の時点に読み替えた推定年収。式は ADR-0005 の2点モデル。`C(a)` を業種カーブとして、

- 目標年齢 ≦ 平均年齢: `C(22) + (平均年間給与 − C(22)) × (C(目標年齢) − C(22)) ÷ (C(平均年齢) − C(22))`
- 目標年齢 > 平均年齢: `平均年間給与 × C(目標年齢) ÷ C(平均年齢)`

**推定値であって実測ではない。** UI では常に「推定」と分かる表記にする。「35歳換算」のような短縮語を単独で使わない。

**補正倍率（factor）**
`カーブ[業種](目標年齢) ÷ カーブ[業種](その会社の平均年齢)`。**目標年齢が平均年齢より上のときにしか使わない。** 若い側は2点モデルに変わったため、この倍率では表せない（ADR-0005）。CSV の `factor` 列は、この語ではなく**実際に掛かった比率 `salary35 ÷ avg_salary`** を入れている。表示には使っていない。

**目標年齢**
ユーザーが年齢スイッチで選ぶ年齢。25, 30, 35, 40, 45, 50, 55, 60 歳の8段。**表示基準が「実測値」のときは目標年齢を持たない**（内部表現では `null`）。

**表示基準**
サイトが金額として何を出すかの切替。**「実測値」と「年齢そろえ」の2つで、既定は実測値**（ADR-0007）。ランキングと企業詳細で同じ2つを使う。URL では `age` の有無が表示基準を表し、`age` が無ければ実測値、あれば年齢そろえになる。UI のラベルはランキングで「並べ方」、企業詳細で「見せ方」。

**実測値**
有価証券報告書の平均年間給与そのまま。補正を一切かけない。**既定の表示基準。** 検証できる一次情報なので、ここに「推定」の語もバッジも付けない。年齢をそろえていないため、平均年齢の高い会社が上に出る。

**年齢そろえ**
業種の賃金カーブで目標年齢に補正した年齢補正年収を出す表示基準。読者が明示的に選んだときだけ出す。こちらは推定値なので「推定」と分かる表記を伴う。

**東証33業種（tse33）**
表示・フィルタに使う業種。ユーザーに見せるのはこちら。

**産業大分類（industry）**
賃金カーブを引くための内部区分。17系列。**ランキングUIの表示・フィルタ軸には使わない。** tse33 から機械的に写像する。

**例外: 計算方法ページ（`/about`）では開示する。** 補正の式に登場する区分を伏せると「計算方法の全公開」（intent.md の差別化要因）と矛盾するため。また「東証33業種が17本のカーブに集約されている」ことは推定精度の実際の限界であり、限界の明示にあたる。U7 で決定（`docs/ranking/about-page/design.md`）。

**本社のみ**
単体従業員数が連結の10%未満の会社に付けるバッジ。持株会社の数字がグループを代表していないことを示す。173社。CSV の `badge` 列に対応する。

**単体 / 連結**
単体は提出会社1社ぶん、連結はグループ全体。年収は常に単体、従業員数は両方を持つ。

**企業ID**
公開URL `/company/[id]` に使う会社の識別子。証券コードがあればそれ、無ければ EDINETコード（ADR-0006）。**書類ID（EDINET書類管理番号）は使わない** ——毎年の有報提出で変わるため。

**EDINETコード**
EDINET が提出者に振る識別子（`E01798` 形式）。年をまたいで変わらないので、企業IDと、将来の年次データの名寄せの主キーにする。公開の EDINETコードリスト（`Edinetcode.zip`、APIキー不要）から取れる。

**全体順位 / 業界内順位**
選択中の**表示基準**における金額で並べたときの順位。全体順位の母集団は全1,867社、業界内順位は同じ tse33 の会社に限る。同額は同順位（自分より高い会社の数 ＋ 1）。**表示基準ごとに変わる**——実測値の順位と、8つの目標年齢それぞれの順位で計9通りある（`stats.json` の `bases`）。

**上位◯%**
`全体順位 ÷ 母集団の社数 × 100`。分布の形に依存しないので、年収偏差値より水準が読みやすい。**画面には出していない**（2026-08-20、運営者の判断）——Claude Design のモックに無い要素を足さないため。値は `CompanyAgeStats.topPercent` として残っており、必要になれば出せる。

**年収偏差値**
`50 + 10 ×（自社の金額 − 母集団の平均）÷ 母集団の標準偏差`。母集団は全1,867社で、**表示基準ごとに平均も標準偏差も変わる**（実測値は平均719万円・標準偏差200万円、35歳そろえは629万円・155万円）。

**年収の分布は右に強く裾を引くため、この値は100を超える**（35歳時点のキーエンスで150.0）。正規分布を前提にした指標を非正規分布に当てている。

**画面では数字だけを出し、水準は順位で読ませる。** 以前は「上位◯%」を必ず隣に置く決まりだったが、2026-08-20 に運営者の判断で外した（モックに無いものを足さない）。代わりに、100を超えうる理由の注記を**ランキングの表・カードの脚注と `/about`** に置き、順位（全体順位・業界内順位・位置バー）を同じ視界に必ず並べる。**企業詳細ページには注記を置かない**（2026-08-20 に運営者の判断で外した。数字の隣にある順位と位置バーが水準を持つため）。**偏差値だけが単独で置かれた画面を作らない**、という線は変わっていない。

## 働きやすさ指標（worklife 施策）

**女性活躍DB**
厚生労働省「女性の活躍推進企業データベース」。企業が女性活躍推進法に基づく公表項目を登録する。全件版のオープンデータは64,879行・236列。**掲載は任意**で、公表義務の履行先は自社サイトでもよい。有報の1,867社と突合できるのは1,679社（89.9%）。

**自己申告値**
女性活躍DB由来の値。企業が自分で登録したもので、第三者の検証を経ていない。**「実測値」と呼ばない**——glossary の「実測値」は有報の平均年間給与（監査を経た法定開示）を指す語で、意味が衝突する。**「推定」とも呼ばない**——推定値ではない。

**平均残業時間**
一月当たりの労働者の平均残業時間（時間）。**「全体」と「雇用管理区分ごと」の2つの公表項目に分かれている**ので、両方を見る（片方だけだと4割取りこぼす）。全体値には**公表する範囲**（`対象正社員` / `その他` / `基幹的な職種`）が付く。中央値14.6時間。

**年次有給休暇の取得率**
同じく「全体」と「雇用管理区分ごと」に分かれる。中央値73.8%。**100%を超える値がある**（繰越分の消化。小松製作所103.0 ほか7社）。丸めない。

**男女の賃金の差異**
`女性の平均賃金 ÷ 男性の平均賃金 × 100`（%）。100未満は女性のほうが低いことを示す。全労働者・うち正規雇用労働者・うち非正規雇用労働者の3つがある。中央値は全労働者で70.2%。

**数字だけを単独で置かない。** 差異の主因は職種構成や勤続年数の差であることが多く、716社は自由記述の説明を登録している。ある会社はそれも一緒に出す。

**雇用管理区分**
企業が自分で決める従業員の区分。**自由記述で、名前も数も会社によって違う**（「正社員」187社・「総合職」87社・「契約社員」68社・「派遣社員」19社など。区分数は0〜5）。**平均して1つの値にしない**——派遣とアルバイトを混ぜた残業時間に意味がない。区分名と値の組のまま出す。

**法人番号**
国税庁が法人に振る13桁の識別子。**女性活躍DBとの突合キー**（ADR-0009）。EDINETコードリストの `提出者法人番号` から取り、`ranking_unified_2026.csv` の `corporate_number` 列に持つ。証券コードと社名は突合に使わない。

## プロダクト用語

**年齢スイッチ**
目標年齢を切り替える操作。ランキング全体の金額を一斉に置き換える。**表示基準が「実測値」のときは無効（disabled）にするが、消さずに表示は残す**（ADR-0007）。

**表示基準スイッチ**
実測値と年齢そろえを切り替える操作。年齢スイッチの手前に置く。

**ランキング表**
ランキングの本体となる一覧。1行が1社。

**企業詳細ページ**
1社につき1枚の `/company/[id]`。ランキングが「どの会社が高いか」に答えるのに対し、こちらは「この会社はどのくらいか」に答える。

**Unit**
独立してリリースできるユーザー価値の垂直スライス。

## 使わない語

| 使わない | 使う | 理由 |
| --- | --- | --- |
| 年収診断 | — | ベンチマークサイトの弱点として指摘した機能。同じ語を持ち込まない |
| 平均勤続年数（UI） | 在籍年数 | 有報の用語より読者の語を優先 |
| 35歳換算（単独） | 35歳時点の推定年収 | 推定であることが落ちる |
| 想定年収 / 実力年収 | 年齢補正年収 | 根拠のない語感を足さない |
| 偏差値◯だけが置かれた画面 | 偏差値◯＋順位（同じ視界に） | 分布が右に裾を引き100を超えるため、偏差値だけでは水準が伝わらない |
| 賃金格差 | 男女の賃金の差異 | 公表項目の正式名。「格差」は評価語で、値そのもの（女性÷男性×100）を指さない |
| ホワイト企業 / ブラック企業 | — | 3つの数字から総合評価を作らない。評価は読者がする |
| 実測値（女性活躍DBの値に対して） | 自己申告値 | 「実測値」は有報の平均年間給与を指す語。意味が衝突する |
