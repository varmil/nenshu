# glossary.md

並列に走る Unit のエージェントが別々の語を発明しないための共通語彙。
spec・overview・design・実装・UI文言のすべてがこれに従う。

## ドメイン用語

**平均年間給与**
有価証券報告書の「従業員の状況」に載る、提出会社**単体**の年間給与の平均額。賞与と時間外手当を含む。連結子会社の従業員は入らない。

**平均年齢 / 平均勤続年数**
同じく単体の数字。UI では平均勤続年数を「在籍年数」と表示する（一般の読者に通じる語を優先）。

**賃金カーブ**
産業ごとの、年齢に対する年収水準の折れ線。賃金構造基本統計調査から作る。代表年齢は 22, 27, 32, 37, 42, 47, 52, 57, 62, 67 歳の10点で、その間は区分線形補間する。範囲外は端の値で頭打ちにする。

**年齢補正年収**
目標年齢の時点に読み替えた推定年収。式は ADR-0005 の2点モデル。`C(a)` を業種カーブとして、

- 目標年齢 ≦ 平均年齢: `C(22) + (平均年間給与 − C(22)) × (C(目標年齢) − C(22)) ÷ (C(平均年齢) − C(22))`
- 目標年齢 > 平均年齢: `平均年間給与 × C(目標年齢) ÷ C(平均年齢)`

**推定値であって実測ではない。** UI では常に「推定」と分かる表記にする。「35歳換算」のような短縮語を単独で使わない。

**補正倍率（factor）**
`カーブ[業種](目標年齢) ÷ カーブ[業種](その会社の平均年齢)`。**目標年齢が平均年齢より上のときにしか使わない。** 若い側は2点モデルに変わったため、この倍率では表せない（ADR-0005）。CSV の `factor` 列は旧式の派生値で、表示には使っていない。

**目標年齢**
ユーザーが年齢スイッチで選ぶ年齢。25, 30, 35, 40, 45, 50, 55, 60 歳の8段。

**東証33業種（tse33）**
表示・フィルタに使う業種。ユーザーに見せるのはこちら。

**産業大分類（industry）**
賃金カーブを引くための内部区分。17系列。**ランキングUIの表示・フィルタ軸には使わない。** tse33 から機械的に写像する。

**例外: 計算方法ページ（`/about`）では開示する。** 補正の式に登場する区分を伏せると「計算方法の全公開」（intent.md の差別化要因）と矛盾するため。また「東証33業種が17本のカーブに集約されている」ことは推定精度の実際の限界であり、限界の明示にあたる。U7 で決定（`docs/ranking/about-page/design.md`）。

**本社のみ**
単体従業員数が連結の10%未満の会社に付けるバッジ。持株会社の数字がグループを代表していないことを示す。173社。CSV の `badge` 列に対応する。

**単体 / 連結**
単体は提出会社1社ぶん、連結はグループ全体。年収は常に単体、従業員数は両方を持つ。

## プロダクト用語

**年齢スイッチ**
目標年齢を切り替える操作。ランキング全体の金額を一斉に置き換える。

**ランキング表**
ランキングの本体となる一覧。1行が1社。

**Unit**
独立してリリースできるユーザー価値の垂直スライス。

## 使わない語

| 使わない | 使う | 理由 |
| --- | --- | --- |
| 年収診断 | — | ベンチマークサイトの弱点として指摘した機能。同じ語を持ち込まない |
| 平均勤続年数（UI） | 在籍年数 | 有報の用語より読者の語を優先 |
| 35歳換算（単独） | 35歳時点の推定年収 | 推定であることが落ちる |
| 想定年収 / 実力年収 | 年齢補正年収 | 根拠のない語感を足さない |
